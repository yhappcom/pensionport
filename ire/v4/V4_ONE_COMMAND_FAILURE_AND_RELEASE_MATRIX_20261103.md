## 연구 보고 종료의 정확한 의미
완료 판정은 요청된 모든 primary cue가 실제로 적절한 원자주장 또는 합당한 비주장으로 해석되거나 증거가 남은 미확정 의미로 표시되고, **모든 주장에 필요한 외부 조사 의무가 시도되었으며**, 기존 관련 주장 관계를 검토하고, OPEN 항목의 구체적인 근거/영향을 적고, 불변 결과를 봉인한 경우에 한한다. 단순 큐 생성/표제 검색만으로 완료 아님.

`SOURCE_COVERAGE_COMPLETE`와 `RESEARCH_REPORT_COMPLETE_WITH_OPEN_ITEMS`는 **개별 사실이 최신 규정에 맞는다는 주장**이 아니다.
`FACT_VERIFIED_IN_SCOPE`는 원문·시행일·계좌/상품·관할·개인 조건까지 일치하는 범위의 개별 명제 판정이다.
`ADVISORY_ELIGIBLE`는 실제 질문·목표·위험·유동성·계좌·법적 세무조건을 확인한 해당 답변 범위에서만 가능하다.
