# V4 P0 — 모델 API 없는 실제 연속 연구 실행 실증 절차

**상태:** 실험 설계 승인 대기 / 실험 아직 수행되지 않음. 2026-11-03.

## 1. 가설과 시험 환경

**가설 H1:** 지원되는 ChatGPT Work 작업(호스트)이 사용자의 단일 자연어 요청을 받고, 같은 작업에서 **실제 모델 해석을 반복**해, 비공개 원본 SRT 12문맥을 분석·검증·저장·결과보고까지 수행할 수 있다. 외부 LLM API 0회, 사용자 '진행' 0회.

**대조 가설 H0:** 호스트는 파일 검사나 모델의 일회성 답변 접수만 가능하고, 미처리 문맥에 대해 자체적으로 의미 해석을 반복할 수 없다.

관찰 환경: `HOST_NAME`, `SURFACE`, `PLAN_OR_WORKSPACE`, `WORK_ENABLED`, `CLOUD_OR_LOCAL`, `GITHUB_CONNECTED`, `GOOGLE_DRIVE_CONNECTED`, `LOCAL_PRIVATE_FILE_ACCESS`, `CODE_EXECUTION_ALLOWED`, `BACKGROUND_CONTINUATION_SUPPORTED`, `PERMISSION_PAUSE`, `TIMESTAMP`, `MODEL_API_CALLS`를 실행 영수증에 기록한다. 계정 접근 권한은 이 문서의 작성 시점에 확인되지 않았으며 추정하지 않는다.

## 2. 시료 고정

- 연구 대상: 비공개 #1 영상의 **현재 미분석 문맥 12개**. v003 기존 8문맥/31주장은 원본 재현성 검사용이며 신규 연구 성과로 계산하지 않는다.
- 출처 고정: video ID, SHA-256, cue 수·시간, 12개 window ID, source packet hashes, `source_registry_sha`, v003 체크포인트 SHA를 시험 **직전** 독립 확인한다.
- 시험용 복사본: 개인 비공개 경로에 새 실험 디렉터리를 만들어 읽기 권한을 제한한다. 기존 v003 불변 파일·연구 원장과 동일한 경로에 쓰지 않는다.
- 12개 중 무작위·숫자·조건·비주장·문맥 경계를 포함한 층화표집을 고정하고 선택 사유·난이도·ASR 오탈자를 기록한다. 선택 후 재선택 금지.
- 원본 텍스트/주장 전문이 공개 GitHub, 공개 CI 로그 또는 제품 동작 기록에 유입되지 않도록 민감정보 검사를 시행한다.

## 3. 실행 프로토콜

| E0 권한 확인 | Work 접근, 필요한 파일·도구 사용, 비공개 파일 연결 가능 | 실제 사용자 계정에서 지원 | 사용 불가능 시 `NO_GO_HOST` |

**판정에 요구할 최소 증거**: 최초 요청/작업 ID, 시간순 호스트 tool invocation 집계, 신규 각 window의 원본 digest/답변 digest/접수 timestamp, 끝 상태 영수증, 파일 접근/승인 중단 사건, 코드 commit, V3 검사 로그, `MODEL_API_CALLS=0` 근거, 새 연구를 수행한 12개 문맥 목록.

## 4. 고의 장애 시험

1. 처리 4문맥 뒤 도구 호출이 실패한 경우 → 중복 접수 없이 나머지 8문맥 처리.
2. 인용을 바꿔 전체 입력 해시를 다시 계산한 가짜 패킷 → 실제 SRT 기반 재현 검사에서 거절.
3. 이미 제출된 답변의 일부 금융 의미 문장을 바꾼 낡은 감사보고 → `STALE` 판정.
4. 12문맥 중 숫자·부정·조건만 바꾼 경우 → 해당 원자 주장 격리, 무관한 다른 주장은 보존.
5. 사용자의 승인이 필요한 단계 → `PAUSED_APPROVAL` 기록, 승인 없이 작업한 것으로 간주하지 않음.
6. 브라우저/앱 인증 또는 파일 접근이 실패 → `BLOCKED_HOST` 또는 `BLOCKED_SOURCE`, 조용히 다른 출처로 대체하지 않음.

## 5. 수락 표와 의사결정

### GO — 모든 항목 필요

- [ ] 한 번의 최초 사용자 요청과 지원 호스트 작업 ID를 확인했다.
- [ ] 12/12 **새 미분석** 창을 모델이 실제로 읽고 의미 주장/비주장으로 판정했다.
- [ ] 모든 primary cue 커버리지 100%, 잘못된 인용 0, 누락 0.
- [ ] 새 불변 영수증·해시와 체크포인트·원본을 독립 재실행으로 비교했다.
- [ ] 외부 LLM API 호출 0회가 실행 기록에 나타난다.
- [ ] 사용자 '진행' 추가 요청 0회이며, 중단/재개가 정상적으로 관찰됐다.
- [ ] 미확정 금융 명제/공식자료/독립 골드가 안전하게 보류된다.
- [ ] 원본 또는 투자자 개인정보가 공용 GitHub로 전송되지 않았다.

### NO-GO — 하나라도 해당하면 해당 호스트는 탈락

- Work나 그 도구가 사용자의 계정에서 접근 불가 또는 비공개 원본을 안전하게 읽을 수 없음.
- Host가 실제 모델 해석을 다시 실행하는 반복 루프를 형성하지 못함.
- Python/Actions가 **이미 작성된 분석 답변만 재접수**하며 신규 12문맥 해석을 완료했다고 보고함.
- 사용자에게 문맥마다 `진행` 또는 재작업 시작을 요구함.
- 재개 시 원본·주장·증거 원장의 손상이나 중복이 발생함.
- 외부 API/승인 없는 인증/비공개 자료 유출 등의 금지 제약을 우회해야 함.

**조건부 판정**: 실제 한 사용자 요청이 Work에서 중단되었다가 *자동으로 지원되는 방식으로 재개 가능한 경우* `CONDITIONAL_GO`로 표시할 수 있다. 이때 U1은 충족하나 사용자 개입·승인이 반드시 필요한 상태에서는 U2 완주 보장으로 승격하지 않는다.

## 2026-11-03 P0-C/P0-R 정정 (기존 호스트 실증 제약에 우선)
- 이 문서의 Work 호스트 task ID·자동 복귀·실제 Work 사용 의무는 **선택형 P0-R**에만 적용한다.
- **필수 P0-C는 현재 Chat**에서 실제 V3 적응형 신규 12문맥을 의미 분석하고 primary cue 전수 분류, 원문 인용 대조, 비공개 불변 저장/재실행을 검증한다. 단일 요청 동안 가능한 만큼 진행하되 채팅 종료 이후 무인 실행은 약속하지 않는다.
- 합격 판정은 GO_BOUNDED_CHAT_TO_P1로 한정한다. 실전 자동 자문 승인이나 긴 연구의 전량 무중단 완료를 뜻하지 않는다.
- 2026-11-03 실전: 정확한 V3 적응형 W00009~W00020 (182 cues, 44 잠정 주장, 인용 179), 로컬 적대적·복구 시험 7건 PASS. 기존 구형 120문맥 표본의 P0 승인 근거 사용 금지.
- 기존 P0의 NO_GO_HOST 판정은 P0-R 미입증 이력으로 보존한다. P1의 정식 V3 accept 및 검증 게이트 접수는 별도 실증 필요.

## 2026-11-03 후속 최종 결정 — P0-R 필수 관문 복원
사용자가 원래 정의한 무인 연구 완주의 필수 조건을 재확인했다. P0-C GO는 유한 Chat 소프트웨어 시험의 성공만 의미하며 **P0 전체 GO 또는 P1 개발 승인으로 사용 금지**. P0-R의 실제 호스트 자체 자동 재개 실증 및 신규 12문맥 완료가 통과하기 전 **P1~P4 본격 실행·운영 개발 승인 보류**. 이전 P0-R 선택/비차단 문구와 충돌하는 부분은 [최신 P0 필수 관문 결정](V4_P0_MANDATORY_HOST_RECOVERY_GATE_20261103.md)이 우선한다. 이 내용은 이전 실험 성적을 취소하거나 실제 호스트 시험을 수행했다고 주장하지 않는다.
