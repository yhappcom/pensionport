# IRE V4 — 실전 금융 의미 분석·관계 통합·자문 검증 계획

**목적:** 소프트웨어가 도는지와 금융 사실이 맞는지를 별도 실험으로 입증. **미실행 계획**, 2026-11-03.

## 1. 검증 질문과 별도 판정

1. 원문 SRT를 완전히 읽고 원자 주장을 놓치지 않았는가? (source coverage)
2. 문장 단위 주장이 실제 발언의 조건·원인·단위·시점·부정·예외를 보존하는가? (semantic faithfulness)
3. 실제 금융 규칙/상품/수치에 대해 현재 유효한 공식 근거를 확보했는가? (external factual truth)
4. 유사 영상 간 주장 관계가 실제로 같거나 보완/충돌/기간 변경 관계인가? (cross-video relation)
5. 사용자가 자문을 물었을 때 검증된 범위의 근거만 제공하고 부적합 시 보류하는가? (advice safety)

'전수 cue 구조 검증'만으로 2~5의 답을 대신하지 않는다.

## 2. 기준 데이터와 누출 방지

- V3 v003의 #1~#5 5,129 cue, 346문맥, 8기존 제출 문맥, 338미제출 문맥을 **회귀 기준 데이터**로 사용한다.
- 기존의 source-only 15개 블라인드 태스크는 코드/대화 검사 과정에서 현재 모델이 일부 접촉했다. **동일 모델의 진정한 미노출 시험자료로 주장하지 않는다**.
- P4 단계에서 새로운 SRT 구간을 자동 *샘플링만* 하되 정답은 모델에 보이지 않는 별도 독립 평가자들이 생성한다. 표본 선정/해시/시점은 검토 전 고정한다.
- 영상별 투자·연금·세법·채권·기초생활 재무 주제 및 숫자·예외·부정·의견 사례를 층화한다. 단순 명제와 교차 문맥 인과관계(예: 연금 추납과 장래 납부)를 모두 포함한다.
- 독립 검토자 A/B는 서로 또는 모델 출력을 보지 않고 주장을 원문 cue에서 분해한다. 평가자 C는 차이 조정. 실제 평가자 신원과 독립성은 **데이터 필드만으로 검증됐다고 주장하지 않는다**. 기록/서명이 필요하다.

## 3. 재현율·정확도 계산

- gold의 원자 주장과 prediction 사이에 사전에 정의한 `meaning_match`(대상/행위/방향/숫자/단위/조건/시점/예외/불확실성)을 사용한다.
- **FN**: gold 주장이 모델 결과에 없거나 필수 조건이 빠져 실제 의미가 바뀜. **FP**: 원문에 근거하지 않는 단정 또는 범위 확대. 조건/단위 오해는 단순 텍스트 유사도가 높아도 매칭 실패.
- `Precision = TP/(TP+FP)`, `Recall = TP/(TP+FN)`, `F1 = 2PR/(P+R)`; 0 분모 규칙 명시.
- 오류 유형별 오류율과 95% 신뢰구간, 평가자 간 일치도, 샘플링 가중치, 비독립/평가자 충돌 사례를 공개 보고서에 *비식별 집계*만 포함한다.
- 목표 `Recall ≥0.95`는 **개발 가설**이지 현재 측정된 실적이 아니다. 단일 포인트 추정만 보고 합격하지 않으며 표본 크기·신뢰구간 하한과 중대 오류 발생 여부를 함께 의사 결정한다.
- 관계 탐색은 동일 candidate generation과 동일 top-K 집합에서 baseline 어휘 검색/금융 의미 검색의 Precision@1/3/5, Recall@1/3/5/10을 비교한다. 정답 관계를 만든 동일 모델이 독립 평가자가 되어선 안 된다.

## 4. 재무 공식 근거 검증

1. 공식 원문을 URL만 기록하지 않고 **원본 바이트·문서 해시·발행기관·공표일·효력일·개정이력**과 함께 저장.
2. 해당 원자 주장 인용이 실제 문서에 존재하는지, 수치와 단위가 동일한지, 적용되는 관할/계좌/소득유형/시점/대상/예외가 일치하는지 판단.
3. 조세·연금 규정 등 변경 가능 항목은 `as_of`별로 분리 저장. 2026년 규정을 과거 교육 영상 발언의 당시 법령에 소급 적용하거나 역으로 오래된 규정을 현행 사실로 사용하지 않는다.
4. 법적 효력의 별도 사람 검토가 없으면 `SOURCE_MATCHED_BUT_APPLICABILITY_PENDING`으로 분리.
5. 동일 근거의 앞뒤 문맥이 충돌하면 `EVIDENCE_CONFLICT`와 구체적 이유 기록.
6. 독립 근거 미확정이라도 영상 내용을 '영상 속 주장'으로 정리한 **연구 보고**는 가능; 자문용 검증사실로는 승격 금지.

## 5. 지식 통합의 검증 단위

모든 새 영상 주장에 이전 버전의 관련 주장 후보를 검색하되, 관계는 `SAME`, `EXTENDS`, `CONFLICTS`, `TIME_SUPERSEDED`, `DIFFERENT_SCOPE`, `UNRELATED`, `PENDING`으로 표시한다. 관계의 두 주장 각각에 원문 지문/조건/시점 증거를 보존하고 `PENDING`을 자동 동치 병합하지 않는다.

- **저장 원칙**: 주장 append-only, 조건별 판정, 관계 버전, 불변 원장 및 전후 diff.
- **삭제 금지**: 새 근거가 반증해도 원문 주장을 지우지 않고 `SUPERSEDED`나 `CONTRADICTED`를 별도 상태로 기록.
- **검색 경계**: 검증 수준을 숨긴 유사도 top-K로 개인 투자 권고 생성 불가.

## 6. 자문 적합성/안전성 평가

투자자에게 묻지 않은 사실(나이/계좌/세법상 거주/위험 성향/목표/유동성)을 임의 생성하지 않는다. 서술형 질문, 제도 설명, 적합성 부족, 현행 법령 미확정, 상충 근거, 시점 미일치, 과도한 단정 사례를 **사전 등록된 독립 시나리오**에서 시험한다.

- `ADVISORY_ELIGIBLE`은 원자 주장/근거/법령 시점/범위/상충/사용자 조건이 모두 확인된 **질문 범위에 한정**.
- 자동 투자 주문, 계좌이체, 개인 세금 신고 실행은 범위 밖.
- 핵심 점수는 유용성 외에 **근거 없는 확정 진술률, 미확정 보류율, 법령 시점 오류, 출처 추적 가능성, 중요한 위험 누락률**이다.
- 공식 검증·독립 시나리오 실패 시 자문 성능 인증은 차단하되 연구 기록 자체는 삭제하지 않는다.

## 7. 실행·완료 리포트 필수 출력

각 요청 최종 결과는 **`host_run_status` / `source_coverage` / `research_report` / `factual_approval` / `advisory_eligibility`**를 별도 표기. 항상 다음을 포함한다.

| 영역 | 필수 출력 |
|---|---|
| 실행 | task/run ID, 호스트·버전, 모델 API 호출 여부, 시작/종료/중단 원인 |
| 원본 | 영상 수·cue 수·분석 창 수·제출/미제출/UNRESOLVED, 원본 SHA |
| 명제 | 조건/의견/가정 분류, 원문 인용, 중대 단위/인과 오류, 정정 이력 |
| 사실 | 공식 원문/기준일/법적 범위, VERIFIED/OPEN/REJECTED 수 |
| 관계 | 새로 찾은 SAME/EXTENDS/CONFLICTS/TIME 등 관계 및 검증 근거 |
| 누적 | 이전 knowledge SHA, 새 SHA, 데이터 계보·diff·검증 범위 |
| 평가 | 신규 독립 골드 확보 여부, 재현율·불확실성·시나리오 시험 |
| 보안 | 원본 공개 유출 검사, 기존 원장 보존, 인가 없던 행동 차단 |
| 향후 | unresolved 목록, 법령 추가 근거, 다음 검사 조건 (필요 시) |

## 8. Go/No-Go 요약

- **P0 NO-GO:** 사용자 추가 메시지 없이 실제 모델 분석을 반복 실행할 지원 호스트가 없다 → 자동 완주 제품 발표 금지.
- **P2 NO-GO:** 한 편의 cue 전수 처리 실패, 누락을 빈 비주장으로 채움, 증빙 없는 신규 주장 승인.
- **P3 NO-GO:** 5편 모두 분석을 완료하지 않았는데 완료 선언, 누적 관계 검토 누락, 근거 없는 동치 통합.
- **P4 NO-GO:** 현재 모델에 보인 데이터를 미노출 독립 정답으로 주장, 근거 없는 세율·연금 권고를 검증된 자문으로 승격.

**인증 책임:** V4는 연구 업무를 촉진하고 검증 수단을 제공하나, 독립 검토자·공식 기관 또는 법령 효력 검토자가 행하지 않은 판정을 자동으로 대체하지 않는다.

## 2026-11-03 P0 판정 분리 주석
기존 P0 NO-GO는 지원되는 무인 호스트 루프 검증(P0-R)을 의미한다. **P0-C**는 별도로 실원본 12문맥 source-bound 구조의 유한 Chat 연구 가능성을 승인하며 GO_BOUNDED_CHAT_TO_P1로만 표기한다. 이 판정으로 실전 법령·금융 의미·자문 정확도 또는 791편 완주를 승인하지 않는다. 연구 전수 완결성과 독립 골드는 P2–P4의 별도 합격 필수 기준이다. 우선 적용 문서: [V4 P0 개정안](V4_P0_CHAT_REDESIGN_AND_SCOPED_GO_20261103.md).
