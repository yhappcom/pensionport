# 투자 연구·자문 시스템 — 단일 기준 설계 계약

기준일: 2026-11-04
상태: 설계 기준 확정안. 전체 기능 구현 또는 금융 자문 승인이라는 의미가 아님.
개발 기준 브랜치: feat/ire-v5-vertical-slice-20261103
기존 main, 기존 연구 기록, 원본 파일을 삭제하거나 덮어쓰지 않는다.

## 1. 최종 목표
수백 편의 SRT 원본 자막을 영상별로 완전하게 분석하고, 새 분석을
기존 투자 지식과 대조·통합하고, 공식 금융 근거로 검증해,
질문별 근거와 적용 조건을 갖춘 금융 자문 지식으로 재사용한다.
영상 분석 보고서 개수나 CI 통과 횟수가 최종 성과가 아니다.

기존 로스터는 791개 영상(롱폼 703, Shorts 88)이라고 기록되어 있다.
실제 보유한 700여 개 SRT의 파일 목록과 원본 해시는 아직 전수 대조되지
않았으므로 'SRT 703개 확보' 또는 '703편 분석 완료'로 표시하지 않는다.

## 2. 역할 분담
- GitHub: 원본 등록 정보, 검증 가능한 연구 프로그램, 작업 큐,
  영상별 주장 원장, 근거 원장, 통합 지식, 재검증 이력, 자문 규칙,
  상태와 변경 이력의 단일 관리 기준.
- GitHub Actions: 입력·스키마·해시·누락·참조 무결성 검사, 버전 검증,
  정적 테스트, 연구 완료 조건 검사. 금융 의미를 생성하거나 실제로
  검토하지 않은 공식 자료를 승인하지 않는다.
- ChatGPT: 실제 원본 SRT를 읽고 의미를 해석하며, 외부 공식 자료를
  검색하고, 시점·법령·조건·예외를 대조하고, 기존 주장과 충돌을
  판단하며, 근거가 확인된 구조화된 결과를 제출한다.
- 외부 언어모델 API 사용하지 않는다. 따라서 GitHub Actions 단독으로
  종료된 ChatGPT 대화의 의미 해석·웹 검색을 호출할 수 없다.
  사용자 요청이 활성화된 동안 가능한 범위에서 순차 실행하며,
  실행 한계에 도달하면 미완료 항목을 정확히 저장한다.
  이를 '한 턴에 자동 완주'로 허위 보고하지 않는다.

## 3. 강제 데이터 흐름
SOURCE_REGISTERED
  -> TRANSCRIPT_CENSUSED
  -> VIDEO_ANALYZED
  -> CLAIM_EVIDENCE_REVIEWED
  -> KNOWLEDGE_RECONCILED
  -> RESEARCH_AUDITED
  -> ADVISORY_REFERENCE_ELIGIBLE (범위·질문별로만).

(1) 원본: video_id, 파일명, SHA-256, 자막 번호·시간, 취득 출처,
    원본 확보 여부, 비투자 관련성, 오류 및 누락.
(2) 영상 분석: 자막 구간 전체 처리 판정, 원자 주장 ID, 정확한 원문
    위치·인용, 상품·행동·수치·단위·전제·예외·불확실성, 의견과
    사실의 구분, 미해결 ASR 및 문맥 경계.
(3) 근거 조사: 주장별 공식 출처 URL, 접근·조회 날짜, 원문 근거,
    규정의 시행·폐지 기간, 상품·거주지·소득 유형별 적용 범위,
    상충 자료, 검증자와 검증 수준. 검색 결과는 자동으로 사실 승인하지 않음.
(4) 지식 통합: 기존 주장과 SAME / SUPPORTS / EXTENDS / CONFLICTS /
    SUPERSEDED / DISTINCT / OPEN 관계를 기록하고, 원본 계보를 보존.
    새 영상은 이전 영상을 덮어쓰지 않으며 통합 주제·자문 색인을 갱신.
(5) 자문 활용: 질문에 필요한 기존 주장을 검색하고 현행 규정·개별
    조건을 재확인. 근거·시점·위험·추가 확인 사항을 표시. 개인별
    적용성이 확인되지 않은 주장으로 단정적인 금융 결론을 내리지 않음.

## 4. 완료 기준의 분리
- ANALYZED: 영상 전 구간이 출처 기반으로 판정됨. 사실 승인 아님.
- RESEARCH_REVIEWED: 관련 주장마다 근거·지식 관계 검토가 기록됨.
  근거 부족 항목은 OPEN으로 남길 수 있으나 UNPROCESSED와 구별.
- FACT_VERIFIED_IN_SCOPE: 공인 원문/현행 시점/적용범위 및 별도
  검증 근거가 충족된 해당 주장만 표시.
- ADVISORY_ELIGIBLE: 질문별 최신 정보·개인 적합성·위험 검토가
  충족된 범위에 한정. 전체 영상 또는 전체 지식 일괄 승인 불가.
공식 기관 웹페이지 링크만 있거나 ChatGPT 혼자 판단한 것은
독립 승인으로 간주하지 않는다.

## 5. 실행 및 중단 처리
요청 범위별 원본 확인 -> 미처리 작업 산출 -> 실제 ChatGPT 분석 및
검색 -> 원장 검증 -> GitHub 쓰기 -> 독립 재조회 -> 기존 지식 통합 ->
완료/미해결/미처리 분리 보고. 이미 처리한 영상은 변경 원인 또는
검증 보완 사유가 없으면 중복 연구하지 않는다.
'진행' 요청 시 GitHub의 마지막 확정 상태에서 이어가되,
새로 받은 사용자 메시지가 없는데도 백그라운드에서 ChatGPT가
독립적으로 계속 실행된다고 주장하지 않는다.

## 6. 저장 정책
사용자는 암호화 없는 연구 저장을 요청했다. 이 목표는 존중하되,
현재 yhappcom/pensionport가 PUBLIC인 동안 비공개 원본 자막,
개인 사례, 투자정보를 평문으로 저장하지 않는다.
직접 읽을 수 있는 연구 원장을 GitHub에 두려면 접근 통제된 비공개
저장소/영역을 먼저 확보하고 원본의 저작권 및 개인정보를 점검한다.
기존 암호화 자료는 복원 키와 내용 재검증 없이 승인된 원장으로
간주하지 않는다. 기존 Drive의 사용자 원본은 이전이 검증되기 전
삭제하지 않는다.

## 7. P0 인수 조건
A. 실제 보유 SRT 전수 목록·중복·누락·원본 해시 검증.
B. 새로운 미노출 영상 1편의 전 구간 의미 분석 및 주장 누락 점검.
C. 주장별 공식 근거·시점·적용범위 검토 결과의 재현성 확보.
D. 기존 지식 대조와 충돌·개정 반영 후 질의 재현 시험.
E. GitHub에 완전한 연구 산출물 저장 후 재조회 검증.
F. 개인별 가상 질문에 근거/예외/미확정을 구분하는 안전성 시험.
이 여섯 조건의 실제 통합 시험 전에는 연구 엔진이나 금융 자문 엔진의
정식 GO를 선언하지 않는다.
