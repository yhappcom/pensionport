# IRE V2: ChatGPT 주도 지속형 투자 지식·자문 시스템

2026-11-01. 신규 연구는 ChatGPT 현재 대화에서 분석하며 외부 모델 API를 사용하지 않는다.
기존 GitHub main 및 과거 연구 원본·원장·결론은 보존한다.

## 핵심 목표

IRE의 종착점은 1~5편 영상 보고서가 아니다. 새 영상이 추가될 때마다
기존에 축적한 **새 IRE 투자 지식**과 원자 주장 단위로 대조하고, 공식 근거와
제도 효력일·조건·예외를 반영해 통합 지식을 갱신한다. 사용자는 최종적으로
영상 수나 요약이 아니라 신뢰할 수 있는 금융 자문 근거를 활용한다.

## 사용자 한 번 요청과 처리 흐름

사용자는 “1~5편 전체 분석”, “6~10편 분석 후 기존 지식에 통합”,
“ISA 만기 자금에 대한 자문”과 같이 한 번 요청한다.

현재 ChatGPT는 해당 요청에서 다음 작업을 순차 제어한다.

1. 원본 로스터와 SRT 확보·바이트 SHA·중복 본문 검사
2. 전체 자막 문맥 해석과 원자 주장, 조건·수치·관할·예외 생성
3. 각 주요 주장에 필요한 공식 자료 웹 검색, 원문·산식·효력 시점 대조
4. 새 주장과 기존 새 IRE 주장 간 중복·보완·충돌·수치/관할/시간 변형 검색
5. 의미 관계와 근거의 신뢰 수준별 잠정 판정, 근거 불충분 항목 분리
6. 각 영상의 기존/신규 출처를 보존한 통합 주제별 지식 스냅샷 생성
7. 연구 품질 감사, 변경 내용 및 해결되지 않은 충돌을 포함한 최종 보고
8. 자문 질의라면 기준일과 투자자 조건에 맞게 공식 근거를 재조회하고 설명

**중간에 사용자에게 문맥별 JSON이나 반복적인 진행 명령을 요구하지 않는다.**
ChatGPT가 도구를 조정한다. 다만 저장소 프로그램은 ChatGPT 자체를
별도 API 없이 무인 호출할 수 없고, 채팅 실행 시간과 문맥에는 한계가 있다.
모든 대규모 배치가 반드시 한 턴에 완료된다는 보장은 불가능하다.
실패하면 원본/패킷/버전 해시로 상태를 보존하고 완료로 위장하지 않는다.

## 지식 데이터 계층

- SOURCE: 원본 영상 ID, SHA, 원문 cue 번호·시간, 본문 중복 감시.
- CLAIM: 출처 cue 직접 인용, 상품/사건/행위, 관할, 적용일, 수치/단위,
  양태(부정·가정·조건·의견), 미확정 발언 구간.
- OFFICIAL EVIDENCE: 출처 기관·정확 URL·실제 다운받은 문서 SHA,
  원문 인용, 공개일과 적용 기간, 관할·조건·예외 및 독립 검토 필요 여부.
- RELATION: 새 주장과 기존 주장의 재진술, 근거 보완, 반박,
  수치 차이, 법규 변경, 조건 차이 등의 후보와 개별 근거.
- CONCEPT: 동일 주제의 복수 영상/법령·수치·시점 기록.
  증거 없이 하나의 영구적인 규칙으로 강제 병합하지 않음.
- ADVISORY: 질문 기준일, 관할, 계좌·세금·기간·위험·유동성 조건,
  출처별 유효한 근거, 반례·충돌 및 현재 다시 확인해야 할 자료.
- AUDIT: 요청한 모든 영상의 전수 처리 여부, 출처·근거 검사,
  누적 지식 원장 부모 해시, 최종 연구 품질과 미확정 목록.

개인 원본 SRT, 상세 금융 주장과 개인 투자 조건은 GitHub에
커밋하지 않는다. 엔진 코드·형식·합성 테스트 및 비식별 통계만 공개한다.

## V2 지식 통합 및 검증 정책

현재 구현: ire/v2_run.py, ire/v2_evidence.py 및 V1 호환 저장소
ire/knowledge.py, ire/chat_bridge.py.

- 새 영상이 모두 분석돼야 배치 전체의 누적 지식 원장 반영을 허용한다.
  원본 한 편이 빠지거나 해시가 틀리거나 원문 주장이 변조되면
  지식 원장 일부만 반영해 불완전한 최신 상태를 만들지 않는다.
- 신규 글로벌 주장 ID와 기존 새 IRE 주장 ID를 비교한다.
  동일 영상 재편집·복제 자막을 이중 집계하지 않는다.
- 상품/금융 사건별 통합 주제, 법규 적용일 차이, 수치 변경,
  조건과 예외 차이를 보존한다. 신규 주장이 오래된 주장과 다르다고
  기존 기록을 삭제하지 않는다.
- 관계 검색 결과는 PENDING_SEPARATE_ADJUDICATION이다.
  검색 유사도는 금융 사실이나 의미 동일성의 증명이 아니다.
- 신규 근거 평가에서는 실제 확보한 문서의 원문 인용 존재,
  URL 도메인, 원본 바이트 SHA, 적용 기간, 5개 의미 범위를 확인한다.
  현재 채팅 모델의 지지 판정과 독립 인간 검토의 증명은 분리한다.
- 근거가 만료되거나 관할·조건이 충돌하거나 문서가 부분적이면
  자문용 사실 확정이 아닌 추가 검증 대상으로 남긴다.
- 공식기관 URL 존재만으로 법령의 현재 효력·문서 진위·주장의
  금융적 참/거짓을 승인하지 않는다.

## 완료 상태 구분

1. INCOMPLETE_REQUIRES_RESUME:
   사용자 지정 원본, 자막 구간 또는 의미 검토에 미처리 구간 존재.
   새 지식 스냅샷 반영 금지.
2. SOURCE_ANALYSIS_COMPLETE_EVIDENCE_PENDING:
   원본 전수 처리와 새/기존 지식 비교 및 누적 반영은 완료했지만
   공식자료 근거·관할·날짜·충돌에 미검증 사항이 남음.
   이 상태를 금융 사실 정확도 승인으로 표시하지 않음.
3. COMPLETE_WITH_LIMITATIONS:
   모든 중요한 미확정 사항이 검토됐거나 근거 부족의 이유를
   문서화한 연구 결과 보고서. 이 상태 역시 독립 인간
   정확도 인증이나 사용자별 금융 적합성을 뜻하지 않음.
4. ADVISORY_READY:
   질문에 필요한 현재 공식 근거, 법령·기간, 충돌 해소,
   금융상품 위험/비용, 개인 적합성 재검토가 실제로 충족된
   개별 질문 기준의 상태. 소프트웨어 단위 테스트 통과만으로 부여 불가.

## 자문 사용 시 통제

ChatGPT는 누적 지식에서 질의에 해당하는 주장과 영상 원문,
적용기간/조건 및 충돌 후보를 찾는다. 금융 사실로 사용할 부분은
해당 질문 날짜의 새 공식자료와 대조한다. 수익률 보장·세제 효과·
매매 시기·투자자 적합성이 불명확하면 확정적인 추천이나
자동 주문을 하지 않는다. 현재 개발 단계의 출력은
근거 추적이 가능한 자문용 연구 맥락이며 자동 자문 승인이 아니다.

## 기존 시스템에 대한 변경 및 마이그레이션

- 초기 영상 5편 중심 → 1~N편 지속형 누적 연구.
- 영상별 별도 보고서 → 전체 배치 검증 후 원자 지식 반영.
- 수동 문맥 제출이 실행의 중심 → ChatGPT 호스트가 과정 전체 제어.
- 원자 주장 후보의 무제한 누적 → 변경 이력과 출처를 가진 지식 원장.
- 공식 URL 목록 → 바이트/인용/날짜/관할을 가진 증거 평가 원장.
- 검색 결과만을 자문 근거처럼 제시 → 기준일·개인 조건·충돌 게이트.
- 외부 모델 API 경로는 사용자 선택에서 제외; 이전 코드·연구는
  이력과 회귀시험을 위해 보존하며 신규 기본 실행에는 사용하지 않음.

기존 260편 연구 결론은 새 엔진의 원자 주장 정답이나
골드라벨로 자동 가져오지 않는다. 독립 신규 연구를 봉인한 뒤
차이 검토 자료로만 사용할 수 있다.

## 품질 지표와 미완료 실전 검증

- 요청 원본 전수 처리율, 원문 인용 추적률, 의미 미해결 cue 수
- 공식 출처 실원문·시점·관할·조건 정확성
- 신규 대 기존 원자 주장 관계 Recall@K/충돌 검출 정확도
- 최신성 위반·오래된 법령 활용 오류율
- 금융 자문에서 검증되지 않은 주장 인용률
- 독립 검토자 기준 원자 주장 recall/precision
- 질문별 적합성 누락률과 금융 근거의 최신성

합성 시험 PASS는 실전 품질 인증이 아니다. 새 영상 전체 의미 분석,
공식자료 정확도, 영상 간 관계 블라인드 평가, 실제 자문 품질은
별도로 시험해야 한다. main과 기존 연구 파일은 변경하지 않는다.
