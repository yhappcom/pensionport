## 주요 발견과 금융규정 적용 범위

1. **사적연금 연 1,500만원:** 영상 #1 W21~W27, W30, W34, W38에서 연 1,500만원을 계좌 전체 인출금지 한도처럼 해석하거나 16.5%를 모든 인출에 직접 곱하면 오답이다. **국세청**은 일정 과세대상 사적연금소득이 해당 기준을 넘는 경우 종합과세 또는 15%(지방소득세 포함 16.5%) 분리과세의 선택을 안내한다. [국세청 연금소득](https://nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=7889&mi=6609).
2. **연금계좌 인출순서:** 2026-10-01 시행 **소득세법 시행령 §40-3**은 일부 인출에서 과세제외금액 → 이연퇴직소득 → 과세대상 납입원금·운용수익 등의 순서를 정한다. 따라서 배당분배금을 인출했다는 경제적 현금흐름과 세무상 인출재원의 귀속은 다를 수 있다. 비공제 납입원금 확인·계좌이전·공제자료 확인 필요. [법령정보센터 §40-3](https://www.law.go.kr/lsLinkCommonInfo.do?lsJoLnkSeq=1029964673).
3. **연금수령한도:** **시행령 §40-2**는 연금개시 신청 연령, 계좌 경과기간(이연퇴직소득 예외), 연금수령연차에 따른 한도 등을 별도로 규정한다. 영상의 100억원 전량 인출 예시나 월 500만원 추가 인출은 일률 16.5% 확정 세금 사례로 승인할 수 없다. [법령정보센터 §40-2](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?lsJoLnkSeq=1032953507).
4. **ISA 만기 연금전환:** 국세청은 ISA 만기잔액의 적격 연금계좌 납입 시 전환금액의 **10%·최대 300만원**만큼 추가 세액공제 한도를 적용할 수 있음을 안내한다. 영상의 5년마다 ISA 1억원을 반복 이전하는 모델은 법정 납입한도·계약·시장수익을 모두 충족하는 가정이지 실행 보증이 아니다. [국세청 연금계좌 세액공제](https://www.nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=7875&mi=6467), [ISA 관련 조세특례제한법](https://www.law.go.kr/lsLinkCommonInfo.do?lsJoLnkSeq=1033258307).
5. **고액자산 세율·ASR 혼용:** W24~W25에서 100억원의 세후 **84억6천만원**이라는 값은 **15.4%** 차감 시에만 성립하며 직전의 **16.5%** 가정을 적용하면 **83억5천만원**이다. 두 세율의 단순 산술차이는 **1억1천만원**이다. 이들은 서로 다른 과세기준에 쓰이는 수치다. 출처 음성 미확보로 자막 오류 여부는 `OPEN`으로 둔다.
6. **기대수익률 7%와 장기 적립 시뮬레이션:** 월말 적립, 월복리 `0.07/12`, 240개월 가정의 미래가치는 월 50만원 **260,463,330원**, 월 25만원 **130,231,665원**, 월 75만원 **390,694,995원**이다. 각각의 납입원금은 **120,000,000원 / 60,000,000원 / 180,000,000원**이다. 이는 시장수익 예시이지 투자 성과 보장값이 아니다.
