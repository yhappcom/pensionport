## 2. 정식 지식 승인 조건의 실행 가능 구현

검증 함수 `verify_signed_certificate`와 `review_private_signed_decisions`를 구현했다. **이론상 성공 경로도 단위시험의 임시 키로 실행**하지만 운영용 인증서나 승인 키는 생성하지 않는다.

승인에 필요한 조건:

1. 기존 97개 주장 ID·원본 cue 참조 SHA·V5 이벤트 HEAD·기존 116개 마스터의 불변성 확인.
2. 20개 규정형 주장의 **허용되는 좁은 문장** 및 각 개별 공식 추출문서의 SHA-256과 시행 버전 확인. 개인의 세금·수익률 적용은 제외.
3. 주장별 종전 지식과의 범위 관계 확인. B04 범위제한 교육용 관계 6개 유지, 다른 그룹 관계 9개는 미병합 상태 보존.
4. **서로 다른 두 명의 외부에서 신원 등록된 검증 주체**: `LEGAL_EVIDENCE_REVIEWER`와 `KNOWLEDGE_INTEGRATION_STEWARD`의 Ed25519 서명 모두 확인. 서명은 정확한 좁은 문장·cue 참조·문서 해시·기존 관계·유효기간에 바인딩된다. 자체 작성 `verified=true` 같은 값은 승인 근거가 아니다.
5. 신뢰할 수 있는 검증자 공개키 레지스트리의 SHA-256을 **별도의 권한 보유자가 사전에 검증해 외부에서 제공**해야 한다. 사용자·ChatGPT가 현재 만든 임의 키를 독립 검증자의 것으로 주장할 수 없다. 승인 인증서라도 **기존 마스터 자동 재작성·개인 투자자문은 허용하지 않는다**.

**현재 레지스트리의 승인된 외부 신뢰 앵커와 검증자 서명이 제공되지 않았으므로 실제 정식 지식 승인 0건**이다. 하지만 승인 절차 자체는 긍정·부정 검사를 갖춘 실행 가능한 코드이다. 별도 전문 검증 없이 '독립검증 완료'라고 자칭하지 않는다.

```bash

  --reviewer-registry /private/attested_reviewers.json \
  --reviewer-registry-sha256 APPROVED_OUT_OF_BAND_TRUST_ANCHOR_SHA256 \
  --decision-directory /private/dual_signed_decisions
```
