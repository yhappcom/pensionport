## 2. B04의 정확한 범위와 안전한 지식 연결

기존 `data/claims.jsonl` 116개 중 B04는 `GOMHEE-C61`~`GOMHEE-C80`이다. 기존 교육 오버레이 9개가 만드는 연결 총 15개를 정확히 분할했다.

- `GOMHEE-C66`(국민연금 다층 노후소득) 및 `GOMHEE-C78`(공제·비공제 납입원금 관리)에 연결되는 **6개 관계는 교육용 범위 한정 지식 링크로 접수**.
- C21·C24·C32·C42·C108 등 B04 이외 과거 주장에 연결되는 **9개 관계는 B04로 흡수하지 않고 다른 묶음의 관계 심사 대상으로 유지**.
- 관계 종류는 정확히 **`EXTENDS_SCOPE_NOT_EXACT_DUPLICATE`**. 원본 지식과 동치·상충 여부가 완전히 결정됐다는 주장이 아니다.

`B04_FIRST40_SCOPED_EDUCATION_EDGES_20261106.json`은 **독립적인 확장 관계 원장**으로서 B04 마스터 파일이나 역사적 116개 원장 내용·동영상 ID를 변경하지 않는다. 이 범위제한 지식 연결의 구조적 무결성은 새 게이트로 검증하지만 **정식 B04 금융사실 마스터 병합은 여전히 0건**이다.

## 3. 정식 금융 사실 승인을 별도로 차단하는 게이트 개선

`first_five_40_formal_approval_b04_gate.py`는 기존 40개 창의 주장 원장과 불변 출처, 5개 검토 판정, 7개 공식기관 URL, B04 6개 링크 및 타 묶음 9개 링크를 교차 검증한다. 다음 중 하나라도 발생하면 즉시 실패하도록 설계했다.

1. 원자 주장 ID·cue 번호·출처 SHA나 기존 116개 원장의 Git blob SHA 변경
2. 금융규정 출처가 비공식 도메인으로 바뀌거나, 2026년 종신형 세율 예외 누락
3. `FULL_CLAIM_APPROVED`, 개인 자문 또는 서명 없는 법령 본문 스냅샷이 사실 승인으로 승격
4. B04 외 주장 ID를 잘못 병합하거나 출처 영상 ID를 역사적 기록에 추가
5. 범위제한 관계를 완전 동치 또는 정식 B04 사실 마스터 병합으로 허위 표시

실제로 원본 비공개 V5 이벤트 체인에 연결하면 97개 원본 cue 링크와 40개 창을 `ResearchRun`으로 재생 가능하다. CI는 비공개 SRT에 접근하지 못하므로 **CI 자체가 원본을 다시 열었다고 주장하지 않는다**. 정식 독립 검증자 자격증명·서명 레지스트리가 준비되기 전에는, 자체 작성한 확인 플래그를 주더라도 사실 승인 시도가 차단된다.

```sh
python -m ire.v5.first_five_40_formal_approval_b04_gate --root .
python -m ire.v5.first_five_40_formal_approval_b04_gate --root . --private-root /private/private_chain_v7
```
