# IRE V5 | 40개 원본 창: 공식 증거 재현성 검사와 실제 자문 조회 경로 연결

기준일 2026-11-06. 사용자가 요청한 '연결'은 **독립 서명 승인 전, 안전한 일반 교육용 조회 경로로 연결**하는 것을 뜻한다. 승인되지 않은 금융 사실을 정식 승인하거나 116개 지식 마스터를 변경하지 않는다.

## 실제 연결된 실행 경로

```
V5 P3 질문 분석/답변(`advisory_answer_pipeline.answer`)
  → 질문 의도(일반 교육/개인 지시/수익 보장)
  → `first_five_40_retrieval_bridge.retrieve`
  → `first_five_40_official_replay_approval_gate.verify`
      → 원본 #1 40창·97개 주장 provenance (비공개 V5 event HEAD 보존)
      → 기존 마스터 116개 Git blob SHA 검증
      → 15개 국가법령정보센터/국세청/국민연금공단 추출물 원문 바이트·SHA-256 재생
      → RULE 20개 주장(기존 좁은 근거 15, 전체 발언 미승인 5) 경로 검증
      → B04 교육용 관계 6개 / 다른 묶음 9개 분리
      → 외부 검증자 서명 없으면 정식 금융 승인 0
  → 9개 범위제한 교육용 지식 중 질문과 맞는 것만 답변 부연
  → 원본 cue SHA·공식 URL·추출문서 SHA·제한 조건을 구조화해 반환
  → 기존 P1 `fact_ids` 및 개인 매수/매도 승인 상태는 불변
```

### 공개 가능한 사용 방식

```bash
python -m ire.v5.first_five_40_retrieval_bridge --root .
python -m ire.v5.first_five_40_retrieval_bridge --root . --question 'ISA 만기 연금계좌 전환 세액공제'
python -m unittest ire.v5.tests.test_first_five_40_retrieval_bridge -v
python -m ire.v5.preflight --root .
```

교육용 9개 지식군: 국민연금 추납·물가연동·지급일·연기연금, 사적연금 1,500만원 과세 기준, 금융소득 2,000만원과 사적연금 과세 구별, 비공제 원금·세액공제 기록, ISA 만기 연금전환, 연금계좌의 세법상 인출순서.

## 정책·승인 경계

- 공식 사이트 **제3자 Markdown 추출본**이며 정부 디지털서명 원본이나 법률 전문가 심사 완료가 아님. 2026-11-06 기준 법령 시행일 정보와 별도로 법령의 사후 변경을 실시간 감지하지 않음.
- 질문이 개인별 계좌 주문 또는 무조건 수익을 요구하면 관련 40창의 교육용 지식을 승인된 개인자문 자료로 돌려주지 않음.
- 9개 교육 지식은 `SCOPED_EDUCATION_CONTEXT_NOT_FORMALLY_APPROVED_FACT` 라벨과 함께 반환. **`fact_ids`에 V5 첫 40창 지식 ID를 자동 주입하지 않는다.**
- Ed25519 독립 검증자 2명의 서명과 검증된 외부 신뢰 앵커가 도입되기 전까지 정식 금융사실 승인, B04 마스터 병합, 투자 권고 모두 0건.
- 비공개 원본 SRT, 비공개 이벤트 본문, 계좌정보, 검증자 서명 비밀키는 GitHub에 업로드하지 않는다.
- 원본 #1 40/288창의 세부심사만 완료. 나머지 248창과 4,236개 미해결 cue에 대한 승인·재현성 완결을 주장하지 않는다.

## 검증 기준

1. 9개 교육노드 각각의 원본 주장 ID, cue 참조 SHA, 기존 116개 지식 후보, 공식 스냅샷 SHA를 실제로 조회 시 재검사한다.
2. B04의 C66/C78에 허용된 관계 6개만 통과하며 다른 지식 묶음의 관계 9개를 암묵적 B04 승인으로 바꾸지 않는다.
3. 사후 원문 변조, 잘못된 공식 출처 매핑, 신뢰 가능한 서명 없이 승인·마스터 변경 플래그 조작에 fail-closed.
4. 실제 P3 답변 반환값에서 정보 출처와 교육용 상태를 확인하며, 독립 금융 사실·개인 투자자문 승인 플래그는 계속 false.
5. 동일 GitHub 커밋의 전체 V5 필수검사/회귀시험 성공을 확인해야 변경 승인.

**결론:** 공식 법령 증거와 첫 40개 창의 교육용 지식을 실제 답변 생성 경로에 연결한다. *정식 지식 승인과 교육 조회 가능 상태는 구별한다.*
