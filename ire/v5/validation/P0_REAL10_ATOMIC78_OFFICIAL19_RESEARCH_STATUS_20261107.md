## 연구 증거·재현 방법

원본 자막 전문을 제외한 **파생 연구 원장**은 `private_source_derived_20261107/` 폴더에 4종 보존한다. 확장자가 `.json.zlib.b64`인 텍스트 파일을 base64 디코딩 후 zlib 압축 해제하면 일반 JSON이다.

```python
import base64, json, zlib
from pathlib import Path
p = Path("ire/v5/validation/private_source_derived_20261107/short5.json.zlib.b64")
data = json.loads(zlib.decompress(base64.b64decode(p.read_text().strip())))
print(data["candidate_count"])
```

개별 원장: `short5`(전체 Shorts 179 cue의 49개 잠정 후보), `long5`(긴 영상 18창의 29개 집중 후보), `evidence19`(원자 후보 19개에 연결된 제한적 공식 출처 검토), `long5risk`(긴 영상 354개 창의 정확한 원본 SHA-256·위험 신호·미검토 상태). 각 JSON의 원문 데이터 SHA-256을 `p0_derived_bundle_gate.py`가 고정해 검증한다. **압축 형태는 텍스트 전달·저장 편의를 위한 것이며 암호화가 아니다.** 원본 자막의 텍스트 자체는 포함하지 않는다.
