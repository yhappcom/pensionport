# V5 최종 투자 자문 답변 품질 합격 기준 V2

**제정: 2026-11-05 · 적용 대상:** `ire.v5.advisory_answer_pipeline.answer`가 실제 반환하는 한국어 **완성 답변 본문**. 단순 도메인 라우팅, 근거 URL의 존재, 자동검사 횟수만으로는 최종 합격을 선언할 수 없다.

## 1. 평가 원칙

- 답변은 **결론 → 그 판단 근거 → 조건부 계산·대안 차이 → 위험·적용 제한 → 미확인 항목** 순으로 작성한다. 질문과 직접 관련 없는 연구 주제 목록은 결론을 대체하지 않는다.
- 현재 검증된 공식 원문의 정확한 범위만 사실로 주장한다. 법령의 적용연도, 금융상품별 투자구조, 개인결정세액과 납입액을 혼동하지 않는다. 구 영상 요약을 최신 금융법령 근거로 승격하지 않는다.
- 산술은 **입력 숫자를 독립 재계산**하고 사용자에게 표시된 수치와 비교한다. 모델 내부 계산 결과와 화면의 설명이 모두 맞아야 한다. 총수익/분배금, 공제대상 납입금/환급액, %/%포인트를 분리한다.
- 개인 계좌에서의 매수·매도·주문 및 미래 수익 확정은 이 검사만으로 승인할 수 없다. 보유자산·투자목표·현금수요·세제·손실감내 정보를 갖추지 않으면 결론을 조건부로 제한한다.
- **출처 URL이 열리는지**와 **인용된 문장을 뒷받침하는지**는 별개의 검사다. CI의 링크 문자열 검사는 웹페이지가 실제로 근거를 제공한다는 독립 증거가 아니다.
- 데이터 작성자·채점자가 동일한 ChatGPT 대화이다. 이 품질 기준을 충족했다는 수치는 **독립 외부 전문가 블라인드 평가의 정확도가 아니다**.

## 2. 점수표 — 100점

| 지표 | 배점 | 합격 확인 사항 |
|---|---:|---|
| A. 결론의 직접성 | 20 | 첫 문장에 예/아니오, 비교 우위, 계산값 또는 결론 보류 사유를 먼저 제시. 시스템 내부 주제 ID를 대신 제시하면 0점 |
| B. 사실·출처·적용범위 | 25 | 직접 관련된 공식/원발행 근거에만 연결. 발행기관·문서 주소·적용조건·예외의 일치 확인. 출처 없는 사안은 미검증으로 표시 |
| C. 숫자·단위 검증 | 20 | 원자료로 독립 계산. 세액공제 계산과 환급, 한도·기간, ETF의 분배/총수익, 자산비중 %포인트를 정확히 구별 |
| D. 대안 비교·질문 해결 | 15 | 무엇이 왜 다른지, 계산상 어느 대안이 높거나 낮은지와 차이 명시. 조치 불확실성은 무조건 보류라고 표시 |
| E. 위험·예외·한계 | 10 | 인출 제약, 손실 가능성, 세금·거래비용·유동성, 미확인 개인 입력 및 적용 시점 등 질문에 필요한 조건 명시 |
| F. 행동 권고 안전성 | 10 | 투자자 승인 없는 주문·자동매도 금지, 무조건적인 수익·원금보장 주장 금지, 미검증 내용을 검증 완료로 둔갑시키지 않음 |

**합격:** 총점 **90점 이상**, 그리고 아래 차단 요인 **0건**. 높은 점수로 치명적인 결함을 상쇄할 수 없다.

## 3. 점수와 무관한 즉시 불합격(HARD FAIL)

1. 실제 질문에 답하지 않고 영역·주제 목록만 제시한 경우
2. 법규·상품 조건을 근거 없는 출처에 결부하거나, 실제 문서와 다른 발행기관·법규 내용을 제시한 경우
3. 금액·수익률·%포인트·세액공제 결과를 잘못 계산하거나, 비교 순위를 뒤집은 경우
4. 개인별 매매 주문을 실행/권고하거나, 손실 가능성이 있는 상품에 확정수익·원금 보장을 선언한 경우
5. 이전 영상 자막·연구 메타데이터를 최신 법규의 독립적 사실 검증으로 오인한 경우
6. 새로운 금융 규정이 확인된 것처럼 답했으면서 적용연도·요건·법적 예외를 검토하지 않은 경우

## 4. 평가 분리 — 반드시 모두 표시

| 데이터 | 현재 역할 | 합격률의 올바른 해석 |
|---|---|---|
| Q01~Q12 | **노출·수정된 회귀집합**. 최초 자동 구조검사 12/12이나 실제 직접 답변 8/12 | 수정 후 합격은 결함 복구 여부일 뿐 신규질문 일반화 성능 아님 |
| E01~E08 | **이미 노출된 탐색집합**. 개선 전 5/8 | 이후 성적이 오르더라도 새로운 블라인드 질문처럼 보고 금지 |
| 별도의 새 미노출 질문 | 사전 정의된 정답·근거를 잠금, 수정 전 결과 기록 | 외부 전문가 또는 독립 작성/채점이 없으면 제한적 자체검증으로 명시 |
| 실제 투자자 개인 자문 | 투자자 정보/시장 공시/현행 법규/위험적합성 | **정식 승인하지 않음** |

## 5. 본 차수에 발견한 사실 출처 오류와 정정

기존 외화RP 안내에 기재한 한국투자증권 URL은 **외화RP 자동매매 신청/해지 서비스 페이지**였으며, 예금자보호 제외·원금손실·환율위험에 대한 직접 근거가 그 페이지 본문에 없었다. 이를 공식상품 설명 근거로 잘못 사용하면 B 항목은 즉시 불합격이다.

따라서 외화RP 직접 근거를 <https://img.securities.miraeasset.com/download/pdf/hki3032n15.pdf>의 **미래에셋증권 외화RP 핵심(요약)설명서**로 교체했다. 1페이지에 원금손실·환율변동 위험과 예금자보호 제외를 명시한다. 이 출처는 해당 금융회사의 외화RP 위험 구조를 설명하는 것이지 모든 금융회사의 외화예금 보호를 확정하지 않는다.

그 외 공식 기준:
- 연금계좌 공제대상 한도·공제율: <https://g.nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=7875&mi=6596>
- ISA 만기 60일: <https://nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=7885&mi=6605>
- ETF 괴리율·NAV: <https://www.krx.co.kr/contents/OPN/01/01030203/OPN01030203T1.jsp>
- 급락 시 자산배분 리밸런싱의 일반 교육: <https://www.investor.gov/additional-resources/spotlight/formerdirectorlorischock-directors-take/it-time-rebalance-your-investment-portfolio>

## 6. 기계적 검증과 의미평가의 구분

`ire/v5/advisory_final_answer_standard.py`는 Q01~Q12 최종 본문에 점수와 하드차단을 부여하고, 세액공제·은퇴자금 부족분·ETF 총수익·비중편차를 **기존 계산 모듈과 별개의 산술식**으로 검사한다. 적대적 변조시험은 잘못된 금액, 순위 역전, 가짜 출처, 문두 결론 누락, 개인 매도 명령, 근거 없는 최신 검증 선언을 각각 불합격 처리한다.

그러나 기계 검증으로 금융상품의 숨은 계약조건·세법 예외·복합 질문 추론·고객 적합성을 완전 판정할 수는 없다. 사람이 원문과 투자조건을 독립 평가하기 전에는 `CONDITIONAL_EDUCATION_ANSWER_REVIEW_ONLY` 이상으로 승격 금지한다.
