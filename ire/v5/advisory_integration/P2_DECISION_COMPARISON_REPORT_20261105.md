# P2 — 조건부 투자 대안 비교 및 산술 판단

기준일: 2026-11-05. P0 복합 질문·P1 범위가 확인된 공식 사실을 바탕으로, 알려진 숫자만 이용해 대안을 산술 비교한다.

## 구현한 분석 4종
1. **ISA 만기 전환:** 실제 만기 후 경과 일수 60일 요건, 이전금액의 10%·최대 300만원 공제대상 한도, 가정한 소득세 공제율과 남은 결정세액 상한을 명시. 70일 경과 사례의 전환 특례를 자동 승인하지 않는다. 계좌 유동성·인출제약은 별도 미계량 위험.
2. **은퇴 현금흐름:** 월 필수 지출에서 연금 및 기타 현금수입을 공제하고 부족분·연환산을 계산. 목표 투자원금은 수익률·기간 자료가 없어 계산하지 않는다.
3. **ETF 세전 총수익:** 최초 가치, 기말 시장가치, 현금 분배, 가격에 미포함된 외부비용으로 비교. 운용보수가 이미 NAV에 반영된 경우 중복 차감 방지, 분배율과 총수익률 구분.
4. **목표 자산비중 편차:** 실제 주식비중과 목표비중의 %포인트 차이. 필요한 매도금액·과세·리밸런싱 제약을 가정하지 않는다.

## 검증과 한계
- 5개 합성 비교 사례에서 결과와 위험 제한 규칙을 실행해 확인하며 출처 없는 ISA 세제 산식은 차단.
- 모든 결과가 `TRADEOFF_ONLY_NOT_PERSONAL_ACTION`이고 개인별 매수·매도, 장래 수익률 보장을 승인하지 않음.
- 모든 재무 모델을 완성한 것이 아니라 **4개 시나리오용 결정 엔진 슬라이스**다. 실제 투자자 상황의 적합성 검증과 대안별 현금흐름/세금/시장가격은 현재 채팅의 추가 질문·검색이 필요.
- CI는 숫자·입력조건·출처 ID를 검증하지만 독립 정답시험이나 시장예측 품질은 인증하지 않는다.
