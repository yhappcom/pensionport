# IRE V5 기존 60건 → 자문 의사결정 지원 통합

**기준 2026-11-05.** 범위는 기존 `data/claims.jsonl` 116건 중 B01~B03에서 정리한 **C01~C60 60건**. 기존 13개 교육 지식 노드는 별도 유지한다. 원본 주장·법규 근거 파일·V5 승인 그래프는 변경하지 않는다.

## 실제 구현

- `advisory60.py`: 사용자 자유형 질문을 15개 결정 영역에 연결하며, 해당 영역의 원장 주장 ID·원본 영상 ID·검증 상태·과거 검토 교육 지식·확인 질문·위험 제한을 함께 내보낸다. 기존 `advisory_replay.py`의 고정 답변을 재생하는 방식과 다르다.
- `advisory_integration/decision_routes_20261105.json`: 60/60 주장 커버리지, 한 주장이 여러 영역을 보완할 수 있되 **새 금융 사실 승인 0건**. 주제 유사성과 동일 법적 근거를 혼동하지 않는다.
- `advisory_integration/question_scenarios_20261105.json`: 국내 투자자에게 자연스러운 20개 질문과 예상 주제 ID. **ChatGPT가 만든 시험문제**이며 외부 독립 정답/모델 금융자문 정답률이 아님.
- `tests/test_advisory60.py`: 계좌 세제 오연결, 8% 인출률, 자산배분/DCA 혼동, 원금보장·개인 매수지시, 가짜 출처·누락 원장, 최신 사실 허위승인 방어.
- 기존 `preflight.py`, `one_turn_run.py`에도 필수 검증 및 결과 기록 단계 추가.

## 실제 자문에 연결되는 구조

**질문 → 상황/영역 판별 → 기존 주장·영상 추적 → 일반 의사결정 틀 → 사전에 필요한 조건 확인 → 이전 검증 교육 지식(시간 제한 표시) → 위험/미확정 항목 → 실제 근거 최신 대조**.

다음 영역을 구분한다: 연금저축 세액공제, IRP·퇴직연금, 은퇴 인출, 은퇴재무설계, ISA 만기/연금전환, ISA 해외배당 과세, 일반 금융세제, ETF 구조·비용, 자산배분, CMA, 통화 노출, 채권, 파생·원자재, 시장 급락, 투자자 행동·기록.

**부정합 관계 차단:**
1. C33 ISA 해외배당 과세 ≠ ISA 연금전환
2. C42 비공제 연금원금 ≠ ISA 전환공제 또는 연금 1,500만원 기준
3. C52 자산배분 ≠ 정액적립 단가 산술
4. C26 테마 집중위험 ≠ ETF 괴리율/추적오차 개별 숫자

이 단계는 과거 그래프 링크를 파괴하지 않고, 유관 문맥과 **직접 인과/법규 증명**의 차이를 실행 결과에 표시한다.

## 검증 및 한계

- 정리 지식 60건의 source provenance 연결 및 전주제 라우팅 15개.
- 20개 질의 시나리오로 **분류·문맥 연결**을 검사하며, 개인행동 지시/확정수익 약속 등 별도 적대적 질문을 차단한다.
- 기존 신뢰도 `high`가 현재 공식자료 검증으로 자동 승격되지 않는다. 모든 반환 결과는 `current_financial_rule_live_verified=false`, `personal_action_approved=false`로 고정된다.
- **이것은 자문 전단계 베타 — 의사결정 지원 지식검색 기능**이다. 새로운 질문에 대한 생성형 답변의 금융 정답률, 실제 개인별 적합성, 최신 법률 조문 적용, 예상 투자성과를 측정한 결과가 아니다.
- 실제 개인별 재무 판단에 적용할 때는 채팅에서 공식 규정·상품 공시와 개인 소득/현금흐름·계좌/세제 조건을 다시 대조한다.

## 실사용 예시 명령

`python -m ire.v5.advisory60 --root . --question "ISA 만기자금 연금전환 절차는 어떻게 되나요"`

`python -m ire.v5.advisory60 --root . --question "커버드콜 8% 인출률은 안전한가요"`

`python -m ire.v5.advisory60 --root . --question "내 포트폴리오 목표비중 추천해줘" --intent personal_action`

`python -m ire.v5.advisory60 --root .` (전체 60건·20문항 안전검증).
