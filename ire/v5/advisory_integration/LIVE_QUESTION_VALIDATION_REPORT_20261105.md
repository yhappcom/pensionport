## 1. 기존 질문의 과적합 확인

| 검증집합 | 초기 / 변경 전 | 키워드·안전경계 수정 후 | 해석 |
|---|---:|---:|---|
| 기존 개발 시나리오 | 20/20 | 20/20 | 사전 제작 질문, 일반화의 근거가 아님 |
| **처음 제시한 문제 발견 질문** | **11/20(55%)** | **20/20(100%)** | 수정 과정에서 참조한 질문이므로 최종 독립 성능지표 아님 |
| **추가로 구성한 비튜닝 질문** | 미실시 | **12/16(75%)** | 실제 질문 표현 다양성에 대한 추가 평가; 네 가지 미해결 문제 남음 |

실행은 정적 응답 재생이 아닌 `ire.v5.advisory60.resolve`의 **실제 질문→지식 라우팅**이다. 그러나 여기서의 합격은 올바른 `route_id`를 선택했다는 의미이며, 무제한 신규 자연어 질문에 대한 생성형 자문 정답률은 측정되지 않았다. ChatGPT가 스스로 작성한 기대 정답이므로 독립 블라인드 정답/검사로 주장하지 않는다.

## 4. 공식자료 내용과 15건 좁은 답변 대조

현재 채팅에서 직접 확인한 16개 공식/원발행 금융상품 출처를 `CHAT_FACT_CHECK_20261105.json`에 URL, 관찰일, 주장 적용범위로 기록. 그중 15개 질문에 대해 ChatGPT가 직접 작성한 좁은 답변을 근거 범위와 대조했다. 이는 **모델 본인이 작성한 답변의 정합성 확인**이며 외부 인간의 독립 정답 검증, 원본 SRT 전수 확인, immutable 법령 웹페이지 스냅샷은 아니다. GitHub CI는 이 링크의 호스트·출처 ID·답변 요건을 검사할 뿐 웹페이지 본문을 다시 열어 사실성을 인증하지 않는다.

| 주제 | 근거 | 제한 |
|---|---|---|
| 연금저축 세액공제 600 / IRP 포함 900만원 | 국세청 연말정산 안내 | 대상 납입한도와 환급세액은 다름, 공제율/결정세액 확인 |
| ISA 만기→연금계좌 이전 60일 | 국세청 연금계좌 납입 안내 | 70일 지난 이전의 추가 공제 자동승인 금지 |
| ISA 및 국내 설정 해외 펀드 외국납부세액 | **2026년 국세청 펀드 외국납부세액 안내** | ISA 만기·중도해지, 종합과세 여부, 해외상장 ETF와 차이 |
| 사적연금 연 1500만원 초과 | 국세청 사적연금소득 | 해당 소득원천의 과세선택, 모든 연금에 일괄 적용 금지 |
| 국민연금 연기 0.6%/월 | 국민연금공단 | 연기 기간 수급 포기, 타 사회보장·건보료 영향 |
| ETF NAV/괴리율/추적오차·분배 | 한국거래소 | 분배율과 총수익 차이, 공시 시점과 지수·시가 구분 |
| 엔화노출 미국주식 ETF | 거래소 KIND 개별상품 공시 | 통화노출·환헤지 실제 상품 구조마다 다름 |
| 자산배분·채권 | 미국 SEC 투자자교육 | 개별 매도·매수 승인 금지 |
| CMA RP형 | 해당 증권사 공식 상품설명 | 예금자보호와 투자위험은 상품별 구분 |
| ELS knock-in | 금융위원회 ELS 설명 | 녹인 즉시 전액손실 아님; 만기 손실·발행사 위험 존재 |

**계산 5건 별도 재현:**
1. 합산 세액공제대상 납입 900만원 × 소득세 15% = **135만원**(국세·충족 조건 가정, 환급 자동 보장 아님).
2. 월 은퇴생활비 300만원 − 공적연금 120만원 = **월 180만원 부족**(세전·기타수입/비용 미반영).
3. 주식 목표 60%에서 실제 75% = **+15%포인트 편차**.
4. 채권 액면 100만원, 매입가 98만원, 쿠폰 연 3%, **정확히 1년 후 만기 상환**이라면 단순 총수익률 (3만원+2만원)/98만원≈**5.102%**(신용·수수료·세금 제외; 일반 만기수익률로 단정 금지).
5. 월 분배액 80만원×12 = **연 960만원 현금 분배액**(총수익률·수익 보장 아님).

## 5. 남은 16문항 중 실패 4건

- **H03 ISA 만기→연금 이체**: ISA 전환보다 연금저축 세액공제 루트로 우선 분류.
- **H07 은퇴생활비 부족분**: 질문이 은퇴 현금흐름임에도 어떤 루트에도 연결하지 못함.
- **H09 외화예금과 달러RP**: 통화 목적/환위험과 신용/유동성 두 영역이 동시에 필요한데 CMA로 단일 분류.
- **H12 서킷브레이커와 목표비중**: 시장 급락 대응과 자산배분이 혼합된 질문에서 자산배분 우선으로 분류.

이 네 건은 결과를 정확히 기록하고 **아직 수정하지 않는다**. 해당 holdout을 고쳐 다시 16/16이라고 보고하면 실제 미노출 평가 의미가 사라지기 때문이다. 후속에는 **복수 도메인 우선순위/모호성 표시**, 동의어 검색, 질문별 동적 공식근거 탐색을 별도 데이터로 검증해야 한다.
