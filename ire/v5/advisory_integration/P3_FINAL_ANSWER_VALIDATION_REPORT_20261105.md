# P3 실제 최종답변 검증 (2026-11-05)

현재 채팅에서 이전 GitHub CI가 생성한 한국어 최종답변 Q01~Q12의 전체 내용을 직접 확인했다. 기존 12/12는 영역·출처·계산·위험·안전성 필드의 구조 검사에 불과했다.

## 실제 오류 확인
- 직접적인 질문 답변 충분성: 기존 8/12.
- Q05: 괴리율과 추적오차의 우선 점검 순서가 없음.
- Q07: ETF alpha 2.00%와 beta 3.50%를 계산하고도 더 높은 대안 및 1.50%포인트 차이를 명시하지 않음.
- Q09: 서킷브레이커가 전량매도 신호인지에 대해 직접 답하지 않음.
- Q10: 달러예금·외화RP의 신용위험, 환율위험, 예금보험 차이를 제시하지 않음.
- Q12의 CMA 수익보장 부정에는 해당 상품의 예금보호 근거가 부족했음.

## 실제 보완
- P3 자연어 답변은 첫 문장에서 금액/판단·비교 또는 근거부족을 직접 제시한다.
- P1 원자사실 6건에 발행자별 외화RP, 증권사 CMA, SEC의 일반 시장급락 리밸런싱 지침 3건을 추가한다.

## 방법상 제약
기존 12개 질문은 이미 수정에 사용했으므로 회귀 테스트다. 새로 작성한 8개 탐색 질문의 실패는 수정하지 않고 별도 공개한다. 모두 동일 채팅 모델이 검사한 결과이지 독립 전문가 블라인드 평가가 아니다. 최종 CI는 외부 공식 페이지 내용을 매번 새로 확인하지 않는다. 거래 실행, 개인 포트폴리오 권고, 수익보장은 승인하지 않는다.
