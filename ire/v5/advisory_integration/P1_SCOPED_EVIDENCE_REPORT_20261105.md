# P1 — 원자 금융 사실과 공식자료 결합

기준일: 2026-11-05. P0 복수 의미영역 후보와 금융 사실 원장 `P1_ATOMIC_SOURCE_FACTS_20261105.json`을 연결한다.

## 구현 범위
- 실제 공식 페이지에 범위를 맞춰 확인한 6개 원자 사실: 연금 세액공제 납입 한도/공제율, ISA 만기 60일, ISA 만기 전환 10%·최대 300만원 추가 공제대상 납입한도, 국내 설정 해외투자 펀드 외국납부세액, ETF 시장가격/NAV/추적오차.
- 이 사실은 **60건 연구 문서 중 60건을 신규 법률 사실로 인증한 결과가 아님**. 원본 지식은 기존 학습/원천 출처로만 보존하고, 법규·상품 사실은 질문 범위와 공식 출처가 직접 일치할 때만 제한적 설명에 활용.
- C33의 외국납부세액과 ISA 연금전환, C42의 비공제 원금과 연금세제, C52의 자산배분과 DCA 산술, C26 테마 ETF와 NAV/추적오차의 **오연결 5개를 직접 금융 사실 근거로 쓰지 않도록 차단**.
- URL, 발행기관, 적용 시점, 필수 개인 입력조건, 예외, 공식자료 페이지 재검증 필요 상태를 함께 반환.

## 범위와 판정
현재 채팅에서 국세청·한국거래소의 공식 원문을 직접 읽어 6개 좁은 사실을 기록. GitHub 테스트는 URL/근거 구조·조건·차단 관계를 검사하되 **외부 공식페이지 본문을 재확인하거나 원본 전체 SRT를 재검증하지 않음**.

P1 기능 구현·CI 통과는 완료 가능한 기술 단계이며, 투자자 개인별 세율/신고·시점/규정 전체 판정은 해당 질문마다 채팅 검색과 조건 검증이 추가로 필요하다. 본 단계에서 매매 또는 투자비중 추천 승인 0건.
