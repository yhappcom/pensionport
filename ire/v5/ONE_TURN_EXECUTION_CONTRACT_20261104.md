# IRE V5 단일 사용자 요청 완결 계약 (2026-11-04)

## 목적
사용자가 `진행` 메시지를 반복 전송하지 않아도, 현재 요청에서 지정한 **유한한 영상·주장 집합**을 GitHub 상태·ChatGPT 의미분석·공식자료 검색·대조·중복통합·테스트·결과보고까지 가능한 범위에서 끝낸다.

## 단일 요청 실행 단계
1. **인수:** 기존 원장·원본 SRT 해시·미승인 주장·기존 평가를 ID로 재조회해 중복·누락 방지.
2. **의미분석:** 활성 ChatGPT 채팅에서 관련 원본 SRT cue를 읽고 해석한다. 외부 모델 API는 사용하지 않는다.
3. **공식기관 근거:** 법령 시행일과 추진안, 다른 나라 투자교육 자료와 대한민국 세법/상품 규정을 구분한다.
4. **재판정:** 원자 주장마다 제한적 공개교육에 쓸 수 있는 사실, 금융회사/상품별 미확인 사항, 고객 정보 미확보로 거부해야 하는 행동, 숫자·ASR의 불확실성을 정리한다.
5. **중복 통합:** 다른 영상의 동일 지식은 새 원장을 무한히 추가하지 않고 기존 ID에 출처 링크만 추가한다. 상충하는 내용은 승인 원장 변경 대신 경고와 조건을 추가한다.
6. **일괄 검증:** `python -m ire.v5.one_turn_run --root .`를 호출하여 기존 V5 모든 게이트·회귀시험과 단일 요청 종료판정 확인.
7. **종료 보고:** 재현 가능한 수치, 비승인 이유, GitHub commit/CI 실측값과 남은 외부 증빙을 제시. 다음 `진행` 요청을 필수로 만들지 않는다.

## 이번 실제 범위
- 2026-11-04 신규 5편 잠정 주장 **53개** 중 기존 집중 검토 9, 이번 추가 검토 33, 과거/비투자/위험 차단 11; 분류 누락 0.
- 이번 33개: 법령 7, 상품/회사 7, 개인 적합성 5, 산술/ASR 2, 독립 발행기관 자료 확인 교육 후보 12.
- 기존 교육 지식 4개와 교차 대조하여 신규 중복 제거 후보 9개, 누적 잠정 교육 지식 주제 13개.
- 사용자가 제공한 비공개 원본 ZIP에서 **33개 구간별 SHA256 정합성** 재검토. GitHub CI에는 원본 SRT 전문을 공개 업로드하지 않는다.
- 단순 테스트 성공을 외부 심사나 개인 투자자문 승격으로 취급하지 않는다.

## 결함 및 증거 부족에 대한 종료 규칙
- **외부 개인 정보 부재:** 특정 투자자에게 '매수/해지/계좌전환/세금 확정' 명령은 **거부한 상태로 이번 요청 완료**한다. 후속 자료를 무기한 기다리거나 자동 승인하지 않는다.
- **원본 음성 부재:** 비공개 SRT의 숫자 산술과 문맥은 검증하되 음성 오류 판정은 **별도 보류**. 오디오가 없으면 있는 척하지 않는다.
- **인간 독립 블라인드 판정 부재:** 외부 기관 자료 두 곳 이상을 대조했더라도 독립 검토자로 승인받았다는 뜻은 아니다. 판정자 독립성 0으로 기록하고 정식 자문 승격은 차단한다.
- **정책 변경:** 발표와 시행 법률/규정을 별도로 기록한다. 날짜·대상 불확정 상품은 개인 권고를 차단한다.
- **도구 실패:** 현재 턴 내 가능한 재시도·복구·결함수정·CI 재검증을 완료하고, 그 후에도 불가능한 항목은 정확한 원인을 가진 TERMINAL_BLOCKED 상태로 종료한다. 반복 `진행` 명령을 요구하지 않는다.

## 구현·실제 동작 경계
- GitHub Actions는 금융 원본을 자동으로 '이해'하거나 현재 ChatGPT 채팅을 네트워크로 호출하지 않는다. 채팅 내 모델 추론·웹 검색은 채팅이 실행할 때만 가능하다.
- `ire/v5/one_turn_run.py`는 단일 명령으로 모든 **결정적** 검증을 실행하고 `ONE_TURN_RESEARCH_RECEIPT`를 한 번 발행한다.
- CI에서는 비공개 SRT를 받지 않는 검증을 수행하므로 영수증에 `private_original_archive_verified_in_this_process=false`로 기록한다. 비공개 SRT가 로컬에 있는 경우에만 `--private-zip` 경로로 실원본을 검사한다.
- 이 엔진은 의미판단의 '채팅 한 턴 전자동 재호출'을 보장하는 독립 LLM 엔진이 아니다. 외부 API 없이 완전자율 추론을 실현했다고 주장하지 않는다.

## 규제 및 안전 경계
- 공개 교육 원칙과 특정 개인·상품에 대한 금융투자 자문을 분리한다.
- 법령·납부세액·소득·상품·적합성 데이터와 독립 감사가 없는 상태에서 `formal_personal_investment_advice_authorized`는 **false**.
- 이 제한을 넘기는 변경은 기존 CI에서 실패하게 유지한다.
