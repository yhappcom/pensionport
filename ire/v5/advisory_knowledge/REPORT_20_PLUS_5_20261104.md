# V5 자문 지식 전환·신규 영상 통합 20+5 개발 보고 (2026-11-04)

## 목적과 평가 범위
이미 누적된 `data/claims.jsonl` 116개 주장 중 20건을 금융자문용 지식 후보 구조로 정리하고, 향후 신규 영상 5편의 원본을 같은 지식 원장과 연결할 수 있는지 검증한다. 영상 분석·지식 자문 승인을 **서로 다른 상태**로 유지한다.

이 보고서는 외부 LLM API 없이 ChatGPT가 공식기관의 공개자료를 검색한 결과와 GitHub 원장을 연결한 개발 시험이다. **독립 블라인드 검증, 5편의 실제 SRT 의미 분석 완료, 개인 투자자문 승인을 뜻하지 않는다.**

## 1. 기존 20건의 연구 전환
분야별 4건씩 원본 주장과 뒷받침 영상 ID를 기존 원장과 문자 단위로 대조하는 구조.

| 분야 | 원장 주장 ID |
| --- | --- |
| ISA | GOMHEE-C13, C32, C33, C109 |
| 연금저축 | GOMHEE-C07, C28, C42, C71 |
| IRP | GOMHEE-C08, C43, C73, C80 |
| ETF | GOMHEE-C06, C26, C97, C110 |
| 자산배분 | GOMHEE-C09, C23, C52, C75 |

`core20_candidates_20261104.json`에 (1) 기존 주장 원문·원본 영상 ID,
(2) 검토한 공식자료 후보, (3) 적용조건·예외·검증 부족 사항,
(4) 계보와 지식 승인 상태를 분리 기록한다. **공식자료 출처 후보 11개,
주장-근거 후보 연결 33개**이며, ChatGPT 검토자료의 원문 스냅샷과
독립 심사 결과가 없어 **승인 금융사실 0개**로 유지한다.

### 구체적 개선 사항
- ISA: **계좌 내 손익통산과 계좌 밖 손실 혼동 금지**, 비과세 200만원/특정
  가입유형 400만원 구분. 2024년 등의 발표안과 2026년 시행 법령 분리.
  해외 원천세 처리와 개인 유형은 별도 검증 대기.
- 연금저축: 세액공제 한도 600만원, 퇴직연금 포함 900만원과 납입·투자
  실행 및 실제 납부세액 구분. 월세공제 등 중첩 효과는 개인별 확인.
- IRP: 시행령 제18조의 중도인출 법정 사유, 계좌별 제약을 명시.
  **2026년 10월 고용노동부 위험자산 70% 한도 완화 발표는 추진 단계이므로
  현행 변경법으로 승인 불가.**
- ETF: 분산/추적오차/비용/호가, 특정 업종 집중과 배당률-총수익 구분.
  ETF 매매제도와 시간외종가 예외는 현행 거래소 자료 확인.
- 자산배분: 자산군 분산, 목표비중, 리밸런싱과 비용·위험 감내 구분.
  미국 투자자 교육자료는 **한국 계좌·세법의 증거로 사용하지 않음**.

## 3. 자동검사
`python -m ire.v5.knowledge_stage --root .` 및
`ire/v5/tests/test_advisory_knowledge_gate.py`에서 다음 오류를 차단한다.

1. 과거 주장 텍스트/영상 출처 변경·기존 Git blob 원본과 불일치
2. 잘못된 공식기관 도메인, 근거 참조 누락, 조건·예외 누락
3. 정책 발표를 시행법으로 잘못 표기
4. 금융 사실 또는 개인별 매수 판단의 무근거 승인
5. 기존 연구가 있는 영상을 신규 대상으로 재등록
6. 원본 SRT 해시·로스터 ID를 바꿔치기
7. 미분석 5편을 분석·지식 병합 완료라고 허위 보고
8. ISA 영상에 ETF 핵심 주장을 자동 병합하는 등 주제 혼동

테스트 통과는 **계약과 원본 ID 무결성**의 검증이며, 금융 사실의
독립적 정확성 검증을 대체하지 않는다.
