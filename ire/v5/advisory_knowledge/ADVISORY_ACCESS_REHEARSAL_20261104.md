## 1. 검증 목적

## 4. 실제 구현과 한계
- `ire/v5/advisory_education_rehearsal.py`: 원본 5편 `studies/*.json` 53개 claim ID를 전부 읽고, 검증된 13개 통합 지식의 17개 출처와 매칭.
- `python -m ire.v5.advisory_education_rehearsal --root .`: 전체 53개에 대해 일반 교육 접근 및 개인별 조치 차단을 확인.
- `python -m ire.v5.advisory_education_rehearsal --root . --claim-id I255-03 --intent general_education`: 원본 주장 ID로 한정된 설명·예외·공식자료 URL을 반환.
- `python -m ire.v5.advisory_education_rehearsal --root . --claim-id I255-03 --intent personal_action`: 자문 승인 거부와 확인해야 할 고객 정보 범주 반환.
- `python -m ire.v5.one_turn_run --root .`: 모든 이전 연구 검수 단계, 통합 지식검수와 **53개 전수 사용성 안전 모의검사**를 한 번에 수행하고 종료 영수증 발급.
- **현재 ChatGPT 대화가 종료된 뒤 GitHub 코드가 ChatGPT 자연어 분석·검색을 스스로 실행하지는 않는다.** 외부 API 없이 구현할 수 있는 것은 원본·근거·검증 결과 상태관리 및 결정적 안전 게이트다. 실제 신규 영상 의미 분석과 공식자료 검색은 사용자가 지정한 활성 ChatGPT 요청이 담당한다.
- 독립 블라인드 기준자료, 실제 고객 적합성, 국내 세법 시행일 봉인, 제품명·종목코드 현재 공시가 없는 단계에서 금융자문 운영 승인은 허용하지 않는다.
