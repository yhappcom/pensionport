# V5 #1 영상 핵심 64건 — 3차 증거·문맥 검토 실증

기준일: 2026-11-04 (Asia/Seoul). 외부 언어모델 API 사용하지 않음.

## 수행한 내용

이전의 67/67문맥·81개 잠정 원자 주장·원본 11개 불변 영수증, 182건 위험 분류 3개 영수증, 기존 지식 충돌 13건 재판정 1개 영수증을 **모두 그대로 유지**하고, 실질 검토 우선순위 64건을 별도 3차 원장으로 접수했다.

| 위험 유형 | 대상 | 새 실제 판정 | 본 단계에서 잔존 |
|---|---:|---|---:|
| 자막 문장 경계(B) | 35 | 20건은 정확한 앞뒤 원문 연결과 기존 원자주장 조건을 재확인(문맥 범위만 조건부 해소) | 15 |
| 숫자/ASR(N) | 8 | 8건 모두 원문·주변 조건 재검토. 독립 음성·공개 전사 부재로 수치 확정 보류 | 8 |
| 공식 금융규정(E) | 21 | 20건 공식기관 설명 **원문 일부의 근거 후보를 주장별 연결**, 1건은 기존 자료만으로 특정 세율 주장 뒷받침 불충분 | 21 |
| **합계** | **64** | **64건 새 검토 기록** | **44** |

기존 112건 중 본 단계에서 해소한 것은 **문맥 연결 위험 20건에 한정**한다. 분류 결과 **92건이 남았으며**, 여기에는 이번 우선순위 이외의 개인별 시나리오 48건도 포함한다. 금융 사실의 독립 승인 **0건**, 투자 자문 승인 **0건**이다. 문맥 연결 확인은 법령·수치의 사실승인과 다르다.

## 시스템 검증 및 영속성

- 64개 개별 판정은 원본 자막 구간 및 이전 검토 이벤트 해시가 일치해야 접수되며 3개 추가 사건으로 해시 연결했다.
- 4단계 원장(원본 11 + 위험 분류 3 + 지식 관계 1 + 이번 3건)을 하나의 AES-256-GCM 암호화 패키지로 저장했다. 복구키는 암호화 파일과 분리했다.
- **독립 저장 경로 복원 성공:** 4개 원장 해시, 64개 판정, 잔여 92건 일치. 잘못된 키 및 암호문 변조 복원 거부.
- 로컬 엔진 회귀시험 138건: **135 PASS, 기존 비공개 fixture 3 SKIP**. GitHub 앱 회귀시험 37건: **37 PASS**.
- 신규 검증기에는 허위 금융 승인, 원본 인용 위조, 기계적 승인, 다른 공식 도메인 사칭을 거부하는 테스트 포함.
- 원본 비공개 SRT, 64건 자막 발췌, 금융 사용자 사례 데이터, 복구키는 GitHub 공개 브랜치에 추가하지 않는다. `main` 및 과거 V3/V4 원장 불변.

## 최종 판정

**단일 사용자 턴 안에 핵심 64건의 3차 검토·영수증 생성·독립 재생까지 수행: PASS (조건부 위험심사).**

**64건 중 금융 사실 독립 승인이 64건이라는 의미는 아니다.** 맥락 20건 조건부 해소, 나머지 핵심 44건 OPEN. 개인별 사례 48건을 포함해 전체 잔여 92건. 이 92건은 독립 전사·시행 법령·계좌 원장 등이 필요하므로 이번 작업에서 모두 해소하지 못했다.

**정식 자문 엔진 금융 검증 승인 NO-GO**. 후속 실증은 8개 ASR 원음 확보, 21개 공식 규정의 유효시점·계좌별 적용 범위, 9개 실질 경계 위험을 우선 처리해야 한다.
