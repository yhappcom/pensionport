# IRE V5 P0 — 범용 자막 분석·의미 누락 점검 구조 개선 (2026-11-07)

## 원인과 변경 범위

- 기존 `ResearchRun.packet()`이 원자 주장 인용에 필요한 주요 자막만 전달하여, 창 경계 전후의 질문/답변·조건·반례 문맥을 모델에 노출하지 못했다.
- cue 1개에 claim 1개가 연결된 사실만으로 다른 원자 명제가 모두 회수됐다고 단정할 수 없다.
- 4~5편 전용 배치 스케줄러만으로 신규 영상 단편 또는 10~20편 공통 처리를 표현하기 어려웠다.
- 전용 LLM API를 사용하지 않으므로 Python/GitHub Actions가 실제 채팅 모델을 재호출할 수 없다.

## 구현

1. `p0_semantic_coverage.contextual_packet()`: 0~8개 좌우 원문 cue를 **인용 불가능한 문맥 전용**으로 표시하고, 경계 연결 검토 플래그를 노출한다. 기존 `packet_sha256`과 이전 영수증은 변경하지 않는다.
2. `p0_semantic_coverage.audit_second_pass()`: 실제 채팅에서 작성한 별도 의미 단위(second-pass)를 원문과 교차검사한다. 하나의 cue에 복수 원자 단위를 허용한다. 누락 주장·미분류 cue·기존 주장 재확인 누락·원문 위조는 각각 차단 또는 검토 대상으로 보고한다. 단순 단어 탐지만으로 의미 완전성을 자동 승인하지 않는다.
3. `p0_generic_runner.GenericResearchCohort`: 기존 `ResearchRun` 원장 위에서 **1~20편**을 공통 처리하고, 원본·계획은 비공개 로컬 폴더에 불변으로 보관한다. 중단 뒤 원본을 다시 열어 상태를 복원할 수 있다. 모델 추론/웹검색은 현재 ChatGPT가 수행한다.
4. 기존 4~5편 경로 `FiveVideoResearchBatch.next_source_bundle()`도 문맥 패킷을 함께 전송한다. 모델 응답은 기존 primary packet을 인용한다.
5. `test_p0_generic_semantic.py`: 경계 문맥·원문 SHA 보존·복합 명제·누락 탐지·오염·복구·복수 입력의 합성 회귀시험.

## 완료로 주장하지 않는 항목

- 실제 #1~#10 원본에서 새 2차 전수 심사 실행 또는 금융 주장 누락률 산출
- 외부 독립 골드 기준 원자 주장 회수율, 791편 전편 자동 분석, 한 채팅 턴의 무중단 무인 처리
- 116개 기존 마스터 승인, P4 29개 교육 노드 변경, 개인별 매매/세무 판단 승인

**합격 게이트 제안:** 새로운 미검토 SRT 10~20편을 이 공통 실행기에 넣고, 매 창 1차 분석 → 별도 2차 의미 단위 → 누락 재판정 → 공식 근거·지식 관계를 실측한 뒤 V5 처리량 GO 여부를 결정한다. CI 통과와 실제 원자 주장 연구 품질 인증은 별도이다.
