# V5 실제 자문 질문의 근거 재현·차단 실증 (2026-11-04)

## 범위와 성격

**입증 대상:** GitHub의 기존 통합 주장 116건 + 신규 V5 #212 ETF 연구의 미승인 주장 10건을 활용하여
가상 투자자 질문에서 필요한 지식을 검색하고, 공식 근거 후보 및 자문 위험을 분리할 수 있는가.

**실행:** 외부 모델 API 없이 ChatGPT가 2026-11-04 공식·제도 제공기관 페이지를 검색·읽고
답변 초안과 위험/보류 조건을 작성하였다. GitHub 코드는 해당 기록을 **재생**해
출처 누락, 오래된 증거, 미해결 법적 조건, 미래 확정수익, 개인별 매수 지시,
가짜 주장 ID, 미승인 지식의 자동 승격을 차단한다.

**절대로 주장하지 않는 것:** 독립적인 인간/블라인드 정답 검증 완료, 종료된 채팅을 GitHub가
재호출하여 모델이 실시간으로 답한 결과, 모든 금융규정의 최신 시행일을 별도 원문으로 봉인한 결과,
고객별 투자 적합성 또는 종목 매매의 확정 승인.

## 시험 설계

- 기존 원장: `data/claims.jsonl` 116건을 변경하지 않고 사용.
- 신규 영상: `ire/v5/reviews/4TFtEQxSM38_20261104.json` (잠정 10개, 독립 승인 0개).
- 출처 메타데이터: `cases.json`의 7개 공식기관/서비스 제공기관 URL.
- 예시 질문: 10개. ETF 시간외거래, 지정가 미체결, IRP 중도인출,
  연금계좌 세액공제, ISA 개정안, 배당 수익 보장, 전세금·테마 ETF 적합성,
  저녁 애프터마켓, D+1/D+2 ASR 오류, ISA 계좌간 손실 무기한 통산.
- 답변: `responses.json`의 ChatGPT 작성 10개. 모두 금융자문 출시 승인 **false**.
- 검색: 116개 기존 주장 텍스트 및 주제의 2·3글자 n-gram IDF 순위,
  정답 주장 ID를 검색 알고리즘에 전달하지 않음. **동일 턴에서 만든 질문·정답이고
  통계적 독립 테스트가 아니므로 검색 재현율 수치의 일반화 금지.**
- 검사: `python -m ire.v5.advisory_replay --root .`, `ire/v5/tests/test_advisory_replay.py`.
  모의 오류 주입은 출처 제거·존재하지 않는 주장·미승인 승인 변조·근거 날짜 만료·
  필수 위험 누락·불확정 ASR의 억지 승격 등을 포함한다.

기관의 법률 인증을 대체하지 않는다.
