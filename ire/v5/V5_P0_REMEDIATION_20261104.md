# V5 research correction mechanism

Date: 2026-11-04

## Identified defect
A submitted MODEL_ANALYSIS window containing an UNRESOLVED cue could not
be amended, because a second MODEL_ANALYSIS was rejected as a duplicate.
The closure gate correctly blocked finalization, but no repair route existed.

## Implemented remedy
MODEL_CORRECTION provides an append-only revision with a prior-model digest,
reason and complete replacement. The original event remains in the ledger.
Prior evidence and prior-knowledge decisions for that window are invalidated
and must be repeated. Source binding and unique claim IDs are rechecked.
The task router now offers MODEL_CORRECTION_REQUIRED for unresolved cues.
The local server validates its existing task and chain digests before accepting
the event. No model answer is generated by this deterministic controller.

## Remaining limits
This removes one restart loop, not every incomplete-research cause.
GitHub Actions is not an always-running ChatGPT reasoning engine. Without an
external model API, the chat host must do the actual interpretation and search.
Single-request full-video verified completion is unproven; 4-to-5-video
completion and independent financial approval remain NO-GO. Approved cumulative
knowledge merging also requires additional validation.

The user requested removal of mandatory encryption. The storage policy has
not been changed here: first ensure that confidential materials are in a
restricted-access location, then separately migrate and verify readable copies.
