2. **신규 영상 편입:** 로스터 ID와 일치하는 실제 SRT 등록 -> 구간별 의미 분석 -> 금융 법규/원문 확인 -> 기존 116개 통합 주장 및 개별 분석과의 SAME/SUPPORTS/EXTENDS/CONFLICTS 검토 -> 검증 가능 지식 원장에 반영.

## 새 영상이 등록된 뒤의 합격 기준

- **원본 확인:** 영상 ID·SHA-256·자막 전체 구간.
- **연구 결과:** 주장 단위 원문 위치, 조건, 출처, ASR·수치 미확정 별도 표시.
- **비교:** 기존 통합 주장·기존 동일 영상 분석·관련 금융 제도와의 관계 판정.
- **통합:** 기존 승인 원칙과 동일하면 중복 생성 없이 출처만 확장. 차이가 있으면 변경조건·시점·반례를 기록. OPEN은 승인 원장에서 제외.
- **자문:** 공식 최신 원문·시행일·개인 적용성·위험·독립검증 통과한 부분만 질문별 참고로 승격.

## 안전 원칙

GitHub Actions 실행 성공 = 금융 사실 검증 성공이 아니다. V5 의미 해석·근거 검색은 활성 ChatGPT 대화가 수행하며, 외부 모델 API 없이 종료된 대화를 GitHub가 스스로 재개하지 않는다. 현재 GitHub는 공개 저장소여서 비공개 SRT 원문은 직접 커밋하지 않는다. 원본 암호화 여부는 공개 연구 메타데이터와 별개 문제다.

정식 개인 투자자문 적합성은 아직 **NO-GO**.
