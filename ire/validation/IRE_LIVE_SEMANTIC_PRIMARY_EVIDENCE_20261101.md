# IRE 금융 의미 해석 ↔ 실원문 독립 근거 검증 통합 감사

**2026-11-01 · 신규 소스 전용 엔진 · 코어 통합 시험 PASS / 금융 사실 승인 BLOCKED**

## 목표 및 독립성

과거 연구의 주장·판정·골드라벨·검색 원장·기존 코드 등을 새 엔진의
입력이나 증빙으로 인용하지 않는다. 신규 원본 발언에서 직접 제안된
금융 명제와 외부에서 **그때 새로 취득**한 원문 자료만 비교한다.
단순 URL 검색, 공식기관 도메인 형태, AI의 지지 판단을 서로 다른
증거 단계로 분리한다.

## 실제 연결한 9단계

1. **SOURCE_INTEGRITY**: 원본 SRT 바이트 SHA-256·전체 cue 계보.
2. **FINANCIAL_SEMANTICS**: 외부 Responses API로 문맥별 원자 금융
   주장 초안을 제안; JSON Schema strict와 프롬프트 버전 고정.
3. **ATOMIC_TRACEABILITY**: 원문 인용·분류·조건·수치 출처를
   검증하고 누락된 cue를 분리 기록.
4. **INDEPENDENT_PRIMARY_DISCOVERY**: 최초 생성된 주장만으로
   공식기관 후보 페이지를 별도 web_search 호출.
5. **PRIMARY_DOCUMENT_VERIFICATION**: 후보 URL을 제한된 기관
   호스트 allowlist로 거르고, HTTPS로 **독립적으로 직접 다운로드**,
   공개 문서 원본 SHA-256·시각·HTML 가시 문구 추출.
   별도 모델 호출로 주장·문서 간 SUPPORTS / CONTRADICTS /
   CONDITIONALLY_SUPPORTS / INSUFFICIENT / NOT_APPLICABLE
   후보 판단. 답변에 포함한 인용문이 **실제 내려받은 원문에
   그대로 존재하는지** 검사한다. 관할·유효시점·조건·예외·수치와
   단위 관계를 별도 필드로 기록한다.
6. **QUANTITATIVE_OBLIGATIONS**: 정확 Decimal 산술과 독립
   재현 검증이 필요한 항목을 보류 작업표로 관리.
7. **WITHIN_SOURCE_RELATIONS**: 해당 입력에서 새로 나온
   주장만을 연결; 이전 지식 원장/기존 연구 결론 사용 금지.
8. **INDEPENDENT_REVIEW_GATE**: 실제 별도 인간 블라인드 심사
   확보 전에는 금융 사실 승인 및 지식 통합 금지.
9. **FINAL_PRIVATE_REPORT**: 진행·보류·실패·출처·모델·검사
   결과를 변경 불가능한 비공개 보고서에 저장.

## 원문 취득 및 보존 경계

- 기관 후보로 허용되는 도메인은 금융기관·정부/공공기관 등 명시적
  등록부에 한정. 모든 .or.kr 도메인을 자동 신뢰하지 않음.
- HTTPS에서만 공식 페이지를 취득하며 사설/예약 IP,
  서로 다른 기관으로의 리디렉션, 비인증 호스트 및 너무 큰 응답 차단.
- 같은 기관의 HTTPS 리디렉션은 제한 횟수 내에서 재검증.
- 현재 HTML/일반 텍스트만 처리. PDF·자바스크립트 전용 자료는
  미처리로 표시. 문서 부분 발췌 시 전체 법령 문맥을 자동 승인하지 않음.
- 원본 바이트를 별도의 개인 경로에 저장할 경우 0600 권한,
  SHA-256 일치로 기존 스냅샷의 임의 변조 차단.
- 출처 문구와 명제의 관련성은 검토 대상일 뿐 확정적 금융 사실 아님.

- 신규/기존 원본 없이 직접 구성한 합성 시험에서 금융 명제 추출기,

## 완료되지 않은 실전 성능 시험

현재 환경에는 OpenAI Responses API의 실제 의미 분석 및 근거
검토 모델 호출용 인증 정보가 없다. 따라서 **실제 원본 SRT에 대한
의미 분석 모델 호출 0회**, 금융 원자 주장 정밀도·재현율 및
공식사실 검증 정확도는 아직 **미측정**이다.
합성 모의 모델 실행은 외부 언어모델 실호출로 환산하면 안 된다.

또한 공식기관 사이트의 적합한 도메인을 찾고 정확한 문구를 내려받았더라도
발행기관의 법적 효력·문서가 그 사실을 충분히 뒷받침하는지·현재 적용
조건·중요한 발언 누락은 자동으로 확정할 수 없다.
PDF 원문, 법령 조항 변경 이력, 별도 검토자 2인의 독립 블라인드 정답자료,
미노출 재현율 검증은 후속 관문이다.
