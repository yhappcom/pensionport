# IRE V2 — 현재 채팅을 연구 오케스트레이터로 사용

현재 IRE의 모델은 **이 ChatGPT 대화**다. 별도의 모델 API 호출은
사용하지 않는다. 사용자가 요청한 여러 편을 ChatGPT가 원본 확보부터
해석·검색·검증·누적 지식 통합·보고까지 내부 도구로 처리하도록 설계한다.

사용자가 10개 cue 문맥별로 JSON을 입력하거나 "진행"을 반복할 필요는 없다.
IRE의 chat_bridge는 ChatGPT가 내부적으로 사용하는 출처 검사/비공개
체크포인트 도구이며, 사용자를 위한 별도 대화 입력 양식이 아니다.

- prepare / next --batch-size N: 원본·좌우 맥락·출처 cue를 가져온다.
- accept: 모델이 현재 채팅에서 작성한 원자 주장 JSON을 검사한다.
- status: 중단 이후 다음 미처리 문맥부터 재개한다.
- finalize: 해당 영상의 모든 문맥이 검증되어야 연구 후보 원장 생성.
- v2_run plan: 요청한 1~30편 전체의 원본·세션 진행 상태 검사.
- v2_run finalize: 원본과 모든 제출 답변을 재검사한 뒤 한 번에
  기존 새 IRE 지식에 통합하고 배치 감사 보고서를 작성.
- v2_evidence review: 현재 채팅이 찾은 공식기관 원문을 독립적으로
  다시 취득하고 인용·적용 범위·시점을 검사.
- v2_evidence advisory: 기준일·관할·충돌을 고려한 자문 근거 검색.

직접 명령 인수와 전체 실행 절차는 README.md 및 ARCHITECTURE_V2.md.

**실제 기술적 한계:** ChatGPT 호스트가 저장소 프로그램을 모델 API 없이
무인 호출하는 장치는 없다. 이 대화에서 ChatGPT가 호출을 이어가는 방식이다.
한 턴의 시간·도구 제한을 넘으면 완료를 허위 주장하지 않고 출처·결과
체크포인트를 보존한다. 나중에 자동으로 실행된다고 약속하지 않는다.

V1 연구 본문과 260편 과거 분석은 보존하되 신규 연구의 정답/근거로
자동 인용하지 않는다. 신규 영상은 신규 지식 원장과 대조한다.
이 채팅 모델은 독립 인간 블라인드 검토자가 아니다.
