# IRE V3 금융 의미분석 품질 감사 — 원인·조건·단위 교차 검증

2026-11-02. 본 기능은 금융 사실을 독립 인증하지 않는다. 모델이 실제 원본 인용을
다시 읽어 금융 의미 오류 가능성을 적발하도록 **기계적 검토 의무**를 강화한다.

## 분석 품질 계층 — 서로 대체 불가

| 검사 | 무슨 점을 검증하는가 | 증명할 수 없는 것 |
|---|---|---|
| Source SHA/quote | 원문 바이트·cue·인용 연결 일치 | 문장 간 인과관계·금융 규정 진위 |
| Window semantic audit | 인용되지 않은 금액 주기/상품, 고위험 비주장 | 다른 창에서 가져온 조건이 같은 계산에 해당하는지 |
| **Cross-window claim quality** | 같은 금전적 증가 결과가 다른 기여조건에 재귀속됐는지, 규정 수치에 단위가 누락됐는지 | 어떤 계산이 참인지, 외부 독립 평가자가 정확한지 |
| Independent source-first gold | 원본을 모델 출력 없이 독립 검토·판정한 실제 명제/관계 정답 | 특정 시청자 개인 금융조건·현행 법령 자동 인증 |
| Official evidence | 개별 명제의 기관별 현재 공식 원문, 법규 기간·조건·예외 | 공식 URL만으로 전체 법적 효력 자동 입증 |

**심각한 판정 결함 수정:** 원본 인용과 SHA가 맞고 윈도우 개별 경고가
0이라고 해도, 서로 다른 원인(예: 미래 보험료 계속 납부 vs 과거 추납)에서
같은 결과액이 등장할 수 있다. 같은 금액을 재사용한 이후 주장에
`PENSION_INCREMENT_CAUSAL_BASIS_UNSEPARATED`를 기록한다. 결론은
"같은 계산인지 별도 확인"이며 자동으로 금융 명제 오류를 확정하지 않는다.
추납/납부라는 원인 패턴 없이 숫자만 겹친 경우는 판정하지 않는다.

**법령 숫자:** 원문에 세율처럼 제시된 `5.5`와 `4.4`의 `%` 단위가
없거나 다른 출처에서 추론됐으면 `REGULATORY_NUMERIC_UNIT_UNESTABLISHED`를
남긴다. 소득세·지방소득세 포함 여부, 개인별 적용일·구간은 공식자료 검증
전까지 미확정이다.

## 실행 방법

```bash
python -m ire.v3_claim_quality audit \
  --private-manifest /private/research_manifest.json \
  --private-report-dir /private/claim_quality
python -m ire.v3_orchestrator audit \
  --private-manifest /private/research_manifest.json
python -m ire.v3_orchestrator gate \
  --private-manifest /private/research_manifest.json
```

`audit`는 원본 영상 해시·패킷·주장 인용 지문과 오류 코드만 포함한 비공개
불변 보고서를 출력한다. 원문 자막이나 명제 본문은 콘솔이나 GitHub에 노출하지
않는다. 새로운 검토 결과의 독립 인간 골드 여부는 항상 별도로 검증한다.
`finalize`는 **교차 문맥 인과관계/법령 단위 위험이 1건이라도 있으면**
새 지식 스냅샷을 생성하지 않고 `INCOMPLETE_REQUIRES_RESUME` 상태로
반환한다. 명제 수정은 기존 불변 원본·답변을 건드리지 않는
`ire.v3_orchestrator correct` 경로로만 수행한다.

### 2026-11-02 실제 비공개 #1 영상 v003 재검토 결과

- 5편 5,129개 원본 자막, 적응형 346개 문맥. 현행 제출 8개 문맥,
  원자 주장 31건. 338문맥 미분석.
- 원본 SHA/연속 cue/유효 인용·체크포인트 검증은 통과.
- 기존 의미 검토 경고는 8건(각각 별도 원자 주장 8건).
- 새 핵심 재검토 3건: W00005 주장 3, W00008 주장 4
  (`PENSION_INCREMENT_CAUSAL_BASIS_UNSEPARATED`), W00007 주장 2
  (`REGULATORY_NUMERIC_UNIT_UNESTABLISHED`). 중복 경고를 제거하면
  최소 9개 서로 다른 원자 주장이 추가 검토 대상.
- 서로 다른 투자수단의 수익률·세후 비교, 연금저축 계좌 납입 범위,
  물가 반영에 관한 주장은 **원문 속 가정·의견**으로만 유지한다.
  공식 자료의 실제 법적 효력/개인별 보험료·연금 수급액은 승인 0건.
- 관련 수치의 독립 Decimal 점검: 1,800만원 × 1.07^12 ≈ 4,053.9만원;
  4,000만원 × 연 6/7/8% ÷ 12 ≈ 월 20 / 23.33 / 26.67만원.
  단순 계산 정합성은 수익률 가능성·과세·적합성에 대한 증명이 아니다.
- ChatGPT의 자체 원문 판정은 인간 두 명 및 별도 조정자의 독립 블라인드
  판정으로 계산하지 않는다. 실제 금융 연구·자문 출시 계속 차단.

## 성능 및 범위 한계

금액 비교 후보를 `video_id`·정규화 금액별로 색인하여 동일 영상 가까운
12개 문맥의 최대 8개 앞선 조건 후보만 대조한다. 이는 실전 누락률을
제어하는 후보 탐지 휴리스틱이지, 관계 Recall@K의 인증이 아니다.
긴 영상의 먼 문맥 재사용이나 단위 없는 OCR, 의미상 동치인 한국어
표현은 별도 평가가 필요하다. 규칙이 탐지하지 못한 주장은 검증 완료가
아니며, 독립 골드가 없으면 품질을 인증하지 않는다.

## 구버전 경로 우회 방지

V3 적응형 입력(`window_strategy=V3_ADAPTIVE`)을 사용자 또는 연결
스크립트가 `python -m ire.v2_run finalize`에 직접 전달하더라도
`v2_run.finalize_batch`는 동일한 `v3_claim_quality` 검사를 먼저 수행한다.
원인·단위 위험이 남아 있으면 신규 지식 스냅샷을 쓰지 않는다.
이 보호 규칙은 과거 `V2_COMPAT` 원본의 불변 체크포인트 동작을
재해석하거나 변경하지 않는다. 외부 코드가 데이터베이스 파일을 직접
수정하거나 역사적 코드 버전을 실행하는 행위까지 보호하는 것은 아니다.
