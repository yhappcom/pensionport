- 3 ZIP CRC 정상; macOS 메타데이터 제외 실제 300항목, 고유 SHA 299, 영상 ID 299(파일명 추출). 원본 269,627자막, 마지막 종료시간 합계 529,669,008ms. 중복 1개 별칭 유지. 순번/게시일은 미대조. 791편 전체 확보 아님.
- 24자막 창, 12자막 간격, 꼬리 보존. 22,314창. Unicode NFKC/공백 제거/대소문자 정규화, SQLite FTS5 trigram (2글자 검색은 instr). 검색어 그룹 AND/별칭 OR; 명시적인 질의 작성 필요. 구간 랭킹, 겹침 억제, 원본별 기본 3개 및 상위 30개 제한, 앞뒤 8자막 원문 복원. 원본 해시/경로/영상 ID/시간/번호/원문 반환. 검색 결과가 사실 또는 승인 상태 아님.
- 원본 DB는 읽기 전용 사용, 새 파일로만 빌드, 잘못된 파일명·CRC·파싱은 실패 시 임시 DB 정리. 첫 빌드에서 예외 파일명 발견, `_public_auto_timed_YYYYMMDD`를 명시적으로 허용한 후 재실행. 외부 데이터 내용 변경 없음.
