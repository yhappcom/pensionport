# P0-0-06 공개 자료 범위 결정 — 2026-11-22

사용자는 **"다 공개 자료 이므로 암호화나 보안 등이 필요 하지 않습니다."**라고 명시했다. 이 별도 사용자 턴의 선언을 **프로젝트 자료 분류 및 처리 범위**에 적용한다. 외부의 독립 인증·제3자 저작권 사용 허락 또는 개인정보 무노출 검사로 과장하지 않는다.

- 기존 공개 Base64+zlib JSON 6개: 복원 가능한 공개 연구 파생 자료. 암호화 의무 **없음**.
- 기존 V3/V4 PPC1 25개 및 V5 레거시 11개: 보관물 무결성 36/36 확인 이력은 유지. 원본 복원 미검증 사실 유지. **현행 E5 승인 지식은 0이므로 해당 보관물의 키 복원을 P006의 전제조건으로 요구하지 않음**. 향후 연구에 필요한 원본은 출처에서 새로 확보하고 해시/내용을 대조해야 한다.
- 42/42 Git blob·바이트·해시 검사, 6/6 복원 가능한 JSON 파싱, 60개 순차 체크리스트와 동일 SHA CI는 **유지**한다.
- 기존 보안 HOLD 원장과 고정 근거 SHA는 **역사적 원본**으로 수정하지 않는다. 그 6가지 위험은 이번 사용자 공개 범위 결정에 따라 P006 진행 차단이 아니라 역사적 보안/복원 한계로 별도 보존한다.
- 공개 접근 가능성이 저작권상 재배포 허가를 보장하지 않으며, 향후 Google Drive 포트폴리오·계좌 정보는 이번 공개 범위에 포함하지 않는다.
- 해당 공개 분류 PASS가 ETF 250자막 원자의 정확도, V123 13구간 승인, 공식 금융근거 E4 및 E5 출판의 PASS를 뜻하지 않는다.
