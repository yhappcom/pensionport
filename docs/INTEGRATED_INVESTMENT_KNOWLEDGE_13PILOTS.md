# 박곰희TV 13편 기반 통합 투자 지식 — 심층 검토 초안

**작성·검증 기준일: 2026-10-09 | 상태: DRAFT, NOT_APPROVED**

이 문서는 현재 1~70번 영상 중 자막 원문을 분석한 13편의 발언을 **서로 연결해 이해하기 위한 학습 노트**다. 새 영상 10편의 88개 검토 주장과 기존 3편의 25개 검토 주장을 연결한다(총 **113개** 시간코드 주장). 초기에 작성한 별도의 28개 중첩 검토 자료는 중복 가산하지 않는다.

원본 SRT의 자동 음성인식 오류 가능성, 촬영일·자막 내용·영상 화면의 차이, 개별 과세·ETF 상품의 실시간 조건 때문에 **실제 자산 매수/매도·계좌 변경 지침으로 자동 승인하지 않는다.**

## 통합 검증 규칙

1. **원문:** 주장마다 YouTube 영상 ID, 자막 SHA-256, 시간코드를 유지한다.
2. **두 시점:** 영상 당시 언급한 세율·금리·상품가격과 현재 공식자료의 기준일을 구별한다. 영상의 게시일은 촬영일이 아니다.
3. **주장 등급:** 구조적 기본 개념 / 개인 견해 / 시나리오 / 정량 주장 / 법률·세제·상품조건 / 미검증 안전성 단정으로 구분한다.
4. **중복 근거:** 같은 영상의 다른 JSON과 Shorts·요약 재편집·복제 자막은 독립 근거로 추가 집계하지 않는다.
5. **저장:** 전체 저작권 보호 SRT 원문을 공개 저장소에 게시하지 않는다.
6. **승인:** 현재 파일은 **심층 검토 초안 13편**이며 정식 학습 승인과 별개다.
