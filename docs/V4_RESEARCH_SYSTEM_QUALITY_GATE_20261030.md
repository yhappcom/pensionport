# V4 연구 시스템 품질·의사결정 활용 게이트 (2026-10-30)

**상태:** ACTIVE · #11 이후 신규 V4 심층 검토에 적용. **적용 범위:** 791편 연구, 기존 V3/V4 보존, 새 V4 근거·정정·모형 및 지식 통합. **우선순위:** V4 품질·의사결정 게이트는 이 문서를 적용하고, 원본 SRT 증거·V3 승인·비공개 자료·CI 원자적 저장은 기존 [WORKFLOW](../WORKFLOW.md) 및 [V3 검증 정책](INVESTMENT_RESEARCH_VERIFICATION_POLICY_20261012.md)의 더 엄격한 규칙을 유지한다. 이전 영상의 과거 승인·판정을 소급 수정하지 않는다.

## 0. 배경과 확인된 기준선

- #1~#5: 기존 V3 **62개 주장**, V4 조건부 교육용 종료. #5는 기존 완료 유지.
- #6~#10: V3 **60개 주장 재사용**(신규 V3 승인 0), 그중 **35개** 핵심 근거/계산 재검토, **25개** V3 유지·신규 독립 재검증 아님; V4 가상 모형 **9개**, 외부 증거 **OPEN 14건**. #5~#10 통합에서 #5를 이 60개에 다시 더하지 않는다.
- 기존 계산·해시 연결 CI 통과는 계산 재현과 등록 파일 일치만 의미한다. 전 발화 원음·화면, 법률 적용 해석, 상품 실제 총비용, 개인별 세후성과 또는 L3/L4 승인을 뜻하지 않는다.
- #10 `VKr060rIirM-05`의 `CONTRADICTED`는 “일반계좌는 항상 15.4%, 연금은 항상 3.3~5.5%”라는 **보편적 세율 우열 비교에 대한 반박**이다. 이 오해를 긍정 투자 원칙으로 재활용하지 않는다. 기존 V3 기록은 변경하지 않고 별도 차단 원장에 등록한다.
- 이번 규정으로 #6~#10의 기존 L1·L2 허용은 유지, **L3 개인별 판단·L4 실행은 모두 미승인**이다. 가상 모형의 산술 PASS를 근거로 상태를 자동 승격하지 않는다.

## 1. 영상 연구 단계별 강제 체크리스트

| 단계 | 반드시 확보·검증할 항목 | 검증 실패 시 |
|---|---|---|
| G1 원본 근거 | 정확한 video_id, SRT 등록 SHA-256과 **이번 회차 파일 바이트를 실제로 다시 읽었는지** 구분, cue/시각·전수 구간 범위, 공개 ASR·원음·프레임 확인 여부 각각 구분 | 실제 재검사하지 않은 해시는 `HISTORICAL_HASH_ONLY`로 기록. 원본 부재를 확인 완료로 표시 금지 |
| G2 주장 전수성 | 각 원자 주장 ID의 재검토/기존판정 유지/조건부·반박/제외+사유 연결. 전수 색인율과 **실제 독립 재검증률** 분리 | 누락 ID 및 재검증 건수 과대계상 차단 |
| G3 공식 근거 | 기관 원문 특정 조항/상품번호, 발효일·검증일·적용대상·소득원천·예외, 출처의 실제 결론까지 대조 | 링크만 존재할 때 `PRIMARY_CONFIRMED` 금지. 충돌은 `OPEN_SOURCE_CONFLICT` |
| G4 정량·경제·법률 | 단위/기간/지급시점/원금/현금흐름/수익률/세율/보수, 계산 재현 **및 별도 경제·법률 해석 QA**. 민감도·반례, 실제상품/원본 성과 여부 분리 | 계산만 PASS면 `SYNTHETIC_ARITHMETIC_ONLY` |
| G5 정정·충돌 | `CONTRADICTED`의 **반박 대상 원문 주장**·정정된 원칙을 구분. 신규 지식 생성·교차영상 병합 시 관련 ID의 충돌·적용조건·효력일 매핑 | 반박된 원문을 추천 또는 검증 지식으로 승격 금지 |
| G6 OPEN 관리 | 자료, 확보 경로, 영향받는 claim/model, 막히는 이용수준, 재개 조건, 해결불가 시 명시적 제한 | OPEN을 조용히 RESOLVED/PRIMARY로 바꾸지 않음 |
| G7 종료·활용 분리 | `research_status`, `evidence_status`, `max_use(L1/L2)`, `L3_approved`, `L4_approved` 각각 저장 | 교육 연구 완료를 개인 투자 승인으로 해석 금지 |
| G8 배포 | 기작성 V3/V4 보존, GitHub 단일 원자 커밋 권고, 변경 파일 재조회, **정확히 그 커밋** CI 최종 SUCCESS 확인 | pending/failure/cancelled는 완료 보고 금지 |

## 2. 반복 오류 방지 — 필수 연구 판정

1. **세제 비교:** 일반/ISA/연금저축/IRP, 국내·해외 상장상품, 세액공제 원금·미공제 원금·운용수익·이연퇴직소득, 연금수령·연금외수령을 분리한다. 원금과 이익에 일률적인 세율을 적용하지 않으며 해외원천징수·연금소득 한도와 가입자 요건을 따로 표시한다. #10 `V4_010_ORDINARY_PENSION_TAX`는 **가상 민감도 비교(L2)로만** 유지. 세액공제 원금 과세경로가 미구현이므로 보편적 세후 우열·L3/L4에 사용 금지. 추가 모형에서 입력 재원별 과세경로와 대조 증거가 마련되기 전에는 제한 해제하지 않는다.
2. **자녀 증여:** #6 연 3% 할인된 정기금 예시는 계약 현금흐름 가정에 따른 계산일 뿐 실제 법적 증여평가가 아니다. 월·연 지급시점, 철회/중도해지 일시금, 기존 10년 증여 합계, 수증자·특례 해당시점·세법 적용일 없이는 개인별 비과세 여부 불확정.
3. **엔화 투자:** #8/#9 직접 환전·국내 엔화 ETF·일본 상장 주식/미국지수 ETF의 **결제통화와 실제 경제적 환노출**을 구분. 동일 원화 원금/보유기간·양방향 환전 스프레드·환헤지 비용·총보수 외 비용·추적차이·과세·원금손실과 연금계좌 매수 가능 여부를 통일하여 비교한다. 연 0.19% 등 특정 공시값을 전체 비용 또는 미래 확정 수익으로 오인하지 않는다.
4. **개인 실적·통계:** #7의 4억원→7억원은 순납입·인출시점·계좌기록이 없는 한 수익률, 복리 성과나 재현 가능한 전략 우월성의 근거가 아니다. 5시간 44분 모음 영상의 여섯 개인사례는 독립 통계 표본 6개가 아니다.
5. **원본 정합성:** #8 공개 자동자막 누락 cue 2개, #10 사적 원본 34 cue SRT 해시 부재는 각각 남겨둔다. 과거 V3에서 저장된 SHA 연결이 맞더라도 이번 원본 ZIP 재다운로드·해시 산출이 이뤄지지 않았다면 `raw_hash_recomputed=false`를 유지한다.

## 3. 기계 판독 규약과 차단 조건

- [기준선/교정 차단 원장](../data/synthesis/investment_knowledge_v4/research_quality_controls_20261030.json)의 `blocked_positive_claims`에는 기존 반박된 주장 ID, **원래의 오류**, 검증된 제한적 정정, 지식 전파 제한을 별도로 적는다. 영상 V3 기록이나 기존 대형 원장을 덮어쓰지 않는다.
- #11 이후 **신규** `reviews/v4_NNN_*deep*review*.json` (또는 `*decision*review*.json`, `*quantitative*review*.json`)에는 `quality_gate` 객체를 추가한다. `source_provenance`, `claim_coverage`, `model_scope`, `knowledge_integration`, `decision_status`, `open_blockers` 필수. 누락은 CI FAIL.
- `claim_coverage.rechecked_ids`와 `reused_ids`는 중복 없이 저장된 `claims[].id`를 완전 분할한다. `contradicted_ids`는 반박 주장과 일치해야 하며 그 ID가 있으면 `knowledge_integration.correction_ids`가 있어야 한다. 재검토 이력은 원 주장 판정을 암묵적으로 변경하지 않는다.
- `model_scope`는 `model_ids`, `arithmetic_status`, `semantic_status`, `legal_product_status`, `tax_basis`, `limits`로 나누며, 모형이 없으면 `NOT_APPLICABLE`; 세제모형인데 재원 분리가 안 되면 `tax_basis=OPEN` 및 L2 이하로 제한한다.
- `decision_status`에서 연구 완료, 근거 상태, 최대 활용수준과 L3/L4를 독립 저장한다. 본 프로젝트 자동 V4 연구 과정은 **L3/L4 false**를 유지한다(개인 자료·승인 별도 과정).
- `open_blockers[]` 각 항목에는 `id`, `claim_ids`, `needed`, `blocked_use`, `reopen_trigger`를 저장. 기존 `external_open[]`가 있다면 ID 목록이 일치해야 한다.
- 구현: `python -B scripts/verify_v4_research_governance.py --self-test` 및 `--root .`; GitHub Actions push/PR 경로에 연결. 새 스키마 강제는 #11 이후 신규 영상 리뷰 파일에만 적용하며 #1~#10의 불변 원본을 소급 덮어쓰지 않는다.
- **자동화의 한계:** 문법·ID·비율·상태 차단과 등록된 기존 교정은 검사할 수 있지만, 외부 법령의 내용·계약·개별 투자 적합성의 참거짓은 자동으로 인증하지 못한다. 자료가 있는 경우 사람이 공식 근거를 읽고 확인한 별도 판단 기록이 필요하다.

## 4. 실제 연구·배포 순서

1. 현재 브랜치의 원본/기존 V3/V4 리뷰와 핵심 지식 ID를 읽어 신규·변경·반박·OPEN을 표시한다.
2. 할 수 있는 공식자료 대조·정량 민감도·반례·교차영상 검증을 **같은 영상 회차**에서 끝내고, 외부 자료에 의존하는 부분만 OPEN으로 남긴다.
3. 새 `quality_gate` 작성 후 거짓 신규 승인 0건인지, 반박 주장 차단·OPEN의 활용수준 제한·가정·정정 전파 여부를 재검토한다.
4. 산술 CI + 시스템 품질 CI + 기존 V3 증거 CI를 **모두** 통과시킨 후 정확한 최종 커밋 재조회. 실패 시 재수정하며, 성공 전 완료·점수 상승을 보고하지 않는다.
5. 같은 세법·ETF·연금 등 다중 영상의 지식 충돌은 관련 기존 원칙에 조건부 보강 또는 별도 반박 오버레이로 연결한다. 새 영상 추가가 기존 원칙을 기계적으로 참으로 승격시키지 않는다.

**운영원칙:** 연구 완료와 투자 실행 가능성은 별개이다. 확보 불가능한 개인 거래명세는 객관적 자료로 대체하거나 가상의 검증 완료로 기록하지 않는다. #1~#10의 기존 V4 조건부 종료는 유지하면서 #10 제한 모형 등 중대 사항은 근거 확보 시 별도 교정판으로 추적한다.
