## 승격 문턱

1. 실제 한국어 전사 **전체**를 살펴 같은 영상인지 확인한다. 원본 SRT 바이트가 사용 가능하면 레지스트리 SHA-256과 대조한다. 원본 없으면 독립 공개 전사로 진행하고 **바이트 미일치 검증 OPEN**으로 표시한다.
2. 영상 당시 설명과 현재 제도의 기준일을 나누고 **주장별** `verification_evidence`에 독립 공식 원문 URL, 확인일, 확인한 사실, 적용범위·정정/예외를 기록한다. 검증하지 않은 자료의 단순 `official_sources` 링크는 인정하지 않는다.
3. 부정확·반박된 발언은 `CONTRADICTED`와 `correction`을 함께 남긴다. 정정 없는 반박 주장이 있다면 승격 불가.
4. 부록/초안(`pilots`) 자체를 무작정 승인으로 바꾸지 않는다. 문턱을 충족한 경우에만 **별도의 단일 `data/analysis_events/<video_id>.json`**을 작성해 원본 요약, 주장별 검증결과, 예외·위험, OPEN, 원문 수준을 명시한다.
5. 파일을 재조회하고 **새 최종 기록 CI 통과**까지 확인한다. 원본 화면/음성 미검토는 숨기지 않으며 직접 투자 조언·보장성 진술을 승인하지 않는다.
6. GitHub 안전 검사에서 쓰기 차단이 발생한 실행은 **추가 쓰기 없이 종료**하고 실패 사실을 기록한다. 사용자 검토 전 `main` 병합 금지.
