# 1~70번 자막의 내용 색인 (2026-10-09)

## 실제 진행 결과
- 대상: 확정 로스터 #1~#70, SRT 70편(롱폼 49 / Shorts 21).
- 원문 검사: 56,045개 자막 구간을 읽고 주제 키워드 및 시각 참조점을 추출했다.
- 로컬 상세 색인: 70편, 참조점 245개. GitHub 축약 색인 `data/subtitles/content_index_001_070.json`: 70편, 참조점 234개.
- SRT 원문과 실제 음성의 일치, 원화 자막 교정, 금융상품 공식 검증은 수행하지 않았다.
- 내용 색인 ≠ 핵심 주장 분석 ≠ 공식자료 검증 ≠ 투자 지식 승인. 70편 모두 `NOT_ANALYZED`/`NOT_VERIFIED`로 보존한다.
- 첫 ZIP의 SRT 70개는 고유 영상 69편(#59 중복 1개), 이후 #60 추가 파일로 #1~#70 전수 확보.
- 전체 791편 중 아직 자막 미등록 721편.

## 형식과 출처 검증
- 유일 식별자: YouTube video_id; 원본 파일 변경 감지: SHA-256.
- 색인 증거: 각 SRT 구간의 텍스트에서 실제로 검출한 키워드와 해당 시작시각.
- 키워드 출현 빈도는 동일 문장의 자막 중첩 영향을 받으므로 독립 주장 수가 아니다.
- 2019년 이전 분석과 이번 2026년 영상 색인은 별개로 관리한다.
- 타인의 SRT 원문은 공개 저장소에 업로드하지 않는다.

## 나머지 우선 분석 흐름
1. ETF 기본: 68 → 66 → 63 → 58 (구조, 종류, 선정 기준, 상장폐지)
2. 세제·연금: 47 → 45 → 42 (ISA, 연금저축, IRP 현행 공식자료 필수)
3. 실전 사례: 60 (개인의 소득·나이·투자성향을 일반 법칙으로 확대하지 않음)
4. 7번 모음집은 약 5시간 45분의 재편집 영상이므로 원영상과 구간 중복을 확인하고 별도 처리.

## 이후 배치의 안전한 처리
1. 새 ZIP을 `scripts/ingest_subtitle_zip.py`로 검사 및 등록.
2. 기존 `data/subtitles/registry.json`의 SHA와 일치하는 자막만 색인; 변경은 반드시 별도 검토.
3. 새 영상의 검색용 주제·시간코드를 `content_index_001_070.json` 형식에 증분 추가.
4. `CONTENT_INDEXED`에 도달해도 심층 분석·공식 검증 상태는 자동으로 올리지 않음.
5. 장기 지식은 원문 시간과 외부 공식 증거를 가진 개별 분석 파일에서만 갱신.
