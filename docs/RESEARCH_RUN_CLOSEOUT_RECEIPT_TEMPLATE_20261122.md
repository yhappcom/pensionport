# 연구 실행·브랜치 종료 영수증 양식 (개별 영상/배치별)

> 공개 Git에 실제 비공개 SRT·개인 투자정보·민감한 대화 원문을 복사하지 않는다. 각 원본·검토 근거의 SHA 및 접근통제된 비공개 보관 위치만 남긴다.

|---|---|

| 원본 종류·SHA-256·자막 총수 | 작성 필요 |

| 종료일 / 검토자 / 다음 재검토 트리거 | 작성 필요 |

**강제 원칙:** 1턴 준비 + 별도 실제 사용자 메시지 2턴 의미 검토; 2개 함수/프로세스 실행은 2턴이 아니다. ChatGPT 호스트의 암호학적 서명은 실제 증명이 없으면 미확보로 기록. 공개 GitHub의 이전 원장 데이터를 V123/E4/E5 최종 승인 자료로 무조건 승격하지 않는다.

**정식 합격 검사:** 해당 영상/배치의 100% source cue 판정, 손실 없는 원자/문맥 구조, 실제 V123 ChatGPT verdict, E4 적법 승인과 E5 원자적 발행 및 재개봉. 실패 또는 HOLD 시 작업상 완료가 아니라 `CLOSED_WITH_EXPLICIT_HOLD_TRANSFER`로 이관한다.
