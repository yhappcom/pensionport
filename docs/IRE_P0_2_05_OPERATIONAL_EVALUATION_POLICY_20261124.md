# 사용자 승인 운영 평가 정책 V1 — 2026-11-24

사용자 승인: “말씀하신대로 정책을 변경하겠습니다.” (실제 채팅의 정책 결정; 암호학적으로 인증된 호스트 서명이라고 주장하지 않음). 기존 독립 평가 실패와 95%/98%/0 인증 기준은 보존한다. 이 문서는 기존 master plan 및 catalog의 독립 인증을 운영 진행의 필수 조건으로 취급하던 부분에 한해 우선 적용된다. 정책 변경은 현재 PASS가 아니다.

## 운영 합격(A)과 독립 인증(B)

A. E2 운영 평가: ChatGPT와 엔진만으로 동일 채팅에서 수행하는 두 실제 사용자 턴. L2 내부 참조는 독립 정답이 아니다. 정밀도 ≥95%, 재현율 ≥98%, 내부 참조 기준 고위험 FN=0, 숫자/단위 출처 오류 및 중대한 조건/예외 왜곡 0. 원문 100% 재판정, 원자별 출처·대응 근거·누락/과잉 원자 사유, 금융 위험별 공식 근거 또는 격리 사유를 보존. 정식 E3/E4 검증은 추후 순서대로 수행하며 E2 합격 자체로 금융 사실 승인/지식 발행/개인 자문을 허용하지 않는다.
B. L4: 기존 독립 검토·중립 호스트 신뢰 등록 및 95%/98%/0 기준을 그대로 유지. 실제 증거 없으면 UNMEASURABLE, 수치는 null. 운영 합격과 무관하게 유지한다.

## 시험 설계 (결과를 보기 전에 고정)

- P205 운영 성능 시험용 ETF·연금·자산배분 각 신규 원본 1편, 총 3편. 기존 ETF250과 개발 노출 자료 제외. 이는 엔진/프로젝트 수준의 미노출 확인이며 모델 훈련 자료 노출 여부나 독립성을 증명하지 않는다.
- 실제 출처 ID·원문 SHA·노출 이력 조사 SHA·선정 근거를 엔진 SHA와 함께 사전 고정, 원문 분석 전에 등록. 이력 확인 불충분 시 신규로 주장하지 않는다. 3개 모두 개별 합격 필요, 평균으로 실패 은폐 금지. 실제 파일을 확보하지 않았거나 합성만 통과하면 HOLD. 추후 P1의 별도 신규 5편 시험은 유지한다.
- TURN1: 원문 전체 분석, 금융 근거 및 기존 지식 후보, 동결 예측을 작성. TURN2: 새 사용자 명령, 원문 재판정, 내부 참조와 출처 근거를 동결한 뒤 9축 1:1 대응 및 누락/과잉/부분 일치 판정. 기존 예측 노출 가능성을 명시. 고위험 참조 최소 1개 이상 포함하여 공집합 PASS 금지. 모든 OPEN_UNCERTAIN은 해소될 때까지 계측/합격 불가; 실제 불명확한 사항은 무리하게 NO_ATOM으로 바꾸지 않는다.
- TP/FP/FN은 최초 동결 예측 기준. 수정 결과로 최초 점수 대체 금지. 실패 보존, 일반 결함 수정 후 새로운 사전 등록 시험 세트에서 재시험. 동일 자료는 회귀만 가능. 원문과 대응의 의미 정확성은 ChatGPT가 판정하므로 점수에 편향 가능성이 남는다.
- P205 운영 통과는 3편 내부 시험과 정확한 엔진 SHA 6-job CI, 검토된 실제 비공개 재실행 영수증 및 체크리스트 증거가 필요. P206은 전체 실제 원본과 남은 위험/격리·오분류 확인, 이후 E3/E4/E5에서 실제 2턴 최종 의미검증·공식 금융 원문 바이트·적법 권한·원자적 저장·재조회. 791편 확대는 E1~E5 및 기존 범용성/자문 검증 계획 완료 이후. P1-3-04는 별도 신규 질문을 사전 고정한 재현 가능한 내부 운영 평가를 사용하고 독립 인증은 별도 표시.

## 구현 및 현 상태

운영 전용 함수 operational_assessment.evaluate_operational_trial은 실제 원문/owner inventory/전체 범위 및 native 구조를 재실행, 기존 9축 정량 계산기와 근거 원장을 결합한다. 입력자 자체 평점을 받지 않는다. scripts/ire_p205_operational_release.py는 공개 SHA-only 사전 등록 및 운영 종료 영수증을 별도로 고정하여 체크리스트와 연결한다. 현재 두 pin 모두 미등록이며 L4 pin도 그대로 비어 있다. 공개 CI는 비공개 연구 진실을 인증하지 않는다. 모든 신규 시험은 합성 회귀에 불과하다.
