# P0-0-06 · R02 Actions 전체 파일 아티팩트 재배포 경로 완화 (2026-11-22)

## 출처 및 결함
수동 워크플로 `.github/workflows/full-repository-snapshot-audit-20261122.yml`의 과거 정의는 Git의 전체 추적 파일 바이트를 ZIP에 저장해 Actions 아티팩트로 업로드했다. 현재 공개 접근 가능한 Base64+zlib JSON 6개가 이 ZIP에 다시 포함될 수 있는 추가 배포면이었다. 아카이브 36개도 ZIP에 포함되지만 암호화돼 있다는 사실은 원문 복구를 입증하지 못한다.

## 이번 비파괴 변경
- 전체 파일 ZIP 업로드를 중단하고 파일명/크기/SHA-256/추적 커밋의 **메타데이터 전용 JSON**을 수동 업로드한다. 실제 파일 바이트를 아티팩트에 담지 않는다.
- 해당 워크플로의 Git blob SHA를 P0-0-03 검사 인벤토리에서 최신 상태로 갱신하되, 과거 SHA를 `p006_pre_containment_source_git_blob_sha`로 남긴다.
- 27개 워크플로의 검증 코드를 강화하여 수동 워크플로가 이전 전체 ZIP 재배포를 부활시키는 것을 탐지하고 적대적 회귀시험을 추가한다.
- P0-0-06 기존 보안 감사 원본은 현행 E1~E5 상태 검증에 SHA로 고정돼 있으므로 **원본 문서를 변경하지 않고** 이 후속 문서에서 조치 증거를 별도 누적한다.

## 미해결 사항과 책임
- **R02 부분 완화만 실시**: 기존 Git history, 이미 업로드된 Actions 아티팩트, 외부 클론/캐시는 삭제·검증되지 않았다.
- R01 공개 JSON 기밀성, R03 PPC1 25개 키 복원, R04 V5 11개 실제 복원, R05 개인 원본 비교, R06 관리자 사전 Ruleset/secret scanning이 여전히 미완료다.
- 증명 전 상태는 `P0-0-06 HOLD`, `P0-0-07 BLOCKED`, E1~E5 실물 연구 및 개인 자문 `HOLD`. `main` 및 브랜치 2개 유지.
- 본 변경은 GitHub Actions에서 동일 SHA CI가 PASS일 때만 소프트웨어 회귀 성공으로 기록한다. 보안 PASS 또는 기밀 무노출 선언 금지.
