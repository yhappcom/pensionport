- **투자한도 ≠ 매년 자동 참여 권리.** 전용계좌 연1억원·5년2억원이지만 [2026-09-22 2차 공지](https://www.fsc.go.kr/no010101/87766)는 **1차 가입 이력자는 2차 가입 제한**을 명시. 2차 모집기간 9/30~10/15는 원 영상 촬영 이후 발표된 조건.
- **보장 ≠ 후순위.** 선순위 투자금의 20%인 재정 후순위와 자펀드 운용사 출자분을 합친 자펀드 전체 대비 비율은 **17.5~20.8%**로 다름([금융위 5/21](https://www.fsc.go.kr/no010101/86950)). 공모펀드 전체 원금보장이 아니며 원음 설명의 후반 원금위험 경고를 보존.

- [운용사 원문 2026-05-18](https://www.samsungfund.com/fund/lounge/notice-view.do?no=241328)의 **후순위 손실부담을 선순위 과세대상 수익으로 간주하여 실제 투자손실에도 과세 가능** 경고는 세후수익 산정 시 필수.
