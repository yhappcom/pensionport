# V4 근거 중심 투자 지식베이스 — 파일럿 프로토콜

## 범위 및 보존 원칙
- 기존 main 자료는 삭제/수정하지 않는다. 이 브랜치는 V4 스키마·검증기·대표 10편 목록을 독립적으로 추가한다.
- 고정 로스터: VIDEO_INVENTORY_2026-10-07.md (791 / 롱폼 703 / Shorts 88).
- data/v4/pilot_manifest.json의 10편은 **시범 분석 대상으로 선정만 되었으며 학습 완료가 아니다**.
- 이전 V1~V3 문서, canonical_events, 누적 지식은 자료 후보이며 V4 검증 통과 전에는 의사결정 승인 데이터가 아니다.
- 원문 영상 자막 전부나 개인정보/거래내역을 공개 저장소에 복사하지 않는다.

## 단계 구분 (완료 편수와 분리)
| 단계 | 설명 | 상향 조건 |
| --- | --- | --- |
| INVENTORIED | 로스터 ID/메타데이터 확보 | 정확한 URL / ID 확인 |
| SOURCE_READY | 해당 영상의 충분한 원문 확보 | 정확한 ID의 전사/화면 자료 및 한계 기록 |
| GROUNDED | 주장별 원문 근거 연결 | 직접 출처 참조와 구체적인 주장·조건·위험 |
| VERIFIED | 중요 주장·수치의 1차자료 교차검증 | 공식 문서, 시점, 모순/미확인 처리 |
| SYNTHESIZED | 과거 주장들과 지식 관계 통합 | 변경/충돌 연결 및 기록 |
| DECISION_READY | 특정 맥락의 조건부 사용 가능 | 최신 확인, 적용조건, 위험 및 사람 검토 |

## 10편 파일럿의 검증 게이트
1. **정체성**: 모든 파일의 video_id, 영상 URL, 로스터 영상 유형 일치 (100%).
2. **출처**: YouTube 원문 전사/화면을 주 출처로 쓴다. 2차 요약만 있는 경우 GROUNDED 이상 금지. 원문 영상 전사에서 근거를 확보한 사실과 화면을 확인한 사실을 엄격히 구별한다.
3. **증거 연결**: GROUNDED 이상은 모든 주장에 근거 문서 ID를 연결한다(100%). 타임코드가 없으면 null, 절대 만들어내지 않는다.
4. **수치와 제도**: 현재 실행에 영향을 주는 세율, 한도, 자격, 상품 운용조건은 현재 공식 1차자료로 확인하지 못한 경우 OPEN으로 남기고 DECISION_READY 금지.
5. **변경 추적**: 영상 발행 당시 주장과 현행 규칙을 분리하고 서로 충돌할 경우 CONFLICT 또는 SUPERSEDED 상태를 부여한다.
6. **화면 의존성**: 포트폴리오 비율/표/증권사 UI가 중요한 영상에서 화면을 검토하지 못하면 품질 메타데이터에 기재하고 DECISION_READY 금지.
7. **품질 방어**: 음성 자동전사의 고유명사, 자산명, 금액 인식 오류를 별도 기록한다. 미확인 정보를 추측으로 채우지 않는다.
8. **투자 적용**: 개인별 위험허용도, 자금 시점, 계좌 자격, 세금, 상품 비용을 점검하고 해당 맥락 이외의 일반적 매매 신호로 쓰지 않는다.
9. **재현성**: 저장 후 재조회 및 JSON Schema + 교차필드 검사 통과; 실패 시 별도 보류 상태.
10. **파일럿 합격**: 10편 중 10편이 최소 GROUNDED, 위험도가 높은 제도·수치 주장은 확인 또는 명시적 OPEN; 투자 적용은 별도 심사.

## 데이터 모델
- schemas/v4_video_analysis.schema.json: 영상별 근거·주장·공식검증·조건·품질·적용 검토.
- schemas/v4_pilot_manifest.schema.json: 10편 대표 샘플과 품질 기준.
- data/v4/pilot_manifest.json: 고정된 샘플 명단. 상태가 INVENTORIED이므로 완료 수 0.
- data/v4/analyses/<video_id>.json: 원문 조사 뒤에만 새 파일 생성.
- scripts/validate_v4.py: 스키마·로스터·교차필드·중복·단계 상승 규칙 검사.

## 실제 작업 순서
1. 이전 자료를 **참고용**으로 열고 동일 영상 ID의 전사를 다시 확보한다.
2. 주장을 문장 단위로 분리하고 타임코드/출처 ID, 전제, 위험, 유효 시점 표시.
3. 최신 법령/공식공시를 독립적으로 확인; 개정안과 시행규칙을 분리.
4. 검증 실패 또는 화면 미확인 항목을 OPEN, 제한사항으로 보존.
5. 영상별 JSON 생성 → 자동 테스트 → GitHub에서 재조회 → 개별 품질 감사.
6. 파일럿 합격 시에만 레거시 전수 품질 등급 분류 및 703편 확장.

## 절대 금지
- V1~V3 등록/요약 편수를 원문 기반 학습 완료로 표시하기
- 날짜, 발언, 숫자, 시간코드, 시청/화면검증 여부를 추정으로 채우기
- 과거 영상의 세제·투자상품 권고를 무검증으로 현재 조언에 승격하기
- 인간 검토 없이 자동생성물을 개인용 매매 지시로 사용하기
