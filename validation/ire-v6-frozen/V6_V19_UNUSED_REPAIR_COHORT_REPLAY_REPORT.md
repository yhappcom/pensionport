## 2. 발견한 실질 결함 — 한국어 혼합 금액 분해 오류

V18의 `NUMBER` 정규식이 원본의 다음 형태를 금액 하나로 보존하지 못했다.

- `2천만 원`을 숫자 `2`로 축약
- `2억 4천만 원`을 `2`와 `4`로 분리
- `18만9,000원`을 `18`, `9,000원`으로 분리

**V19 수정:** 숫자 + 한국어 자릿수(`천`, `만`, `억`, `조`) + `원`을 복합 금액으로 우선 인식하고, 기간·퍼센트·기존 숫자 토큰 규칙을 후순위로 보존한다. 공백만 다른 동치 금액은 허용하지만 금액의 자릿수·숫자나 년/개월 단위를 바꾸면 `HOST_ATOM_PROPOSITION_NUMBER_UNGROUNDED`로 거부한다.

**실제 1–70 원본 전체 56,045 cue를 V18과 V19로 비교 재생:** 숫자 토큰이 달라진 cue **145개 / 30개 영상**. 총 숫자 토큰 수 V18 **8,457개 → V19 8,415개**(잘못 쪼개진 금액들을 결합). 변동된 145개 cue 모두 새 토큰에 `원`을 포함했다. 이것은 **토큰화 재현 실측이지 금융 수치의 진실 입증이 아니다.** 기존 원본 SRT/manifest를 변경하지 않았다.

## 3. 원자 분할 오류 — 신규 원본 기반 회귀

`yDt8Ki7d_Yk`의 두 증여 시점 금액이 동일 cue에 나오는 원문으로 **고의 병합을 만든 실제 소스 기반 회귀시험**을 수행했다.

- 미분할 입력: **15개 ChatGPT/시험 후보**, 복수 금액이 하나의 원자로 앵커링된 cue의 새 `MULTIPLE_NUMERIC_TOKENS_SINGLE_OR_NO_CANDIDATE` frontier 경고 **1건**.
- 분할 후: **16개 후보**. 두 별도 원자로 분해되고 해당 frontier 경고 **0건**. V18 `audit_chat_atom_splits`의 원본 앵커 보존·기존 ID 퇴역·신규 ID·변경 없는 나머지 후보 확인 **PASS**, 무단 기존 원자 변경 **차단 PASS**.
- 새 탐지기는 **한 cue의 다수 금액이 하나의 주장으로만 붙을 때 보수적으로 검토 요청**을 만든다. 복수 숫자가 반드시 복수 원자 주장이라는 뜻은 아니다. 시험용 병합 사례를 모델이 자연발생적으로 저지른 새 FN으로 보고하지 않는다.

## 4. V14 원본 의미 위험 12건의 채팅 내부 재판정

동일 SRT를 다시 확인하고 V18의 위험 사례 SHA를 전부 보존했다.

| 처리 | 건수 | 의미 |
|---|---:|---|
| 조건·예외·부정 관련 실제 모델 문맥 보정 | **4** | 조건 2, 예외 1, 부정 태도 1 |
| 다른 원자·절의 취소/부정 표현으로 출처 구분 | **7** | 원시 경고 삭제 없이 연결 근거 기록 |
| 원래 경고를 명시적으로 OPEN 유지 | **1** | 한 cue의 반박 접속사와 집중투자 손실 서술이 결합된 사례 |
| **원래 12건에서 판정 누락** | **0** | 모든 원래 case digest 보존 |

위 수정 후 원시 V14 경고는 **12 → 9**(4개 모델 문맥 수정으로 제거, 별도 같은 cue 반대 태도 경고 **1개 새로 발생**). 발생한 신규 충돌 1건은 정확한 cue 안에서 *서로 겹치지 않은 두 직접 인용문*을 요구하는 V19 `SAME_CUE_DISTINCT_CLAUSES` 판정으로 별도 처리했고, 원시 경고 자체는 보존했다. 최종 **채팅 내부 미해결 의미 경고 1건** 및 **원시 경고 9건 보존**. 원문 소유 문장을 분리한 출처 검증일 뿐 외부 독립 의미 사실 판정은 아니다.

**금융 사실 위험(별도 OPEN):** 증여재산공제의 수증자·증여자·10년 합산·결혼/출산 추가공제 조건, 주식 증여가액의 평가 기간과 증여 취소, 연금저축 비공제 원금 인출 순서/과세, 지수 ETF와 액티브 ETF 구분, 수익률·금액의 실제 적용 가능성은 **법령 시행일과 개인별 적용 범위 대조 전에는 승인하지 않는다**. 모델 후보가 원문에 등장한 숫자를 정확하게 옮긴 것과 그 숫자가 현행 법령·금융상품에 맞는 것은 별개다.
