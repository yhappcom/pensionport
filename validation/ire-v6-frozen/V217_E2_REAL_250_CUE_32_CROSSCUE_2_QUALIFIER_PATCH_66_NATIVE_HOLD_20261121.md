**결론: 실제 원본에 대한 E2 신규 결함 1종 보완 및 원자 2개 범위 수정, 구조 PASS. 최종 의미 E2 HOLD.** 이전 V215.2·V216.1 비공개 원장을 변경하지 않았다. 공개 저장소에는 개인 자막/실제 의미 판정 텍스트를 저장하지 않는다.

## 5. 엔진 코드 개선과 RunFail 회피

공개 GitHub 검증 브랜치에 추가된 `v217_e2_private_crosscue_discourse_guard.py`는 다음을 실시한다.

- 원본·미승인 native·과거 source-only 관계의 원본 바이트 SHA가 다르면 **InvalidInput 차단**. 3종 모두 바이트가 없으면 다른 데이터로 조용히 대체하지 않는다.
- 교차 관계마다 원문 인용/자막 SHA 검문, 중복 관계 ID·비정상 인덱스·조작된 gold/승인 라벨 차단.
- 기존 동결 V6 native 감사 결과와 조합해 `SAME_ATOM_CONTEXT` / `CROSS_ATOM_DEPENDENCY` / `UNMAPPED_SOURCE_CUE_HOLD` 구분.
- 승인 인계 시 교차·unmapped 관계가 남아 있는 경우 **명시적으로 차단**. 설령 이 관계가 모두 해결돼도 독립 gold 없이 E2 PASS를 제공하지 않음. 기존 동결 V123/E4/E5 코드를 바꾸거나 실제 승인 경로로 자동 연결했다고 주장하지 않는다.
- 최대 2,000개 cue·512개 원자·1,000개 관계의 입력 제한. 큰 장편은 분할 처리 필요. 개인 원본을 공개 CI에서 읽지 않으며 합성 테스트만 실행한다.

새로운 테스트 `test_v217_e2_private_crosscue_discourse_guard.py` 15개를 E2 CI에 포함하도록 워크플로를 수정했다. 이전 기준 324개 + 신규 15개 = **총 339개 검사 예정**. 최종 CI 결과는 별도 실행결과로 확인하며, 예정 수치를 통과 실적으로 표현하지 않는다.
