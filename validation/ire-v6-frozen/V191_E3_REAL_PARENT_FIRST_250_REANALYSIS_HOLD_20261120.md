# V191 — E3 부모 발화 선복원 → 원자 분해 실제 영상 재분석 (HOLD)

**기준:** 2026-11-20 KST. **E3 정확성 미합격 / V123·E4 미수행 / E5=0**.

## 이전 구조 결함과 이번 변경

기존 V176/V183 E3는 개별 SRT 자막 위치에 원자를 먼저 부착했고, 서로 다른 자막에 같은 부모 문장이 걸려 있을 때 누락과 동치가 섞여 있었다. V189~V190에서 누락으로 신고된 12건 중 5건이 다른 자막에 이미 대응하는 원자로 나타났고, 부모 연결 65건 가운데 13건은 관련되지만 서로 다른 명제였다. 따라서 자막 유사도와 근접성만으로 부모 동치나 재현율을 확정할 수 없다.

신규 `v191_e3_parent_first.py`는 **부모 발화를 먼저 구분한 뒤**, 그 범위 안에서 독립 원자들을 **CHATGPT_IN_CHAT 원문검토로 직접 생성**한다. 이 신규 실행 관문은 기존 주장을 `prepare` 입력에 노출하지 않고 원본 자막과 주변 원문만 전달한다. 부모 발화와 원자 ID를 원장 이벤트 SHA에 연결하고, `DISTINCT_FROM` / `ELABORATES` / `CONTRASTS` / `CONDITION_FOR`의 원자 관계, 발화자 직접 조건, 검토자 추가 주의사항, 선행 가상 범위, 원문 숫자 인용을 분리한다.

모든 제출은 SRT SHA와 이전 1·2차 원장 헤드에 고정되며, 수정 불가능한 별도 소유자 비공개 SQLite 이벤트 사슬에 저장된다. 중복·누락 구간·위조 인용·인용 위치·숫자·조건·원본 범위·의미 검증 승인 위조가 차단된다. 별도 CLI `v191_e3_parent_first_cli.py`로 다음 Python 프로세스/채팅에서 안전하게 이어받을 수 있다. **과거 원장과 원자 후보는 수정하지 않는다.**

## 재현성 및 제한

- 합성 원문 시나리오에서 원자별 인용·숫자·조건 출처와 별개 명제 관계·기록 해시·중복·원장 훼손 차단을 검증한다. **합성 CI는 투자 정확도 평가가 아니다**.
- 실제 영상 전수 분할은 **이 대화 안의 ChatGPT가 작성한 새 의미 판정**이다. `prepare` 패킷에 이전 정답이 없더라도 연구 수행자가 프로젝트 경위를 알고 있으므로 **완전한 외부 독립 블라인드 정답셋이라고 주장할 수 없다**.

1. 부모 단위 36개와 1·2차 원자의 **내용적 동치 및 과잉 분할**을 사람이 재검문하여 다대다 동치·분리 평가원장을 만들되, 독립 정답으로 인증하지 않는다.

4. E3 합격 조건이 측정되기 전에는 E4·E5를 호출하지 않는다.
