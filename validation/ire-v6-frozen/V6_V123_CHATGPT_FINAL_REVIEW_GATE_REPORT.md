# V123 — ChatGPT를 신규 투자 연구 지식의 최종 검증·활용 관문으로 지정

**운영 기준:** 2026-11-15 KST. 사용자 결정 반영. GitHub 검증 브랜치·Draft PR #53 한정. `main`, Master116, P4, V5는 그대로 유지한다.

## 최종 단계의 책임과 승인 범위

앞선 V109/V119 합의에 따라 **연구 검토는 ChatGPT 채팅에서 수행**한다. 외부 사람·외부 모델 API·외부 신원기관은 채팅 내부 연구의 필수 조건이 아니다. V123은 순서를 더욱 엄격하게 고정한다.

1. **V6 엔진:** 원본 SRT/인벤토리/창 소유권 고정 → ChatGPT가 작성한 후보 원자 주장·조건·예외 입력 → 출처와 숫자·맥락·기존 지식 관계 점검 → V6 host_batch ACID 구조 저장. **소프트웨어 PASS는 최종 연구 승인 아님.**
2. **ChatGPT 최종 검증:** 원본 전체 cue·전체 원자 주장 재검토, 발화자 입장과 검토자 추가조건 구별, 조건·예외·반례·단위·기간, 원음/영상 OPEN, 금융 고위험 누락, 최신 법령 원문 본문 SHA·시행일·상품/계좌 적용범위를 판정하고 A/B 의견 차이를 조정한다.
3. **최종 판정:** `CHAT_FINAL_PASS_RESEARCH_CANDIDATES_ONLY`, `CHAT_FINAL_HOLD_OPEN`, `REJECT/OPEN` 등으로 구분한다. 하나라도 필수 항목이 OPEN이면 해당 전체 배치의 **신규 지식 후보 반출은 보류**된다. 자동으로 CLOSE/GOOD로 만들지 않는다.
4. **P1 읽기 전용 후보 확인:** 새 `preview_chat_validated_candidates`가 **반드시 최종 ChatGPT 검문을 먼저 실행**하고 PASS인 경우에만 기존 Master116/P4와의 읽기 전용 관계를 보여준다. 기존 내부용 `audit_prior_candidates`는 진위 승인·신규 연구 공개 인터페이스가 아니다.

## 실제 구현

- `ire/v6/chat_final_gate.py`: 기존 `audit_host_atomic_exchange`로 같은 원본·원자 입력을 **다시 실행**한다. 기존 `host_batch`의 소유자 원본 핀·원자 후보 해시·호스트 영수증과 **실제 DB 최신 HEAD·창별 증거 개수**·OPEN 상태를 교차 확인한다. 금융 주장별 공식자료 원문 바이트를 따로 제공받아 SHA-256을 재계산하고, SHA만 있을 때는 HOLD로 처리한다. DB 인스턴스나 현행 영수증이 없으면 최종 승인하지 않는다. ChatGPT 검토표는 원문 전수 cue와 원자 ID를 1:1로 연결하고, 내용·출처·화자·반례·숫자·금융규정 항목을 개별 기록한다.
- `ire/v6/chat_validated_knowledge_preview.py`: `require_chat_final_release`를 통과하지 못하면 P1 새 연구 후보 읽기 전용 진입도 차단한다. 기존 지식 자체를 덮어쓰지 않는다.
- 공개 영수증에는 **개별 자막 원문·개인별 메모·평가 문장을 쓰지 않으며** 원본/검토 SHA와 건수만 남긴다. 검토 본문 SHA는 변경 여부의 증거이지 **원문 의미의 진실성 또는 법령 원문 신원 인증의 대체물이 아니다**.
- 신규 합성 실험에서는 원본 V6 host_batch를 실제 호출해 최종 판정의 실패·성공·중복·오염·OPEN 처리를 확인한다. **합성 PASS는 실제 금융 사실 정식 승인도, 독립 정답셋 정확도 인증도 아니다.**

## 기존 V122 실물 데이터의 적용 판정

- 원본 ISA 만기 영상 **47 cue**, 고위험 금융 근거 **OPEN 12**. V114 5단계 재현과 V121→V6 입력 어댑터는 확인했지만, **실제 소유자 원본의 V6 host_batch ACID 저장 영수증 및 현재 DB HEAD 고정과 모든 금융 원문 적용성은 미확보**다.
- 따라서 현재 V122는 **`HOLD_MISSING_V6_HOST_BATCH_OR_STORE`**, 실제 소유자 V6 영수증이 준비돼도 금융 OPEN이 해소되지 않는 한 **`CHAT_FINAL_HOLD_OPEN`**이다. 이번 V123 정책과 합성 테스트만으로 V122 47 cue 또는 다른 영상의 기존 연구 사실을 소급 승인하지 않는다.
- V120/V121 내부 정밀도·재현율 값은 동일 채팅 내부 참조 기준이다. ChatGPT 최종 검증 통과 여부와 **외부 독립 정확도 인증·P0 GO·개별 투자자문 승인**은 별도 관리한다.

## 안전한 후속 실행

다음 비공개 실증은 실제 V122 원본을 `host_batch`에 소유자 인벤토리 핀·모델/검토 원장과 함께 재실행하고, ChatGPT가 실물 원자별 최종 검토표를 작성해 	12개 금융 OPEN을 확인·해소 가능한 만큼 처리하는 순서다. 해결 불능은 HOLD로 보존한다. 신규 영상은 기존 예측을 채팅 참조보다 먼저 봉인한 뒤 동일 규약을 적용한다.

**운영정책 결론:** 엔진·CI → ChatGPT 최종 의미/금융 판정 → (PASS일 때만) 읽기 전용 연구 지식 후보 검토. 외부 검토자는 필수 아님. 자동 금융 사실 승인 0건, Master/P4 자동 병합 0건, 개인 투자자문 자동 승인 0건, P0 NO-GO 유지.
