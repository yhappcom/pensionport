### 효과와 반례

- 우선순위 검토 관점에서 V96은 21개의 신호로 145개 인접 자막을 탐색하게 한다. **200개 전체 직접 검토 대비 55개(27.5%) 적은 입력 범위라는 것은 가상의 triage 수치**이지 실제 사람의 시간 절감이나 동일 검출력 보장이 아니다. 위험 신호가 없는 40-cue 창은 이 방식만 따르면 통째로 빠질 수 있다.
- 단일 채팅 모델이 전체 200-cue 원본을 먼저 읽고 기록한 잠정 유의 구간 20개 중 **8개는 위험 신호와 겹치지 않았다**. 따라서 V96 우선순위만으로 원본 전수 의미 검증을 대체할 수 없다. `12/20`은 **독립 재현율이 아니라 동일 모델 내부의 임시 비교 지표**이다.
- V91 인벤토리 자체도 200개 중 7개 cue가 부모 후보에 직접 매핑되지 않았다. 다만 미귀속 cue를 명시적으로 드러내고 확인 대상에 넣는 전수검문 원칙은 유지해야 한다.
- 숫자·조건·수정·의견·자산배분·개인 사례의 스코프를 구별할 필요가 있다는 점은 확인했지만, 20개 주석 중 실제 정답의 수, 오인식 진위, 투자 사실성을 인증한 것은 아니다.
