# V206 E2 — 현행 V176 원본 자막 전수 의미 검문 및 비공개 재개 기능: 부분 성공, 실제 의미 합격 HOLD

**작성:** 2026-11-20 KST  
**작업 위치:** E2 ONLY / PR #75 / `verify/ire-v6-e2-source-census-adversarial-20261120`  
**전제:** E1 합성 실제 소프트웨어 구조 PASS (PR #73). **E2 동결 기준**: "질문·의견·가설·금융 사실을 구분하고 조건·예외 보존".

## 1. 실제 발견한 원인과 수정

1. **원자 단위 E2 검사만으로 누락률을 판단할 수 없음.** 기존 V166 E2 의미 레저는 정식 V6 원자의 수만 전수 검사한다. 처음부터 V176의 `QUESTION`, `QUOTE`, `NON_RESEARCH`로 처리해 `NO_ATOM`이 된 자막의 숨은 금융 사실·인용 의존관계는 원장에 아예 없을 수 있다. **V206은 원본 SRT의 모든 cue를 직접 전수** 검문하고 원자 없는 자막에도 독립적인 E2 의미 분석/문맥·숫자 확인을 요구한다.
2. **질문 속 주장/인용된 금융 주장 누락**: 별도 합성 한국어 원문에서 질문 `ISA는 8%가 무조건 비과세라는 주장이 사실인가요?`, 인용 `모든 소득이 비과세된다고 누군가 말했습니다.`를 V176의 `QUESTION/QUOTE`로 처리하면 V6에 원자가 남지 않는다는 실제 코드 특성을 확인. V206의 독립적 ChatGPT E2 검토에서 `QUESTION_WITH_EMBEDDED_ASSERTION`/`QUOTE_WITH_FACT_DEPENDENCY` 및 원문 인용을 제출할 때 두 건 모두 `HOLD_EMBEDDED_ASSERTION_EXCLUDED_BY_V176`로 검출하며, 자동 금융사실/지식으로 승격하지 않는다.
3. **조건/예외 혼동**: 별도 원본 조건 `조건에 따라`, 예외 `한도 초과분`의 원문 자막 번호·인용문·SHA·조건/예외 별도 필드를 유지하고, 누락·조건/예외 교환·다른 출처 인용을 오류/OPEN으로 처리한다.
4. **원본 숫자 누락**: V6 원자로 뽑히지 않은 QUESTION에 같은 `8%`가 2번 나와도 **자막 전체 토큰 2회 위치**를 검문한다. 하나만 남긴 답변은 실패한다. ASR 수치 모호성/금융 수치 역할은 E2 ChatGPT가 별도로 표시해야 하며, 현실의 수치 사실 승인과 구분한다.
5. **원자 투영이 불가능한 일화의 침묵 누락**: 기존 V176은 `ANECDOTE`가 있는 원문 주장 자막을 `UNRESOLVED`로 처리해 정식 V6 원자를 0개로 만드는 경우가 있다. 이전 V206은 원자 수 불일치로 도전 과제 생성 자체를 중단했다. 수리 후 이 자막의 **원문 주장 전체를 재검토에 포함**하면서 `native_claim_id=None`, `UNSUPPORTED_ANECDOTE_NOT_IN_V6`를 명시하여 HOLD한다. 가짜 V6 원자는 생성하지 않는다.
6. **다음 턴 연속성/재실행**: 비공개 `PrivateE2CensusCheckpoint`는 append-only SHA chain, owner head/source/manifest SHA, cue 범위/정확한 응답, 0600 파일 권한, idempotent retry, 충돌 시 기존 판정 보호, SQLite 독립 재개 검사를 구현한다. 실제 사용자 자막·검토 본문은 GitHub로 내보내지 않는다. 변경 판정은 명시적인 별도 정정 메커니즘 없이 덮어쓸 수 없다. 외부에 별도로 고정한 private E2 head를 후속 재실행 시 대조해야 한다.

## 3. 절대 E2 합격으로 간주할 수 없는 이유

- **원본 실물 SRT 없음**: 이번 PR의 GitHub 코드/검증에는 사용자 소유 장편 #1/ETF 영상의 실제 개인 SRT 바이트와 원본 검토 SQLite가 존재하지 않는다. 현재 턴의 Library/Conversation 검색에서도 실제 원본 ZIP을 검증 가능한 연결 파일로 확보하지 못했다. 따라서 `1,481 cue / 13구간` 실물의 전수 독립 심사에 재현 가능한 원본 SHA를 붙일 수 없다.
- **독립 정답셋 부재**: 합성 한국어 판정과 Python 정합성·SHA 검문으로 실제 ChatGPT의 의미 오판/false negative를 측정할 수 없다. E2 본문 합격 기준은 오분류·누락·문맥 상실 0이므로 실물 원문 대비 독립 고정 검토/불일치 조정이 먼저 필요하다. 정밀도≥95%, 재현율≥98%, 고위험 누락0도 여기서는 측정할 수 없다.
- **수정 전원자 누락은 아직 실제 원장에 미보충**: V206은 Q/QUOTE 속 원자 누락을 발견하여 개인 source-hash-bound repair docket으로 넘긴다. 그러나 정식 V176/V6의 원자 구조를 자동 변경하거나 E1 approval/저장에 새로운 원자를 주입하지 않는다. **질문/인용의 복합 주장 분해 및 기존 결과와의 동치 검토**는 이어지는 E2 실제 원문 처리에서 명시적으로 완결해야 한다.
- **단계 엄수**: 비공개 E2 review 기록도 `e2_pass=False`, `e3_e4_e5_authorized=False`로 동결. 기존 V166 과거 E2 기록은 현행 V176 신경로의 실제 의미 전수 합격 증빙이 아니다.

## 4. 다음 E2 업무와 재합격 기준

1. 비공개 원본 SRT·V176 원장과 독립 `owner_head_sha256`을 현재 세션에서 읽을 수 있도록 확보하고 SHA 검문.
2. 전체 원문 cue를 20~40개 단위의 `prepare_e2_cue_challenge`로 분할하여 실제 ChatGPT가 전수 독립 판정. 매 배치의 `audit_e2_cue_answer`를 통과한 결과를 **비공개 E2 checkpoint**에 기록하고 외부 고정 E2 head를 확인.
3. `build_e2_source_repair_docket`의 질문·인용·일화·조건·반박 미해결 건을 원문 재검토해, 실제 소스 기록에 정식 append-only 수정을 남기고 다시 전수 대조. 단순 NO_ATOM/원자 패킷 문자열 일치로 PASS 금지.
4. 독립 사전 고정 골드와 ChatGPT 의미 판정 불일치를 정리하고 원자 누락/조건·예외/반박 정확성 검문. 실제 누락 위험 0과 추적 가능한 SHA·영수증 제시.
5. 이 모든 E2 증거가 완료될 때만 E2 PASS 후 E3 진입.

**공식 판정: E1 PASS (합성 구조만) / E2 IN_PROGRESS + HOLD_REAL_SOURCE_AND_INDEPENDENT_GOLD / E3~E5 NOT_RUN.** 개인 실제 자문, 최신법규 승인, 지식 출판은 없음.
