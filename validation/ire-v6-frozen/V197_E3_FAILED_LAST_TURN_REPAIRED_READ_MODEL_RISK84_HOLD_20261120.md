# V197 — 실패한 E3 2턴 교정 결과의 재현 가능한 읽기 모델과 고위험 84건 전수 차단

**상태: E3 HOLD / V123·E4 NOT RUN / E5 발행 0 · PR Draft, `main` 보존 · 2026-11-20**

## 개선 이유 및 실제 관찰

V194의 연구 1턴 CMA 영상 `cSNjKKdtp6M` (원본 336자막, V176 연구 원자 120)과 V195의 별도 사용자 메시지 E3 2턴(120원자 전수검문·28건 격리), V196의 원문 고정 교정 16건은 각각 실제 비공개 원장으로 보존된다. **V196 교정 16건은 아직 수정 제안**일 뿐이었다. 이전 구조에서는 이 제안을 downstream 연구 검토에서 원본·이전 E3 판정과 나란히 재현하여 확인하는 경로가 부족했다.

또한 V194의 원자 120건 중 고위험 표지 **84건**을 V195 판정과 재대조하니 **격리 28건 + 다른 HOLD 상태 고위험 56건**이었다. `QUARANTINE` 28건만을 위험 총수로 간주하면 56개가 관리에서 탈락할 수 있다.

## V197 수정한 부분

- `v197_e3_repaired_source_projection.py`: **동결한 V194 연구·V195 E3·V196 교정 원장의 실제 SHA 사슬을 처음부터 감사**한다. 120개 각 원자에 (a) 기존 발언, (b) 이전 검증 판정, (c) 교정 제안 여부, (d) 원본 인용의 SHA, (e) 격리 여부를 별도 읽기 전용 구조로 내보낸다. 기존 원자를 삭제·덮어쓰기·자동 병합하지 않는다.
- **16개 원문 교정 제안 표시:** 원문 표현 교정 **12건**(그중 위험 격리 1건은 격리 유지), 비원자 삭제 **제안만 2건**, 부모 관계 재검문 **제안만 2건**. 따라서 120개 원자와 28개 격리 수는 그대로다. A071의 `항상`→화자 표현 `조금 더 높습니다`, A099의 `0.5%p`→원문 `0.5%`는 **화자 발언의 재구성 제안**이며 금융 사실로 승인되지 않는다.
- **고위험 전수 보존:** 84개 고위험 원자마다 개별 원문 자막의 전체 텍스트 SHA, 1턴 원자 SHA, 2턴 판정 SHA, E3가 작성한 위험 사유, 차단 상태를 연결한 **비공개 위험 근거 작업 원장**을 구성한다. 28개 격리와 다른 HOLD 56개가 빠짐없이 OPEN으로 남는다. 
- `v197_e3_repaired_source_cli.py`: 사용자 비공개 3개 체크포인트 및 외부 SHA 영수증을 재확인하고 **읽기 전용** 자료만 생성한다. 개인정보나 인용문을 stdout에 출력하지 않는다. 결과를 0600 권한의 JSON으로 **한 번만 작성**, 해시 고정·수정 감지·재개 검증을 지원한다.
- 기계 승인 방어: 교정 제안을 근거로 고위험 주장을 금융 사실로 승격하거나, 28개 격리를 일반 HOLD로 완화하거나, 고위험 84개 중 1개라도 누락하거나, 비원자 제안을 근거로 기존 원자를 삭제하거나, 원장 SHA를 변경하거나, **공식 웹 페이지 조회만으로 원전 바이트·시행일 인증이라고 주장**하면 거부한다.

## 공식 근거의 확인 수준

공식 금융투자협회 CMA 업무관련 모범규준 웹텍스트: https://law.kofia.or.kr/service/law/lawFullScreenContent.do?historySeq=1379&seq=285 는 CMA가 예금과 다르고 예금자보호되지 않는다는 기본 설명, 발행어음의 회사 신용위험, RP·MMF 운용 위험 등에 대한 공개 참조 자료다. **조회 URL은 개별 84건 모두를 확정하는 증거가 아니다.** 각 CMA 유형·회사·시행일·화자의 주장 범위에 맞는 **원전 바이트 SHA/상품설명서 및 약관/유효기간** 검증이 별도로 필요하다. `official_document_raw_bytes_verified=false`, `product_specific_terms_verified=false`, `currently_applicable_fact_verified=false`를 전수 강제한다.
