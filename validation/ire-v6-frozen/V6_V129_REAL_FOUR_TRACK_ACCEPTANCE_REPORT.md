## 4. 누적 지식 기반 투자자문 E2E

- 실물 승인 지식 후보: 이번 장편 0건, 기존 V122 0건. 소유자 운영 지식 DB가 확인되지 않았으므로 실제 ‘누적 승인 연구 지식 → 현재 법령 → 사용자의 계좌 조건 → 자문’ 경로는 **현재 증명 불가**다.
- **테스트 질문:** “ISA 만기금 4,000만원을 연금저축계좌에 이체하면 300만원을 환급받나요? 그리고 기존 연구를 이용해 집중투자를 권할 수 있나요?”
- **ChatGPT 일반 교육적 정정(승인 답변 아님):** 추가 세액공제 *대상 납입액*의 상한은 300만원이며 소득에 따라 세액공제율 12% 또는 15%를 적용하는 경우 국세 기준 상한액 부분에 대한 산술 예시는 각각 36만원 또는 45만원이다. 300만원 환급을 약속하면 잘못이다. 실제 계좌 ISA 만료일·60일 전환·결정세액·기존 공제한도·적용자의 연령과 소득·다른 제한에 따라 결과가 달라진다. 집중투자 사례는 전문가의 조건부 원칙을 일반인에게 자동 추천할 증거가 아니다.
- **지식 시스템 판정:** 실물 승인 원자 주장과 사업자 원문 바이트·소유자 계좌 조건이 없으므로 이 질문에 대한 *실물 누적 연구 기반 자문*은 **HOLD**. 기존 V128 합성 2구간 ACID + V126 합성 Q&A 테스트 PASS를 실제 사용자 자문 품질 인증으로 대체하지 않는다.
