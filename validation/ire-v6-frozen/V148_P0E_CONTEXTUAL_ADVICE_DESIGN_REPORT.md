# V148 — P0-E 질문별 설명·계산·반례 검문 개선

**기준:** 2026-11-16 · 검증 브랜치만 수정 · P0-E와 전체 P0는 아직 NO-GO.

## 문제와 수정

V147.3 기준 실제 V5 P3 10개 질문 중 투자 교육 8개에서 필수 설명 키워드를 모두 포함한 답변은 2개였다. E03 집중투자, E06 부실기업, E07 성공확률, E08 반도체 사이클은 무관한 영화관 질문과 **동일한 268자 답변**이었다. 전체 V6 CI가 성공한 사실은 이 답변 결함을 해결하지 않는다.

V148은 기존 `ire/v5/advisory_answer_pipeline.py` 및 V5 지식/정책의 바이트를 변경하지 않는다. 새 진입점 `ire/v6/guarded_question_advisory_v148.py::explain`은 **실제 V5 P3를 먼저 호출·검문**하고, 오래된 법령 문구를 그대로 인용하지 않고 질문별 위험·예외·계산 설명을 **별도 교육 계층**으로 제공한다.

지원 교육 영역: ISA 일반 200만원/법정 우대 400만원(국가법령정보센터 2026-09-18 시행 조문 *웹 발췌*), 연금저축 600만원·IRP 합계 900만원(2026-07-01 시행 조문 *웹 발췌*), 집중투자/분산 SEC 교육, `억원×연간 수익률`과 `월간 필요액×12`의 분리 검산, 고배당과 안전마진 구별, 부실기업의 영구손실 가능성, 신기술 성공확률 가정, AI 수요와 반도체 재고·공급 순환.

**보호 조건:** 법령 수치는 **2026-11-16 기준에만** 웹 발췌 안내로 표기하며 이후 일자 요청은 재검증 필요로 차단한다. 법령 원문 HTTP 바이트, 발행자 서명, 개인별 소득·계좌 자격은 이번 코드가 인증하지 않는다. 원본 연구의 V123 13/13 실물 승인과 V128 지식 저장이 아직 없어 274개 잠정 영상을 승인 지식으로 인용하지 않는다. 매수·매도·송금·주문 지시는 차단한다. 독립 의미 정답셋, 정밀도, 재현율도 생성하지 않는다.

## 측정 계획

1. V147에서 결과 확인 **전** 고정된 기존 10문항·기존 SHA `c661be11f0c931b7abd1777e5abba9a7a9fa4fb62c55f487c476a4ecdfd61847`은 절대 변경하지 않는다.
2. V148 실제 실행 **전에** 8개 변형 문제를 별도 SHA `91b0355b749a2fdf2738fd0ff16ce98ac78442125d96e499c605a6e0ca5ddfda`로 고정한다. 이는 외부 독립 미노출 정답셋이 아니며 질문 변형 범위의 **사전 등록된 회귀 테스트**일 뿐이다.
3. `v148_quality_probe.py`가 18개의 실제 V5 P3 함수 호출, 기존 8문항의 조건·예외 단어 그룹, 8개 변형의 라우팅·단어 그룹, 매매 승인 0, 무관 질문 답변 SHA 충돌 0, 소요 시간과 원본 질문 SHA를 기록한다.
4. 단어 포함 검사는 문맥의 사실 정확성을 판단하지 못한다. 실제 `p0e_go`는 항상 false. 최종 합격은 **실제 승인 원본 지식 + 현행 금융근거 원문 바이트 + ChatGPT 독립 의미 판정과 전체 원문 gold + V23 실제 개인 적용성 E2E**의 별도 증거가 필요하다.

## 연구 정확도 한계

기존 실물 원본 `5NvtBlmt93Y` 1,481 cue 및 274개 V6 초안 중 72개는 상세 의미 정정 기록, 202개는 검토 미완료. 따라서 72/274는 검토 **범위**이지 precision/recall이 아니다. 13개 V123 승인 0, V128 승인 지식 0, 전체 gold TP/FP/FN 미측정이다. V148 교육 답변에 검증되지 않은 사용자 영상 내용이 들어오지 못하도록 분리한다.
