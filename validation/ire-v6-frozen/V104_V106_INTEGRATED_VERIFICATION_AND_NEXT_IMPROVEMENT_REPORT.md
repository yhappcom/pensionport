## V105 — 독립 블라인드 정답셋 생성 경로와 실제 차단 상태

- 사전 고정 비공개 원본 4개 창 **160개 cue**: #1 W00020, #3 W00008, #5 W00006, #7 W00065. 기존 직접 검토 구간을 배제하고 위험 신호 수준을 계층화한 고정 표본이다. 원본 창 SHA·출처 ZIP SHA·잠정 부모 후보 수와 과거 위험 이벤트 수를 판정 **전에** 잠갔다.
- 원문(비공개)과 별도로 **검토자 A/B 양식**을 생성했다. 각 검토자에게 위험 예측을 제공하지 않고 160개 원문 전체에 대해 '주장/비주장/원음 확인 OPEN' 및 원자 명제·조건·예외·위험을 독립적으로 평가하도록 요구한다. 불일치 조정자는 **별도 신원**이어야 한다. 신원 확인·Ed25519 서명·출처 완전성·전 cue 검토 및 동치 조정 후에만 정답셋 잠금이 가능하다.
- 엔진 추출 주장 ID와 골드 주장 ID의 일치 여부로 정답 처리하지 않고, **출처·입장·조건·예외를 따로 판정한 의미 동치 연결**을 요구하도록 채점기를 수정했다. 일반/최적화 합성 부정시험으로 허위 독립검토, 중복 인물, 예측 노출, 출처 위조, 동치 미승인을 차단한다.
- **현실 상태:** 실제 외부 독립 검토자 2명·조정자 1명의 판정 **0건**. 골드 승인 0건. **정밀도/재현율/고위험 재현율 `NO_SCORE`**. 사전 등록과 평가 양식 구축을 정답셋 완성으로 표시하지 않는다.

## V106 — 실제 6편 15,857 cue 로컬 처리 및 분리 측정

동일 비공개 원본을 사용하여 각 코드 단계 `perf_counter_ns`/CPU 시간 15회 측정. 측정값은 이 저장소의 해당 시점 로컬 실행 환경 결과이며 서로 다른 작업 단위의 시간이다. 구체적인 중앙값·p95는 동반 `V106_REAL_SOURCE_STAGE_TIMING_SHA_ONLY.json`을 참조한다.

- 원본 ZIP에서 6개 SRT 파싱 / V33 부모 분할 / V93 위험 탐색 / V104 좁은 다중 자막 연결 제안 / V98 우선·의무 검토 경로 배정을 **각각 실제 실행**했다. 이것은 기계적 소스 처리에 한정한다.
- 실제 공식 사이트 검색을 전후로 관측한 사용자 세션 경계는 **8.254129초**였으나 네트워크/도구/모델 대기시간 등이 혼재한 관측 구간으로, 순수 검색 latency도, 순수 채팅 모델 추론시간도 아니다.
- **채팅 의미 판정 순수 시간, 법령 적용성 심사 독립 시간, OPEN 해결 시간, 실제 별도 검토자의 시간은 계측 불가능하거나 미수집 → `UNMEASURED`.** 따라서 전체 영상 처리시간, 791편 완성 소요기간, 품질 기준 충족까지의 처리량 추정을 허용하지 않는다.

## 무결성·품질 판정

- 신규 소스 검문 코드·동일 소스 재현 실증·합성 회귀시험은 기록한다. 공개 저장소에는 원본 SRT와 개인별 의미 해석 전문을 공개하지 않는다.
- 사전 고정 V105 표본과 본문 V104의 이미 알려진 사례는 별도 집단이다. V104 사례를 V105의 독립 골드로 재사용하지 않는다.
- 금융 법령 적용 조건·개인별 소득 등은 일반 정보와 분리해 `OPEN`으로 남긴다. 공식 원장 V40/V75, Master116/P4, V5 자문 경로, `main` 불변.
- **기술 구현/자동화 무결성: 시험 결과 확인. 의미 정확도: 독립 `NO_SCORE`, P0 `NO-GO`, 신규 개인 투자자문 자동 승인 0.**

## 후속 개발 우선순위

1. V104를 다른 관계 유형(ISA 만기·과세연도, IRP 인출재원, 명목수익률·기간·현금흐름, 부정·화자 전환)으로 확장하기 전, 유형별 사전 고정 홀드아웃을 만들고 탐지 오탐·조건 누락을 검토한다. 특히 '자막 일부의 수식이 맞는다'와 '원문 전체 의미가 정확하다'를 구분한다.
2. V105의 외부 검토자 2명·조정자를 실제 확보하기 전에는 `NO_SCORE`를 유지한다. 독립 평가가 불가한 상황에서 내부 채팅 재평가는 '같은 모델 재검토'로만 표기한다.
3. V106 후속 단일 실행 오케스트레이터는 모델·검색·원음·OPEN 처리의 단계별 시작/종료 시각을 실행 환경에서 자동으로 기록하도록 한다. 비대칭 소요시간과 원문 길이별 표본을 확보한 뒤에만 791편 확장 비용을 추정한다.
