# V181 — ETF 실제 원본 250자막 신규 V176 네이티브 재검토

2026-11-19 KST. 연구 상태: **ACTUAL_ORIGINAL_NATIVE_SOURCE_FIRST_PASS / NO_GOLD / V123·E4 HOLD / E5=0**.

## 동일 원본의 복구와 자료 구분
- 사용자 소유자 원본 `1-100.zip` 안 `LVE7XN_esTc.srt`의 SHA-256 `e4aef32c007bc5e9f1ac6c3e18764ddc1b766e430893127cf98abe632c70301b`; 19,483 bytes/250 cue. 과거 V179 공개 기록의 고정 원본 SHA와 **동일한 원문**이지만 과거 V179 **비공개 250 판정 이벤트와 SQLite가 복원된 것은 아님**.
- 이번 V181은 현재 ChatGPT가 다시 원문 250개를 읽고 작성한 **새 판정**을 별도 V176 native SQLite에 저장한 독립 재검토 실증이다. 과거 62개 후보를 재생 또는 승인했다고 주장하지 않는다.
- 원본 SRT·비공개 판정문·SQLite·전체 checkpoint ZIP은 GitHub에 공개하지 않음.

## 실제 소유자 원본 V176 `prepare → submit` 실행
- 동결 `ire.v6.source.verify_source` 원본 SHA 및 125개씩 2구간 검증 PASS.
- 실제 V176 `EngineChatSession.prepare(source_first_only=True) → submit` 14개 배치로 원문 250/250을 첫 검토. 1~125 / 126~250은 별도의 Python 프로세스에서 기존 private SQLite를 이어 사용. **한 ChatGPT 턴에서 수행한 두 프로세스**이며 서로 다른 두 채팅 턴에서 정식 V176 DB 재개가 성공했다는 증명은 아니다.
- 최초 의미 판정: 주장 63, 비독립 발화 및 문맥 150, 질문 12, OPEN 25. 기존 결과와 의미 동치를 확정하는 독립 정답셋 부재.
- 동결 `ire.v6.atomic_exchange.audit_host_atomic_exchange` 실제 실행: 250/250 원본 열거, 숫자 출처 구조 검사 PASS, 63개 원자, UNRESOLVED 25, 누락 의심 NO_ATOM 57. 구조 PASS는 자동 의미 정확도 또는 금융사실 승인 아님.

## 실물에서 확인한 소프트웨어 문제와 수정
- 비주장으로 오분류된 독립 발화(104번 원문 인접 의미)를 원문에서 발견했지만 기존 `prepare_nonresearch_risk_revisit()`은 금융·조건 정규표현식에 걸리지 않는 자막이라는 이유로 **재검토 요청을 거부**했다. 이는 원본에서 직접 관찰한 lexical-risk filter 결함이다.
- 해결: 원문에 실제 존재하는 인용문과 충분한 ChatGPT 서술형 재검토 이유를 함께 제출하는 경우, 키워드 미탐지 자막도 새 재검토 작업을 발행한다. 원문 SHA와 기존 이벤트 및 현재 head를 다시 검증하고, 최종 판정은 append-only `submit_context_revisit()`로만 추가. 원래 `NON_RESEARCH` 판정은 수정·삭제하지 않음.
- 추가 소유자 원문 의미 재검토 6회(동일지수 상품, 가상 상품명, 극저보수 비교 등). **최종 새 네이티브 원자 69**, OPEN 25, 누락 의심 NO_ATOM 52. 최초 14개 + 추가 6개 = 총 **20개 이벤트**.
- 52개 누락 의심은 ChatGPT가 실제 자막 문맥을 대조하여 **50개를 인접 미승인 원자와 연결**, **2개는 기존 OPEN 원자문맥에 연결**. 이는 원문 연결표이지 외부 독립 판정 결과·재현율 증명이 아니다. 다른 키워드 미탐지 누락이 없다는 보장도 없다.
