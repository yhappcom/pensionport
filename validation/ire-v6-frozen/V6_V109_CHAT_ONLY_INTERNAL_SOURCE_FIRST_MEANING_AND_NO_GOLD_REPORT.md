# V109 — 외부 검토자 필수 조건을 제거한 채팅 기반 원문 의미 검증 실증

기준일: **2026-11-14 KST**. 원본은 소유자 비공개 `1-70.zip` SHA-256 `00024d54bbca57c8c9f528d3c6c2f4766052ad2dc37bf4f132280dbd223dd8fd`. 공개 산출물은 원본 발언·원문·개인적 해석을 포함하지 않는다. GitHub `main`, Master116/P4, V5/P3 및 이전 비공개 원장은 불변이다.

## 1. 개발 방향 정정 및 실제 실행

이전 V105–V107의 두 외부 검토자/조정자 필수 구조는 **현재 사용자의 ChatGPT 내부 연구 프로세스의 필수 요건이 아니다**. V109은 외부 검토자·별도 모델 API 없이 (i) 기계적 예측·평가범위 먼저 고정 → (ii) 같은 ChatGPT 세션의 원문 우선 1차 의미 판정 → (iii) 반례 중심 2차 재검토 → (iv) 발행기관 최신 공식자료와 연결 → (v) 결과를 SHA·출처가 있는 비공개 원장으로 보존하는 경로를 구현·실행했다.

이 과정은 **외부의 독립 블라인드 검증과 동등하지 않다**. 이후 외부 인증이 꼭 필요하다는 뜻이 아니라, 내부 평가의 한계를 설명하기 위한 구분이다. 독립 평가가 없는 동안 공식 정밀도·재현율·고위험 누락률을 `NO_SCORE`로 기록한다. 외부 신원 인증 없이 내부 연구는 지속 가능하지만 자동 금융사실 승인·개인 투자 주문은 허용하지 않는다.

### 평가 범위와 사전 고정

V105에서 원래 외부 미노출 평가용으로 고정했던 **4개 창·160개 원본 자막**을 이번에는 사용자 지시에 따라 **채팅 내부용으로 전환**했다. #1 `W00020`, #3 `W00008`, #5 `W00006`, #7 `W00065`. 원본창별 40개로 각 자막 번호·시각·해시 검증. **이 자료를 앞으로 새로운 외부 독립 블라인드 미노출 셋이라고 주장할 수 없으며**, 향후 그런 평가를 하려면 새 원본을 별도로 고정해야 한다. 원래 V105 파일 자체는 덮어쓰지 않았다.

비공개 원문 의미 판정 전 고정된 기계적 예측에서 자막 160개 중 **69개에 어휘·숫자·조건 신호**, **91개에 신호 없음**. 이 예측은 금융 오류 탐지 모델 또는 인증 평가가 아니다. 고정 SHA는 공개 `V109_PRE_REVIEW_LOCK_SHA_ONLY.json`과 소유자 비공개 패키지에 함께 보존했다.

## 2. 실제 1차/2차 의미 검토 성과

| 단위 | 검문 결과 | 해석 제한 |
|---|---:|---|
| 원본 자막 | **160** | V105 샘플, 전체 791편 대표성 없음 |
| V33 잠정 부모 발화 | **52** | 화자 의미·입장·적용 제한 수기 채팅 검토 |
| 부모 발화에서 누락된 큐 | **2** | 비금융 주장 부재 인증 아님; 별도 OPEN |
| 잠정 하위 원자 주장 | **28** | 선택 사례의 출처 연결 분할이며 전체 원자화 미완료 |
| 2차 반례·범위 제한 구간 | **19** | 같은 채팅 내부 평가, 독립 정답 아님 |
| 기존 사전 고정 기계 신호가 걸린 2차 구간 | **17** | 내부 범위 대조값. 민감도/재현율 아님 |
| 기계 신호가 없던 2차 구간 | **2** | 무신호 원본도 읽어야 하는 반례 |
| 외부 검토자 판정 | **0** | 사용자 요청에 따라 필수로 기다리지 않음 |

초기 부모 발화 입장 분류: `OPINION` 24, `HYPOTHESIS` 8, `CONDITION` 5, `FACT_CANDIDATE` 4, `QUESTION` 3, `UNCERTAIN` 1, `NON_FACT_DIALOGUE` 7. 담화/의견을 숫자·법령 사실이라고 오분류하지 않는 것이 핵심이다. 전부 정식 투자 지식으로 병합한 것은 아니다.

### 대표 반례와 실제 출처 대조

- **사적연금 1,500만원:** 영상의 연 1,500만원 초과 시 '전부 종합과세'라는 넓은 설명은 해당 사적연금의 **15% 분리과세 신고 선택 가능성**을 빠뜨린다. 국세청은 과세대상 소득원천과 이연퇴직소득을 구분하고, 원천징수세율도 수령 형태·연령에 따라 다르게 안내한다. 단일 `5.5%` 일반화 역시 제한. [국세청 종합소득·연금 안내](https://www.nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=7889&mi=6424), [국세청 연금 원천징수](https://www.nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=7888&mi=2312).
- **퇴직금 2억원 분할매수:** `2억원 ÷ 연 7천만원 ≈ 2.86년`. 반면 `2억원 ÷ 월 450만원 ≈ 44.4개월`이고 연 7천만원÷12는 약 583.3만원이다. **같은 시나리오라고 병합하면 부정확**하다. 해당 숫자는 화자의 예시이며 실제 주문 승인 아님.
- **배당·ETF의 원금 위험:** 배당 인출만으로 사망 시까지 투자원금이 유지된다고 확정할 수 없다. ETF 가격 변동 및 원금손실 위험은 [한국거래소 ETF 투자위험 안내](https://www.krx.co.kr/contents/OPN/01/01030205/OPN01030205T4.jsp)와 대조했다.
- **하이닉스 역사:** 2011 SK텔레콤의 인수 계약과 2012 최대주주·SK하이닉스 사명변경은 [SK hynix 회사 연혁](https://www.skhynix.com/company/UI-FR-CP05/)에 근거해 좁게 확인할 수 있다. 화자의 개인 고용 이력은 별도 주장으로 보관한다.
- **사회초년생 네 계좌·투자 과몰입:** 계좌 유형·한도 정보가 불충분하거나 개인의 의견인 발화를 확정 계좌 추천, 수익률 또는 행동지침으로 자동 승격하지 않는다.

이번 19건은 금융 사실 오류가 모두 독립 판정됐다는 의미가 아니다. 일부는 **필요한 예외와 위험을 누락한 경우**, 일부는 **화자의 주관·가정·ASR 불확실성**이다. 원음·전체 화면 표·별도 상품공시가 없어서 OPEN인 부분은 그대로 둔다.

## 3. 코드 및 평가 안전성

`v109_chat_native_eval_gate.py`는 원본 SRT/외부 SHA 잠금, V33 부모 ID·원본 연결, 160개 큐 전수 추적과 미귀속 2건, 1차 의미 주석 52건, 2차 출처 범위 19건, 선택적 원자 분할 28건, 고정 위험예측 및 공식 링크의 기관 도메인을 검문한다. 입력 원문을 바꾸거나 과거 V105 독립 미노출 지위를 유지한다고 위장하거나 정확도/승인을 허위로 쓰면 실패한다. 동일 채팅 내부 QA 완료는 허용하지만, **인간 독립 정확도 인증과 P0 GO는 계속 차단**한다.

신규 공개 합성·적대적 변조 시험은 일반 Python 및 `python -O` 양쪽에서 통과했다. 소유자 비공개 ZIP의 원본 자막·발화별 의미와 반례·원자 주장·재생성 스크립트는 GitHub에 올리지 않는다.

## 4. 실제 구조 처리 시간과 한계

같은 로컬 프로세스에서 원본/검증 단계별 `perf_counter_ns` 50회 반복. 본문의 수치는 공개 `V109_CPU_ONLY_SCOPE_TIMING_RECEIPT.json` 중앙값 기준(환경 의존). 이 중 선택 4개 영상 전체 SRT 파싱·V33 후보 재생성은 대략 **0.08초**, 기록된 채팅 1차·2차 원장 검문은 약 **0.002초** 규모다. 이 둘은 처리 내용이 다르다. 모델 추론/토큰 생성·브라우저 공식자료 검색·원음 확인·실제 회계자문·의견 정리의 사람/채팅 소요 시간은 분리 계측하지 못했다. 791편 완료기간 및 금융 의미 품질 향상을 이 데이터로 인증하지 않는다.

## 5. 남은 개선 우선순위

1. V110: **실제 채팅 중심 검토 경로**를 자동 재진입 가능하게 하고, 각 창 원자 주장 완전분해·수치·조건·전후 문맥 이어붙이기를 적용한다. '52 부모 모두 원자화'를 주장하려면 각 부모의 모든 주장·예외·화자 입장과 미귀속 큐를 검수해야 한다.
2. 단일 채팅 내부 평가를 독립 정밀도라고 부르지 않는다. **새 미검토 원본 창**을 계속 고정하고 최초 판정·반례 판정 차이 및 공식 발행기관 확인 결과를 동일한 프로토콜로 축적한다.
