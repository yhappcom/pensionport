## 5. 규모의 진짜 병목과 올바른 확장 방식

1. **선형 전처리와 누적 재개:** 소유자 원본 SHA/cue, V33 후보, source-window ID, run_id, 최신 Head, 공식 증거 큐를 단위별로 불변 저장하고 한 packet 실패 시 해당 packet만 보류. 영상 단위 결과를 매번 전체 재계산하지 않는다.
2. **의미 검토는 소형 packet:** 기본 원본 120 cue 이하 또는 3개 40-cue 창, V40 입력 한도 이하. ChatGPT가 하나의 packet에 대해 질문/인용/반박/조건/예외/시점/수치를 원자 주장으로 분리하고 출처를 보존해야 함. 단순 후보 생성은 완료 인정하지 않음. 초장편 90 packet을 한 턴에 끝내도록 강제하지 않는다.
3. **검증된 지식 재사용:** 과거 116 승인 지식과 새 영상 간 동치/충돌 후보를 찾고 각 주장에 원본 출처·현행 규정·적용일을 묶는다. 단순 반복 영상은 출처별 검문을 유지한 채 중복 사실 확인 비용을 줄인다. 제목/유사 문자열로 의미적 동치·세법 적용을 자동 승인하지 않음.
4. **유형별 처리:** Shorts는 짧지만 세액·연금의 핵심 수치가 있어 안전 예외를 부여하지 않는다. 몰아보기/재편집은 원본 일치 범위를 대조해 중복 출처를 명시하되 고유 주장·변경된 시점·예외를 생략하지 않는다.
5. **중간 검증 게이트:** V58 130창 1차 검토와 **진짜 원자 주장 누락 제어**를 구분. 역사적 108창 미확보 DB를 원장 실물 복구하거나 새 실험 lineage로 정직하게 재실행. 다음 5편→10편→30편→60편의 실제 완전 연구 성과/고위험 FN/법령 시점 오류/CI를 판정하고, 실패하면 확대 중지.
6. **품질의 최종 경계:** 외부 독립 사람 gold가 없어 현재 9편/6,829cue의 엄격한 블라인드 TP/FP/FN 평가는 미측정. ChatGPT 내부 정답 비교는 개발 지표이지 독립 P0 GO가 아님. 개인별 매매·세금 확정 추천/자동 Master116 병합 없음.

**대량 연구의 성공 조건은 791개의 '완료' 표시가 아니다.** 각 원본 소스와 근거가 지식 노드로 안전하게 합쳐지고, 미해결 주장과 개인 적용 제한이 검색/자문 경로까지 유지되는 것이다.
