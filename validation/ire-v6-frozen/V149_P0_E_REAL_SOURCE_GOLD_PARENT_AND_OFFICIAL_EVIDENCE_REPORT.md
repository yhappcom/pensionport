# V149 — P0-E 연구 정밀도·부모 승인 지식 조회·현행 공식 금융근거 실물 개선

기준 2026-11-16. 대상 영상 `5NvtBlmt93Y`. GitHub 검증 브랜치, `main` 및 기존 V5/V6 동결 승인 자료와 개인 포트폴리오는 수정하지 않는다. **최종 P0-E NO-GO**.

## A. 의미 정밀도: 전체 승인 여부가 아닌 실제 내부 블라인드 구간 평가

- 원본 SRT 1,481 자막 SHA256 `638fefee007aa9122e68717b922194410ebbd7913a619bb9354f09af14468a0d`; V145 정식 후보 원자 274개.
- 원자 `context_cue_indices`로 직접 참조한 자막은 1,227개, 미참조는 **254개**. 미참조 254개에는 숫자 표현 1개, 부정·위험 표현 17개, 조건·예외 표현 20개(중복 가능)가 있음. 이들은 **잠재적 누락 후보**이지 자동 FN이 아니다. 모든 미참조 자막은 원문 SHA 및 검토 필요 상태로 비공개 대기열에 저장.
- B0013 자막 1441~1481 (41개)을 **기존 C00270~C00274 상세 원자 내용을 열기 전** 원문만으로 다시 분류하고 SHA `10e79f4afe68e8bd211ef370f734642bc57aa2190cb3528c2526014c32cd6db1`로 고정한 뒤, 기존 V6와 비교. 이는 **동일 ChatGPT가 기존 프로젝트 문맥은 알고 있는 내부 source-first 평가**로, 외부 독립 검증은 아니다.
- 투자 내용의 구별 가능한 6개 원자 후보 vs 기존 V6 5개. 엄격한 1:1 완전 의미 등가 기준으로 `TP=4`, `FP=1`, `FN=2`, 고위험 `FN=1`; 내부 구간 **정밀도 80.0% / 재현율 66.7%**. 결합된 C00270 하나가 서로 독립적인 (a) 비싼 가격에 큰 금액을 일괄 투입하는 위험, (b) 확신 없는 집중투자의 위험을 한 번에 주장해 세부 원자 단위 불일치 발생. 이 수치는 **41개 자막의 부분 내부 평가**로 전체 1,481개 정밀도·재현율 추정이 아니다.
- C00274는 독립적 투자판단 문맥 1464 자막 참조가 빠져 있음. 수정에는 **새 V6 원자 교환·실물 호스트 영수증**이 필요하며 기존 영수증을 수정·소급 승격해서는 안 됨.
- 전수 gold는 `source_cues` 1,481개 원문 해시/역할, 비교 가능한 원자 단위의 gold/예측 주장, 모든 미매칭을 FP·FN으로 판정한 ChatGPT 검토 영수증을 필요로 한다. V149 코드는 전체 cue 범위·해시·원자 1:1 매칭을 검문하고 합성 장난감 정답으로 전체 P0 합격을 내지 않는다. 아직 **전체 전수 gold 부재, P0-E 정밀도 95%·재현율 98%·고위험 누락 0 인증 불가**.

## B. 승인 지식 기반 자문: 실제 비공개 DB와 합성 정식 발표 영수증 분리

- `v149_owner_approved_evidence.py`는 V126 `PrivateKnowledgeStore`의 비공개 DB HEAD와 V128 `parent_publications` 증명, 소스 정체성, 부모 ChatGPT 승인 SHA, 자식 배치 SHA, 저장 이벤트 경계를 검증한 뒤 **해당 부모가 실제 저장한 ACTIVE 지식 ID만** `evidence_for_question`에 전달한다. 다른 부모 지식·격리·미승인·REVOKED 후보는 선택 불가.
- 실제 V145 비공개 소유자 HOLD DB 복사본 검사: 지식 **0**, 부모 발행 **0**, HEAD 제로. 질의는 `NO_RELEASED_RESEARCH_KNOWLEDGE`로 거절. 허위 V123 PASS / V128 발행 / 포트폴리오 답변을 생성하지 않음.
- 합성 원본 + 실제 V128 트랜잭션 엔진의 2구간 발표 테스트는 **정상 승인 부모 지식 조회만 허용**, 부모 SHA·HEAD·원본·선택 지식 위조 및 13구간 미충족은 거절. 이는 엔진 경로 테스트이지 **실물 13구간의 ChatGPT 승인**이 아니다.
- 증거 조회 결과도 최종 금융 자문이 아니다. 이미 있는 `v126_chat_research_answer_bridge`의 실제 ChatGPT 답변 검토와 재조회 당시 최신 법령 검증을 거쳐야 한다. 원문 SHA 검사는 투자 적합성·의미 정확도를 증명하지 않는다.
