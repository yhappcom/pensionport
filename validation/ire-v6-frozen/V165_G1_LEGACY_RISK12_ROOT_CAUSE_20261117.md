# V165 — G1 고위험 12건의 실제 생성 원인 규명 (실물 비공개 원장·생성 코드 대조)

## 중요 정정

기존 V164에서는 `unresolved_high_risk_omissions=12`를 *'별도로 식별된 누락 위험 사례 12건'*으로 전제하여 원자와 별개의 12사건 원장을 요구했다. **실물 V160 생성 코드와 당시 ChatGPT 검토 행을 대조하니 이 전제는 부정확하다.**

V160 소유자 패킷의 `run_v160_v123_full_source_first.py`는 실제로 아래 식으로 필드를 생성했다.

```python
'unresolved_high_risk_omissions': sum(
    r['high_risk'] and r['status']=='OPEN' for r in atom_rows
)
```

따라서 12는 **당시 위험으로 분류되고 OPEN인 기존 원자 12개의 수**였으며, 독립 검문자가 검출한 실제 원자 추출 누락 12건이 아니다. 독립 고위험 FN(미검출 위험 주장) 평가와 구분해야 한다.

## 직접 재계산한 값

| 지표 | V160 실제 원장 | V164 실제 원장 |
|---|---:|---:|
| B0001 원자 | 15 | 16 |
| OPEN이고 `high_risk=True`인 원자 | **12** | **8** |
| `unresolved_high_risk_omissions` 저장값 | **12** | **12 (이전 값 잔존)** |
| V123 `high_risk_open` 합성 집계 | **24** | **20** |
| 별도 누락 위험 12사건 ID 원장 | 생성 근거 없음 | 생성 근거 없음 |
| 독립적인 원문 고위험 FN=0 인증 | 없음 | 없음 |

V160 원장 재계산에서 `12 OPEN & high_risk` + 동일한 원자 수에서 유래한 `omissions=12`가 합쳐져 24가 됐다. V164에서 OPEN 고위험 원자는 8개로 바뀌었지만 옛 카운터 12가 그대로 남아 20이 됐다. **중복/시차 집계 문제**다.

V160의 12개 원자 ID:
`C00001`, `C00002`, `C00003`, `C00006`, `C00007`, `C00008`, `C00009`, `C00010`, `C00011`, `C00012`, `C00277`, `C00285`.

V164 현재의 고위험 OPEN 8개:
`C00001`, `C00002`, `C00003`, `C00009`, `C00010`, `C00277`, `C00285`, `C00293`.
V160 기준 5개는 OPEN에서 벗어났고, 새로 복구한 `C00293` 질문이 들어왔다. OPEN 종료가 사실 인증을 의미하지 않는다. 원문 확인·근거 수용·명시 격리의 처분 유형을 각각 유지해야 한다.

## 승인 관문에 미치는 영향과 수정 방향

1. **현재 OPEN 고위험 원자**와 **원문에 존재하지만 누락됐을 가능성이 있는 고위험 발화**를 반드시 별도 계측 필드로 분리한다. 전자는 현재 원자/판정에서 재계산, 후자는 전체 cue 원문 우선 검문에서 구체적 사건·근거를 추출한 뒤에만 판단.
2. 기존 `12` 카운터를 그냥 `0`으로 수정해서는 안 된다. V160 기록은 역사적으로 보존하고, 새로운 정식 계약에서 `legacy_derived_open_risk_atoms=12`, `current_open_risk_atoms=8`, `high_risk_omission_cases=UNKNOWN/검문중`처럼 출처를 분리한다.
3. V164의 `risk_reconciliation`이 **기존 12개의 별도 고위험 누락 사건**을 강제하는 전제를 고친다. 필요 시 12개 과거 OPEN 원자의 상태 변화 증거를 검문하되, 독립적인 누락 사건 12개를 조작해 채우지 않는다.
4. B0001 cue 1~120 전수를 대상으로 기존 12개와 새 `C00293` 및 기타 위험 표시를 대조해 **실제 누락·조건 소실·반박·화자 오인**을 별도 발굴하고, 미해결 누락을 실물 원장으로 결정한다.
5. 이 후에도 V126 `require_chat_final_release`와 V128의 버전 미연결 문제는 남는다. 이 카운터 개선 하나를 영상 완료나 금융 사실 승인으로 오인할 수 없다.
