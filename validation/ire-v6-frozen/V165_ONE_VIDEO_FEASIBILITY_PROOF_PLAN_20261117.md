## 4. 운영 규칙과 중단 조건

- B0001에서 **증거 원장 1회 완성 + 정식 승인 경로에 대한 실물 실행 최대 2회**를 수행해 원인별 개선 전후 차이를 비교한다. PASS가 발생하지 않으면 구조 변경 필요성을 판정하고 기존 방식에 같은 유형의 보조 계층 추가를 멈춘다.

- 자료 접근 불능 자체는 소프트웨어 결함이나 정확도 실패로 둔갑시키지 않는다. 반면 실제 원본·코드 실행이 불가능하면 "실물 증명"을 달성했다고 기록하지 않는다.

- 새 기능 개발은 관찰된 구체적 실물 실패와 연결된 최소 수정만 허용. 모든 변경에는 반례 시험/수정 전후 영수증/회귀 비교를 첨부한다.
- GitHub 공개 브랜치에 소유자 원본 SRT, 원자 전문, 개인 정보, 비공개 SQLite/패킷을 올리지 않는다. 실제 원본 실증 산출물은 사용자 권한 범위의 비공개 위치에서만 재생한다.
