# V40 — V39 검문기 원자적 체크포인트 연구 경로 연결

**기준일:** 2026-11-11 KST. **부모 V39 HEAD:** `470bdefc64c93d3ff66ba5456cc8022c454d5c2f`. **작업 범위:** `verify/ire-v6-p1-atomic-host-batch-20261109` Draft 검증 브랜치. `main`·V5·기존 승인 지식 116건·P4는 변경하지 않음.

## 1. 필요한 연결과 실제 구현의 경계

이전 V39의 `audit_host_semantic_custody_v39()`는 원본/후보 일치성·의미 메모 건수를 **계산하고 반환**하지만, 실제 파일 원장으로 체크포인트를 보존하거나 창 중복 등록을 거부하는 전용 저장단계는 없었다.

V40 신규 `ire/v6/semantic_checkpoint_v40.py`의 `PrivateSemanticCheckpointV40.submit()`을 **공식 ChatGPT 의미검토 중간 단계 진입점**으로 추가했다. 이 함수는 현재 대화의 모델이 작성한 비공개 발화 분류를 입력으로 받고, ① V37 독립 고정 원본·창 SHA와 ② V33 후보를 다시 계산하는 V39 검문을 **먼저 통과시킨 후** ③ 비공개 SQLite 체크포인트 및 원본창 소유권을 **단일 트랜잭션**으로 저장한다. 원문 전문·개별 의미검토 문장은 SQLite 및 반환 영수증에 넣지 않고 **원본 SHA, V39 영수증 SHA, 창 ID, 집계 수치만** 저장한다.

동일 `run_id`+동일 증빙 재실행은 **idempotent**, 다른 증빙으로 같은 `run_id` 재시도는 차단한다. 중복 창·오래된 `expected_head`·원본 조작·후보 누락·허위 독립 정확도 승인은 저장 전 차단. 중간에 예외 발생 시 전체 SQLite 쓰기를 롤백하며, `verify_chain()`은 SHA 원장 및 창 소유권 목록 변경을 탐지한다. 한 요청은 **1개 원본 영상·최대 4개 40-cue 창·최대 160개 후보**로 제한한다.

**적용 범위 주의:** 이 연결은 V6 모델/원자 주장/기존 지식 통합 이전의 **ChatGPT 잠정 발화 의미검토 준비 단계**다. 기존 `one_turn_host.py`·`host_batch.py`는 역사적 SHA 보호를 위해 그대로 보존한다. 두 경로를 결합해 금융사실 완전성 또는 자동 자문 승인까지 수행한다는 주장은 하지 않는다.

## 2. 실제 비공개 원본 종단간 스모크

연결된 Google Drive 소유자 원본 `1-100.zip` SHA256 `088869c583b2d3ed93d68e4dd5348b1f506877ea2bdc1d66466c199ec80e7716`, 기존 V37 고정 #1·#2 SRT 원본 SHA와 6개 창/후보 해시를 실제 재대조. 과거 V38.2·V38.3의 비공개 ChatGPT 분류 원본을 V39 검문에 통과시켜 V40 체크포인트 2건을 새로 생성했다.

| 비공개 소스 | 창 | 자막 cue | V33 후보 | 의미 메모 | 체크포인트 |
|---|---:|---:|---:|---:|---|
| #1 `sz5N9WJS310` | 3 | 120 | 37 | 62 | SHA-only ACID PASS |
| #2 `6VEfKF7BzZU` | 3 | 120 | 41 | 59 | SHA-only ACID PASS |
| **합계** | **6** | **240** | **78** | **121** | **2건 PASS** |

동일 요청 재실행에서 **중복 창 0**, SQLite 파일의 원문 발화 문자열 유입 **0건**, 각 영상의 `verify_chain` PASS를 확인했다. 이 과정은 동시성·원본 무결성·저장 트랜잭션 검증이지 영상 주장의 참값 검증은 아니다. 공용 저장소에는 [SHA-only 영수증 경로](V6_V40_ACTUAL_OWNER_6WINDOW_SEMANTIC_CHECKPOINT_SHA_ONLY.json)를 남기고, 비공개 SQLite 자체 및 영상/의미 원문은 업로드하지 않았다.

## 3. 소프트웨어 회귀 검증

V40 추가 합성시험 **16개 로컬 PASS**, V39 기존 **595개** 발견 가드를 **611개**로 확장(새 V6 코드·시험 파일 정확히 2개 추가, 100→102개). 신규 시험에서는 정상 저장·완전 재실행·내용이 달라진 재시도 차단·오래된 HEAD·창 중복·누락·원본/창 SHA 변조·허위 금융 승인·중도 실패 원복·저장 후 임의 데이터 변조 탐지·개인 자막 원문 유출 차단을 확인한다. 역사적 V37/39 매니페스트·테스트 기대값은 보존하며 V40 전용 추가 매니페스트로 SHA를 고정한다.

GitHub의 **최신 정확한 커밋**에 대한 V6 전체/클린룸 CI는 별도로 최종 확인한다. 실제 비공개 원본에서 새 독립 정답셋을 생성한 것은 아니며, 전체 130창 연구·원자 주장의 참/거짓·법령/상품 실제 적용은 아직 별도 수행 대상.

## 4. 남은 과제 및 평가

- V40 중간 체크포인트 경로는 실행 가능. 다만 전체 130창 중 6창의 선별 **잠정 의미 분해**만 재검증 완료, **124창·1,525개 V33 후보 미처리**.
- **8건 과거 음성·발행사 특정 원천증거 미해결**, **9편 독립 블라인드 정답 및 정밀도·재현율 미측정**.
- V40 중간 검문이 통과해도 기존 V6 최종 모델/증빙 저장에는 아직 **V39 검문 SHA를 필수로 묶는 연결이 없다**. 두 번째 연결은 정식 원자화·지식 동치 시험 후 별도 구현.
- 기존 116건 및 P4 자동병합·개인 금융자문 승인 없음. `P0_GO=false`.

**판정:** 소유자 원본 → V33 발화 분할 재현 → V39 채팅 의미 검문 → V40 원자적 중간 체크포인트 저장·해시 재검사 **실제 2영상/6창 PASS**. 독립 금융 연구 품질 **P0 NO-GO**.
