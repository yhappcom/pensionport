# V125 — 연구 엔진 완성 선행 및 포트폴리오 연계 후순위 정책

**사용자 최종 요구(2026-11-15 KST)**: *먼저 V6 투자지식 연구 엔진을 완성·검증한다. 그 이후 새로운 영상 연구가 가능하다. Google Drive 포트폴리오 연계는 엔진 완성 이후다.*

이 문서는 [현행 ChatGPT 최종 검문 정책](V6_CURRENT_CHATGPT_FINAL_APPROVAL_PROTOCOL.md)을 변경하지 않고 **완성 기준/단계 순서**를 추가 명시한다. [기계판독 정책](V125_ENGINE_FIRST_PORTFOLIO_DEFERRED_POLICY.json)과 CI 검사를 함께 보존한다.

## 운영 순서 (엄격)

**Phase E — V6 연구 엔진 개발 및 완료 검증 (현재)**

원본 SRT 전체 구간 → ChatGPT 원자 주장·문맥/조건/예외/반박·수치 의미 검토 → 공식 금융근거 바이트·시행일·적용범위 검색/검증 → V6 ACID 저장 → **ChatGPT 최종 판정** → 기존 지식 116개 및 P4 29개와 개념·관계 수준 동치/확장/충돌/대체 판정 → 승인된 주장만 별도 **누적 지식 저장소에 영속 반영** → 질문 시 누적 지식·최신 규정 검색 및 근거 제시형 투자/연금 자문. 이 전체를 **한 사용자 요청에서 중단/재명령 없이** 끝내거나, 미충족 시 근거가 남는 명시적 HOLD/OPEN으로 종결하는 것이 목표다. 외부 LLM API, 외부 검토자 인증을 필수로 요구하지 않는다. ChatGPT 채팅이 연구 품질 최종 검토자다.

아래 10개 검증 조건을 실물 원본·독립적 재현 가능 로그·회귀테스트로 입증하기 전에는 **엔진 완성 선언 금지**. 단순 코드 작성/CI 통과는 완성 조건이 아니다.

| ID | 필수 완료 조건 | 현재 상태 |
|---|---|---|
| E1 | 120 cue를 초과하는 실제 전체 영상도 소유자 승인한 분할·창/원본 무결성으로 한 요청에서 처리·종결 | OPEN — 현재 `one_turn_host`는 기본 120 cue 초과 시 차단, `full_video_segments`는 제안만 생성 |
| E2 | 전체 cue의 원자 주장·발화자·부정/반박·조건/예외·숫자 결합을 ChatGPT가 검증, 의미 누락·오류 측정 및 OPEN 보존 | OPEN — 47 cue 실증은 구조 귀속 검증이지 완전 의미 재현율이 아님 |
| E3 | 신규 금융 주장마다 최신 공식자료 원문 바이트·시행시점·상품·계좌 적용성 검증, 근거 부재 시 자동 보류 | OPEN — V124.1 금융 OPEN 12 |
| E4 | 사용자 보유 비공개 SRT·인벤토리 핀과 V6 실제 운영 저장소 HEAD·복구/재실행을 원본까지 재검증 | OPEN — 이전 실증은 격리 DB |
| E5 | 모든 원자 주장에 대한 ChatGPT 최종 승인/수정/반려 증거 및 최종 판정이 저장과 반출을 통제 | OPEN — 관문은 존재, 실물은 HOLD |
| E6 | 승인 지식의 **영속 누적·조회** 및 원본 영상/창/자막/공식 근거/검토 이력·변경 이력 추적 | NOT_IMPLEMENTED — 현재는 P1 읽기 전용 미리보기 |
| E7 | 기존 116+29 및 이전 승인된 신규 영상 지식과 의미 동치·중복·확장·충돌·최신 규정 대체 판정, 원본 변경 없이 누적 | NOT_IMPLEMENTED — 기존 검사는 pending relation/원본 신원 검문 |

| E10 | 다양한 길이·주제의 **기존 확보 시험 원본**으로 실물 통합 수용검사 + 전체 CI PASS, 과도한 시간/예산 없이 재현 | OPEN |

E6-E8이 특히 중요하다. **ChatGPT 확인 후 연구 결과를 계속 쌓고, 그 지식을 사용자의 질문에 검색·활용할 수 없는 엔진은 미완성**이다.

**Phase R — 새 영상 연구 확대 (E 전부 완료 후)**

전수 연구 시작 전 E1-E10 수용검사를 통과해야 한다. 신규 영상 연구 결과가 쌓여도 모든 저장·반출은 ChatGPT 최종 관문을 재거친다. 여러 영상·기존 원장 간 중복 및 충돌이 지속적으로 검문돼야 한다.

**Phase P — 포트폴리오 연계 (E 완료 후, 별도 개발 단계)**

Google Drive KIS 포트폴리오 최신 잔고/원금·현금흐름/상품 분류를 확인하는 어댑터, 자문 시점 데이터 신선도 및 원금 완전성 차단, 사용자별 투자 목적·기간·위험 수용도·현금흐름 검토 등은 **Phase E 작업 범위에서 제외**한다. 기존 Drive 문서를 읽어본 사실만으로 통합 구현 착수나 승인으로 판정하지 않는다. Phase P의 초기 구현은 읽기 전용이며 포트폴리오 변형·자동 주문/송금 권한은 부여되지 않는다.

## 개발 착수 순서

1. **P0-A:** 실제 장편 영상의 소유자-고정 전체 창을 하나의 요청에서 분할 실행/복구하고 ChatGPT 최종 관문까지 연결한다. 한 창만 성공하면 전영상 완료가 아니다.
2. **P0-B:** V123 최종 판정 PASS가 난 후보만 별도 ACID 누적 지식 원장에 저장하고 다중 영상 중복·충돌·버전 추적·철회 원칙을 구현한다.
3. **P0-C:** 현재 자문 V23/V24 경로에 **누적 승인 지식 출처 검색**을 결합하고, 현재 금융법령 검색 및 ChatGPT 최종 응답 검문을 거친다.
4. **P0-D:** 기존 확보 원본으로 전체 종단간·결함 주입·신뢰성·처리량을 실측, OPEN/NO-GO의 강제 차단을 유지한다.
5. **E1-E10 전부 통과 이후만** Phase R 승인, Phase P는 이후 사용자 지시에 따라 시작한다.

## 이번 변경의 범위

정책·회귀검사만 추가. **새 영상 연구 수행 없음, Google Drive 읽기/쓰기 개발 없음, 기존 계좌 데이터 수정 없음**, `main`/V5/Master116/P4 또는 동결 V6 엔진 구현 변경 없음. 기술 완료 결과를 과장하지 않는다. 정책 자체와 별도로 엔진을 구현·실증해야만 E를 PASS로 판정할 수 있다.
