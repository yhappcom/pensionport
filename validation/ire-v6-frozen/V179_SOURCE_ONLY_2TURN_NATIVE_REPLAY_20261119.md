## 실물 엔진 재생 RED → 최소 수정 → GREEN

1. GitHub Actions **공개 Python 코드만** 별도 ZIP artifact로 내려받아 로컬에서 실제 V176 `EngineChatSession.prepare → submit`을 수행했다. 사용자의 SRT/SQLite/채팅 판정 원문은 GitHub 또는 Actions에 업로드하지 않았다.
