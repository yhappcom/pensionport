# V169 E4 — 채팅 내 원자 검토 영수증의 중단/재개 및 실제 원본 감사

기준일 2026-11-18. 기존 V168 PR #56 후속 검증. **동결 V123/V126/V128 및 보호 `main` 미변경**. V166 E1–E3 PASS, E4 FAIL, E5–E7 NOT_RUN 상태 유지.

## 발견한 실행 결함
V168의 `run_v168_one_turn_review`는 동기 콜백 일괄 성공을 전제로 한다. 처리 도중 채팅 실행이나 근거 검색이 실패하면 원자별 진행 위치 및 완료된 증거를 안전하게 복구하는 비공개 내구성 원장이 없었다. 모델 API를 사용하지 않는 정책에서 Python은 ChatGPT를 독립 호출할 수 없으므로, **채팅 주도 실행기**가 원본 고정 작업을 읽고 ChatGPT 판단을 입력하는 경로가 필요하다.

## 구현
- `v167_chat_research_loop.execute_chat_review_round(..., start_after=...)`는 **원래 전체 docket SHA를 유지하며** 작업 순서를 변경하지 않고 명시한 원자 다음부터 제한된 수만 처리한다.
- `v169_chat_research_journal.ChatReviewJournal`: 비공개 SQLite 권한 0600, 부모 원본·docket 버전 고정, 완료 순서 및 원자 SHA 재검증, 연결된 SHA 영수증, 배치 전체 `BEGIN IMMEDIATE`·COMMIT/ROLLBACK, 동시 상태 변경 탐지, 재실행 멱등성, 신규 요청만 큐잉, 전체 V167 비발행 제안 수신 영수증으로 안전하게 결합.
- 실제 채팅의 검색·의미 판단 콜백이 **같은 현재 응답 중** 실행을 공급해야 한다. Python 모듈에는 모델 호출·웹검색·스케줄러·자동 판정 기능이 없다.
- `KEEP_OPEN`는 미승인으로 관리되고, `QUARANTINE_PROPOSAL`은 V166 typed 검문, 후보는 V168 2차 검토 및 동결 V123을 거쳐야 한다. V123 PASS여도 E4 공식 원문 검증 없이는 발행 불가. 기존 지식·SQLite 지식 발행 경로에 쓰지 않는다.
