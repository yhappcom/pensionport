## 1. 개선 코드 및 합성 시험

- `v166_e2_semantic_separation.py`: ChatGPT가 개별 원자마다 **원문 화자 발언 요약**과 **검토자의 금융 위험·한계 설명**을 별도 필드로 기록하고 SHA로 검문하는 E2 의미 사이드카.
- 원문 `source_sha256`·`atom_sha256`·원자 문맥 cue/원문 인용을 고정. `original_condition_cue_indices`, `original_exception_cue_indices`가 원래 V6 원자에서 누락·변경되면 거부.
- 질문·가설·의견·사실·역사적 주장 포함 의견·인용된 책 원칙을 구분. 역사 사실/책 원제/인용된 원칙 등 검증 가능한 부분은 **`fact_dependencies`**로 분리하여 출판/금융 원전 사실 승인과 혼동하지 않도록 함.
- 숫자 원문 token은 `ASR_NUMERIC_AMBIGUITY`, `FINANCIAL_QUANTITY_UNVERIFIED` 등으로 분류하되 출처 글자와 정확하게 대응하도록 강제. 금융 숫자 또는 원전 사실의 **자동 승인 코드는 포함하지 않음**.
- `test_v166_e2_semantic_separation.py`: **합성 15개 시험** (원문 인용 위조, 조건 누락, 사실 의존관계 탈락, FACT→의견 재분류, 위험 설명 화자 혼입, 숫자 token 소실, 명시적 원전 검증 없이 PRIMARY_VERIFIED로 승격, 외부 gold/개인자문 허위 인증 등) PASS.
- CI: https://github.com/yhappcom/pensionport/actions/runs/44026049789 — **E1/E2 관련 6 jobs 모두 success**. 이는 E2 실제 영상 정확도 인증이 아니라 코드 검증 및 회귀시험 성공이다.

## 2. B0001 실제 원문을 대상으로 수행한 새 원자별 의미 분리

- 사용자가 보유한 영상 #1 원본 SRT(1,481 cue) 중 B0001 120 cue와 정식 V6 16원자를 읽었다.
- ChatGPT가 원문 cue를 직접 대조하여 **16개 원자 각각의 발언 유형/원문 인용, 검토자 유보, 역사 사실 의존관계, V6 조건·예외 번호, 원문 숫자 token 분류를 구분하는 비공개 사이드카 16행**을 구성했다.
- 실물 비공개 사이드카 SHA-256: `d970713e83116af3baafc07459eb6856145e7d4ea67340821e577f796c50113e`.
- 별도 작성한 **독립 기계적 검산 코드**로 원본 cue/원자/인용/SHA/조건/숫자 역할을 대조했고, 원본 SHA·원자 SHA·인용·조건·검토자 메모·사실 출처·숫자 토큰을 고의로 변조한 **7개 부정시험을 모두 차단**했다.
- 비공개 기계 검산 집계:

| 관찰 항목 | 결과 |
|---|---:|
| 원본/원자 귀속 | 120 cue / 16 원자 |
| 원래 V6에 존재하는 조건 cue 연결 보존 | **2원자** |
| 원래 V6 원자에 명시된 예외 cue 연결 | 0원자 (원문 전체 예외 부재 인증 아님) |
| 책/역사/검증 가능 설명을 포함한 사실 의존관계 | **9개 OPEN** (원전 사실 승인 아님) |
| ASR 기원일 가능성이 있는 숫자 token | 1개 |
| 독립 모델/외부 블라인드 정답셋 | 없음, 재현율·정밀도 미인증 |

- 기계 검산은 신규 공개 `v166_e2_semantic_separation.py`를 **비공개 원본 바이트에 직접 import하여 호출한 시험이 아니라**, 별도 독립 구현으로 출처·조건·SHA 일치성을 확인한 것이다. 따라서 실물 원본에 대한 정식 E2 코드의 전수 실행은 **아직 완료됐다고 기록하지 않는다**.
- **정식 V123/V128 판단은 변경하지 않음.** B0001 실제 신규 연구 지식 발행은 0, 과거 3개 외부 역사/서지 사실 및 위험·의견 충돌은 HOLD.

## 3. E2 합격에 아직 필요한 작업

1. 공개 E2 validator의 **정확한 코드 버전**으로 비공개 B0001 16행을 직접 통과/거부 검증하고, 잘못된 사실·가설·원문 조건을 실제 발언 맥락과 다시 비교한다.
2. 표본 16원자에서 확인한 문제를 일반 원자 처리 경로로 연결하여 **V6 보관된 원문 발언과 검토자 의견이 승인 지식으로 뒤섞이지 않도록** 저장·질의 입력의 타입을 명확히 한다. SHA만 정확한 사이드카 파일을 만들었다는 이유만으로 완료 판정 금지.
3. 책/역사에 관한 9개 *의존관계가 있다*는 것은 9개의 오류나 미승인 금융 주장 확정 수와 다르다. 각 의존관계 검토에서 인용/원전 사실 검증이 필요한 부분을 별도 보류하고, E3/E4에서 필요한 최종 금융 승인은 수행한다.
4. 동일한 조건/예외/화자/전사 숫자 사례로 합성·실물 회귀시험을 반복해 의미 혼동과 고위험 누락을 검문한다.
