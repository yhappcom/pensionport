# V119 — 독립검토의 채팅 내부 수행 원칙과 기존 문서 운영정정

**운영 기준일:** 2026-11-15 KST. **저장소:** `yhappcom/pensionport` 검증 브랜치 / Draft PR #53. 이 문서는 사용자의 기존 명시적 결정과 V109 운영정책을 재확인하는 **현행 우선 운영기준**이다. 구버전 실측·영수증·원본 SHA는 재작성하지 않는다.

## 1. 검토 수행 주체

- **연구 및 검토의 수행자는 ChatGPT 채팅이다.** 외부 인간 검토자 2명, 외부 조정자 1명, 신원인증 기관, 외부 모델 API는 **채팅 내부 연구의 필수조건이 아니다**. 그 부재만으로 원본 분석·지식 검토·오류 정정을 중단하거나 P0-NO-GO 사유를 만들어서는 안 된다.
- “독립검토”라는 프로젝트 운영어는 **기존 엔진의 예측·후보에 자동 동의하지 않고 원본을 먼저 살펴 새롭게 검토한다는 절차**를 뜻한다. ChatGPT가 1차 원본 판정, 반례 중심 2차 검토, 근거 확인, 의견 불일치 조정까지 수행한다.
- **같은 모델/같은 채팅 A·B 역할 분리는 통계적으로 독립된 제3자 정답 평가가 아니다.** 이전 대화에 엔진의 예상 답이 노출됐으면 `BLIND_NOT_ESTABLISHED`로 표시한다. 서로 다른 패킷이나 지시문을 사용했다고 해서 사람이 별도로 평가한 것처럼 서명하거나 독립 정답 인증을 주장하지 않는다.
- 외부 서명 기반 인증은 추후 **선택적으로 요청하는 별도 등급**이다. V103·V105·V107의 외부 신원기관/2명+조정자 규약 및 관련 fail-closed 코드는 그 등급의 **역사적·선택적 경로**로 보존한다. 현행 채팅 연구와 내부 참조 성능 계산의 선행조건으로 강제하지 않는다.

## 2. 채팅 내 1개 평가 단위의 실행 순서

1. **미노출 범위 사전 고정:** 영상·창·원본 SRT 바이트 SHA-256·cue 번호/시간·연구 시점·선정 기준을 확정한다. 기존 연구 예측을 이미 읽었다면 `PRIOR_EXPOSED` 상태를 기록하고 완전 블라인드를 주장하지 않는다.
2. **예측과 기준 분리:** 평가하려는 엔진 예측이 있다면 **정답 참조표 작성 전에** ID·SHA·버전·시점을 봉인한다. 검토용 원본 패킷에는 엔진 예측, 기존 리뷰, 위험 점수와 해설을 넣지 않는다. 같은 채팅에서 완전 정보 차단을 보장할 수 없는 경우에도 순서·노출 여부를 정직하게 기록한다.
3. **ChatGPT 원본 우선 1차(A):** 전체 cue를 읽고 문맥/화자/인용/질문/반박/조건/예외/기간/금액/세율/적용 시점까지 금융 원자 주장으로 분해한다. 부모 발화·하위 주장·다중 cue 근거·미귀속 cue·OPEN을 모두 연결한다.
4. **ChatGPT 반례 검토(B):** 기존 결과에 자동 동의하지 않고 원본과 최신 공식자료를 다시 대조한다. A의 누락·과다 분할·부정어 오류·예외 누락·숫자·상품/개인조건 오독을 검문한다. A를 이미 알고 검토했다면 **같은 모델 재검토**로 표기한다.
5. **불일치 조정 및 기준셋 기록:** A/B 차이를 단위별로 기록하고 원본 근거·반증·최신 법령 시행일·전후 문맥을 대조해 채팅이 최종 `CHAT_ADJUDICATED_REFERENCE` 후보를 만든다. 해결 불능은 `OPEN`으로 남기며, 검토한 전체 cue와 미판정 cue의 분모를 보존한다.
6. **동결·채점·적용성 분리:** 사전 봉인 예측과 사후 고정한 참조셋을 일대일 동치 대조해 TP·FP·FN·고위험 FN을 계산한다. 근거와 분모가 완전할 때만 `CHAT_INTERNAL_REFERENCE_SCORE`로 보고한다. 그 외에는 `NO_SCORE`. 세법 사실·개인별 자문 자동승인은 별도 게이트다.

## 3. 허용되는 성과 지표의 명칭

| 항목 | 허용되는 판정 | 금지되는 혼동 |
|---|---|---|
| 원본 자막 출처 귀속 | `SOURCE_COVERAGE` | 금융 주장 전체 재현율 100%로 오인 |
| ChatGPT A/B 재검토 | `CHAT_NATIVE_REVIEW` | 외부의 완전 독립 블라인드 평가로 표기 |
| 사전봉인 예측 vs 채팅 조정 참조셋 | `CHAT_INTERNAL_REFERENCE_SCORE` (TP/FP/FN 및 분모 공개 시) | `EXTERNALLY_CERTIFIED_PRECISION` 등 외부 인증 지표로 표기 |
| 외부 제3자 검증 (선택) | `EXTERNAL_INDEPENDENT_CERTIFICATION` | 내부 검토의 필수 선행조건으로 강제 |
| 공식 금융 사실 및 개인 자문 | 별도 원문·시행일·적용조건·개인 적합성 게이트 | 단순 소프트웨어 PASS로 자동 승인 |

채팅 내부 점수도 **실제로 채점이 수행되기 전에는 NULL/NO-SCORE**다. V118의 173 cue·46 잠정 주장·41 금융 OPEN, V109의 내부 2-pass 등 과거 실증 결과를 마치 새 검토자가 재판정한 것처럼 소급 승격하지 않는다. 동일 모델의 상관 오류, 도메인 지식의 공유, 평가자료 노출을 정량 점수와 함께 공개한다.

## 4. 이전 문서 간 우선순위 및 정정

- **현행 우선:** `V109_CHAT_ONLY_EVALUATION_RELEASE_POLICY.json` + 이 V119 문서 및 `V119_CHAT_NATIVE_REVIEW_POLICY.json`. 외부 검토자/모델 API 불필요, 채팅에서 검토 수행.
- **V103/V105/V107:** 외부 서명·신원 루트를 요구하는 `EXTERNAL_INDEPENDENT_CERTIFICATION` **전용 역사적 규약**. 해당 구조·테스트는 삭제하지 않지만, 일반 채팅 연구의 필수조건이란 해석은 **폐기**한다.
- **V108:** 당시 “채팅으로 대체하지 않는다”는 **외부 인증만을 목표로 한 권고**이므로 일반 채팅 연구에는 적용하지 않는다. 문서의 후속 권고를 V119 기준으로 정정한다.
- **V118:** 외부 평가자 부재 때문에 연구를 멈추는 것이 아니다. V118에서 실제 참조셋·정밀도·재현율이 없는 이유는 **A/B 원본 재분해·불일치 조정·동결·채점이 아직 실행되지 않았기 때문**이다. 이는 채팅이 이어서 수행한다.
- **V16 채팅 실행계획과 SHA 고정 manifest:** 당시의 평가 구조와 외부 인증 등급을 기술한 **기록본**으로 유지한다. 구버전의 “외부 2명 필수” 문구가 **현행 채팅 연구에 자동 적용되는 것은 아니다**. 고정 blob의 역사성 때문에 내용을 소급 변경하지 않고 본 문서로 명시적으로 우선순위를 정한다.

## 5. 실제 검증 완료 기준 및 안전장치

- 의미 완전성: ChatGPT 원본 전수 분해·조건/예외/반박 재검문, 출처와 다중 cue 동치, OPEN 및 고위험 누락분 기록이 필요하다. 같은 모델의 2차 검토만으로 완전성을 독립 인증할 수 없다.
- 금융 근거: 법령·KRX·국세청·공식 발행사 자료는 유효일·규정 버전·문구 원문·상품/계좌 제한을 분리 검증한다. 페이지가 점검 중이거나 본문 바이트가 미고정이면 `OPEN`. 임의 승격 금지.
- 품질 지표: 실제 사전 봉인 예측과 고정된 채팅 참조셋이 모두 존재해야 내부 점수를 계산한다. 외부 검토자가 없다는 사실만으로 내부 점수 계산을 금지하지 않는다.
- 실행 제약: 별도 모델 API 없이 **현재 채팅과 연결된 도구**로 수행한다. Python이 ChatGPT를 무인 자동 호출한다고 주장하지 않는다. 모델 내부 시간은 제공된 계측 정보 없으면 미측정.
- 보호 대상: `main`, 기존 승인 Master116/P4/V5, 비공개 원본·개인 맥락을 보존하며, 새 금융사실 승인·지식 자동 병합·개인 주문 자동화는 별도 승인 없이는 0건을 유지한다.
- **현 시점 상태:** 정책 정정만 수행. 새로운 인간 검토자 결과도, 새로 채점한 ChatGPT 내부 정밀도도 생성하지 않았다. V118 실물 정확도는 `NO_SCORE`, P0 `NO_GO`를 유지한다.

**다음 실무 조치:** V118 원본 전용 블라인드 패킷으로 ChatGPT가 실제 A/B 재분해·불일치 조정·내부 참조표를 작성한다. 그때에만 내부 기준 대비 TP/FP/FN을 실제 계산한다. 외부 인력 확보는 작업 대기조건이 아니다.

## V123 후속 운영 규약 — ChatGPT 최종 검증 관문 (2026-11-15)
