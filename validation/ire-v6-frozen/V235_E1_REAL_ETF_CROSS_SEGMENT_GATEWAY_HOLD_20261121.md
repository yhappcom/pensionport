# V235 E1 실물 종단간 재검토 — V123/E4/E5 차단 증명 및 구간 간 문맥 보존

기준: 2026년 11월 21일 · 원본 영상 `LVE7XN_esTc` · 정식 투자 지식 승인 0건

## 결론

V232에서 실제 ETF 250개 자막·미승인 68개 원자의 V6 호스트 SQLite 저장(30개 이벤트)을 확인했고, V233에서는 V127 부모 체크포인트의 13개 자식 계획과 재개봉을 검증했다. **V234 재검토에서 21개 원자가 다른 자막 구간을 참조하는 E1 문맥 전달 결함을 발견**해 원본 바이트 기반 측면원장에 보존하고, V235에서 공식 E1 진입점에 해당 검문을 연결했다. 미해결 교차 문맥으로 V123/E4/E5에 승인·발행을 시도할 수 없도록 차단한다.

**실제 ETF의 E3 승인이나 E5 긍정 발행이 이뤄졌다는 뜻이 아니다.** E1 실물 종단간 전체 합격은 HOLD다.

## 1. 실제 원본 검문

- V228 동결 ZIP SHA-256: `9f5a281191502bb30cb78ff17d2b08f6887f55b836cee67e00d7309770efa397`
- SRT 원본 SHA-256: `e4aef32c007bc5e9f1ac6c3e18764ddc1b766e430893127cf98abe632c70301b`
- V232 V6 호스트 이벤트 30개, head `7dd7b5b8b30d8b7233e8fa75949e2e07d48d68cc971a0a5815dead27e1540a55`
- V233 자식 계획 13개, parent plan `4bb9ed049b60b1f41583789b23ac88cb33f2bce17ad181f7c007db56b99e6fa7`, 실제 승인 0/13.

원자 68개 중 **47개는 필요 근거가 모두 자기 구간 안에 있음**, 나머지 **21개는 구간 밖 문맥을 참조**함. 이 21개 중 **11개는 조건·예외**, **3개는 숫자**의 외부 참조를 가진다. 외부 자막 연결(edge)은 **49개**이며, 총 13개 자식 가운데 **12개 원자 소유 구간**에 영향을 준다.

V6의 부분구간 원자 입력 계약은 cue index가 해당 범위 안에 있음을 요구한다. 따라서 다른 구간의 조건·문맥을 잘라내거나, V127의 12개 **인접 경계**만 확인하면 비인접 구간의 문맥이 사라질 위험이 있다. 이는 E2의 정확도 문제 이전에 E1 입력 전달에서 막아야 하는 결함이다.

V234는 모든 교차 원자의 **원자 원본 해시, 실제 원문·자막 SHA, 문맥 역할, 조건·예외·숫자 단서, 자식 구간 ID**를 담은 비공개 측면원장을 생성해 전수 재검문했다. 원문을 변조하거나 누락해 다시 해시해도 독립 원본과의 대조에서 차단한다. 비공개 교차 문맥 원장의 SHA-256(JSON canonical digest):

`1d409d10aea243725a999ead9062eb89c0da343c4cc195256a5cce2aad4b523c`

**문맥 보존 검사는 의미 승인이나 독립 정답셋이 아니다.** 21개 원자는 모두 미승인 상태이며 E2의 출처 기반 수선이 필요하다.

## 2. 실제 원본으로 V123/V128/E5 호출

기존 V232 원본 DB가 아닌 **사본**을 사용했다. 원래 V6 host batch의 입력 및 보호 지식 116+29개 바이트를 재생한 결과 `idempotent_replay=True`를 받고, 이벤트 30개 및 head가 그대로 유지됐다. 해당 실제 V6 영수증으로 `assess_chat_final_gate`를 호출하자 결과는 **`HOLD_MISSING_CHAT_FINAL_REVIEW`**였다. V231의 내부 2턴 리뷰를 V123 정식 승인 근거로 둔갑시키지 않았다.

실제 V127 자식 PASS가 0/13이라 `publish_parent_once`는 **`V128_PARENT_CHILD_PACKET_CENSUS`**에서 차단됐다. V126 승인 지식 0건, 지식 이벤트 0건, 부모 발행 0건이 확인됐다.

V235의 새 E1 진입점은 다음 순서를 실제로 확인한다.

`verify_v232_source_native_host → verify_escrow_bytes → V127 checkpoint.progress → V126 knowledge.audit → (교차 미해결 시 HOLD) / (교차 없음 + 실제 ChatGPT 자식·경계·부모 검토 콜백이 있을 때 frozen V123/V128/V126 호출)`

교차 원자가 남으면 어떠한 가짜 콜백도 실행하지 않고 발행 저장소의 불변성을 확인한다. 새 E1 진입점으로 실물 ETF를 **두 번** 재실행했으며 동일하게 `HOLD_CROSS_SEGMENT_CONTEXT_NOT_REPRESENTABLE_AS_CHILD_ATOMS`, 최종 지식 발행 0건을 얻었다.
