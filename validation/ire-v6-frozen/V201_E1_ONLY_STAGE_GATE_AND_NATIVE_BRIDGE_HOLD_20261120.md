# V201 — E1 단독 개선 및 단계별 합격 계약

**2026-11-20 KST. 단계 진행 규칙: E1 PASS 전 E2 착수 금지, E2 PASS 전 E3 착수 금지, E3 PASS 전 E4 착수 금지, E4 PASS 전 E5 착수 금지.** 기존 E2~E5 연구·실험 기록은 보존하되 완료 또는 이행 근거로 소급 사용하지 않는다.

## E1 합격 기준 (반드시 전부 충족)

1. **입력**: 소유자 원본 SRT의 바이트·자막 전수·윈도우 매니페스트가 독립 보유 SHA와 연결되어 실제 재개 시 검증된다.
2. **검토**: 실제 ChatGPT 호스트에서 발행된 구조적 검토를 V176 원장에 저장하고, 원본·판정·해시가 재실행 뒤 동일하게 복구된다. 합성 CI는 이 요건의 대체물이 아니다.
3. **정식 전달**: V176에서 생성한 검토 결과를 실제 V6 거래 원장에 입력한다. 본 V201에서는 `TransactionStore.snapshot_with_atomic_exchange()`를 통한 해시·원자·출처 구조 **읽기 감사**를 처음 연결했다.
4. **승인 관문 인터페이스**: **실제 정식 V123/E4 실행 경로**가 E3 검토 영수증을 받아 정식 승인·보류·격리로 분기되고, 부적합 입력이 차단됨을 확인해야 한다. 아직 미연결. E2/E3의 의미 정확도 자체는 각 후속 단계에서 별도 증명하되, E1에서는 승인 관문의 실제 호출/복귀 경로를 입증해야 한다.
5. **저장 관문 인터페이스**: E4에서 허용된 승인 패킷에 한하여 **실제 E5 원자적 저장기**가 호출되고, 실패 시 변경 없이 롤백하며, 복구 후 결과가 동일함을 테스트한다. 실제 지식 발행 승인은 E5 단계에서 하며 E1은 구조 연결만 검증한다. 아직 미연결.
6. **종단간 증거**: 연결된 한 실행에서 입력→검토→승인 관문→저장 관문을 사용한 정상·거절·중단·재개 결과와 체크포인트를 확인한다. 아직 미실증.

**따라서 V201 E1 현재 판정은 `HOLD`이며 E2~E5 진행 금지.** 기존 V199 연구 120원자·84 고위험·28 격리 및 기존 승인/검증 이력 변경 없음.

## 이번 변경의 실질적 진전과 한계

- `v201_e1_native_source_bridge.py`는 원래 V176 private SQLite와 V6 `TransactionStore`를 직접 받아, 소유자 원본 SHA 및 별도 입력한 owner head와 inventory digest를 검증한다.
- 신규 scope를 만들 때 native V6의 `create_scope → attest_source → attest_owner_inventory` 경로를 사용하고, 이미 만든 원장의 재개에서는 기존 native 상태와 원본 SHA를 대조한다.
- 이후 **실제 native** `snapshot_with_atomic_exchange`를 호출해 완전한 cue census와 후보 주장 구조를 재감사한다. Python 자료형으로 만든 가짜 승인 사본은 수용하지 않는다.
- 결과는 계수와 원장 해시만 공개하고, 모든 금융 사실은 여전히 미승인 상태다. 외부 제공 inventory digest는 입력된 별도 anchor이지 소유자 신원에 대한 암호학적 서명이 아니다.
- 정상/변조/재개/미검토 시험은 **합성 자료**다. 이번 변경은 실제 V123/E4 승인 관문 호출이나 E5 저장을 구현하지 않았으므로 E1 PASS가 아니다.
- E1 다음 개발은 E4·E5 **구조 연결만** 수행한다. 의미 추론 모델 개선, CMA 72건 조사, 독립 E3 판정, E4 실제 금융승인, E5 실제 지식 발행은 E1 통과 전 수행하지 않는다.

## 검증 증거

PR/CI에서 V176~V200 회귀시험과 V201 신규 합성 통합시험을 실행하고, V201에서는 실제 V6 원장 메서드를 호출하는지 확인한다. 이 CI PASS와 E1 PASS는 별개다.

실제 비공개 CMA SRT/원장/V199 zip은 공개 GitHub에 저장하지 않는다. `main`은 수정하지 않으며 Draft 검증 브랜치에만 변경을 적재한다.
