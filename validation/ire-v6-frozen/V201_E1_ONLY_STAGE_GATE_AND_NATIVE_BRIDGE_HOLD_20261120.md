2026-11-17 V166의 **E1 PASS는 실제로 존재하며 취소하지 않는다.** `V166_E1_E7_STATUS.json`의 첫 항목에 PASS·완료시각과 CI가 기록돼 있고, `V166_E1_FINAL_SINGLE_INPUT_ACID_AND_OWNER_HOLD_PROOF_20261117.md`는 동일 합성 입력의 V6 → ChatGPT 검토 → 동결 V123 → V127 → V128 → V126 **실제 SQLite 기록(knowledge=2, parent_publications=1)**을 입증했다. 실물 B0001은 정식 승인되지 않아 정상 HOLD였고 E1의 의미 정확도/실물 승인 합격 요건은 아니었다.

그 뒤 V176에서 **다른 source-first 연구 경로**를 도입했으나, `V176.compile_native_v6_stage`의 끝은 원자 교환 **미승인 preview**였다. 과거 V166 구조 합격을 신규 V176 경로에 그대로 적용하는 것은 근거가 없다. 따라서 공식 표현은 **`V166 E1 구조 연결 PASS (역사적 보존); V176~V201 신규 경로 E1 적합성 재검증 중 / HOLD`**다. 기존 E1이 애초에 전혀 완료된 적 없었다고 말하면 안 된다.

> E1 — 엔진 전체 구조: **입력·검토·승인·저장 경로가 하나로 연결**

V166 합격 기준을 임의 강화하거나 축소하지 않는다. **같은 합성 입력**에서 V176 → 원본/호스트 digest와 의미검토 → 실제 동결 V123 → V127/V127.1 → V128 전체 staging 및 원자적 COMMIT → V126 private SQLite 저장의 **긍정 경로 1개 이상**이 확인돼야 한다. 또한 소유자 실제 원본에서 미승인/증거 부족 입력을 안전하게 HOLD해야 한다. **실물 지식 13/13 승인은 E5 합격 요건이며 E1에서는 요구하지 않는다.** 의미 분류의 실질 정확도는 E2, 채팅 최종 검증의 정확성은 E3, 적법 승인 품질은 E4에서 별도 판정한다.
