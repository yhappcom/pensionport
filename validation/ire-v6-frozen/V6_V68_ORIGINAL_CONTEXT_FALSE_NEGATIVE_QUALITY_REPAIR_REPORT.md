## 품질 문제의 구체적 원인

이전 V66에서는 기존 금융·수치 위험 탐지(129건)와 광범위 금융용어 탐지(137건)가 첫 5편의 일반문맥 P2 중 서로 다른 후보를 찾는다는 문제가 확인됐다. V67은 두 집합의 교집합 33건, **중복제거 합집합 233건**을 실원본에 연결했다. 이 233건은 전부 실제 금융 오류로 판정된 것이 아니라 탐지 규칙의 **누락 경고 후보**다. V67의 31건 직접 의미검토/54 하위 단위는 별도 비공개 장부이며 V66.1의 기존 300부모/608단위에 안전한 ID 차집합 확인 없이 합산하지 않았다.

핵심 오류는 **기존 V33 P2(일반 발화)로 분류하면 문장 주변의 금액·세율·질문·부정 등 금융 의미가 사라질 수 있다**는 것이다. ASR 자막은 문장 경계와 금융 조건이 여러 cue에 분할되어 있어, 한 발화의 독립된 단어만 검사하면 누락된다. 따라서 P2를 비금융 사실로 자동 통과시키는 것은 근본적으로 위험하다.

## 실제 원본 5편의 새로운 V68 검사

P2 중 **702/1,215개**가 새 문맥 게이트에서 우선 심사 대상으로 표시된다. **361개는 발화 하나만 조회하면 놓치지만 양옆 원본 cue를 결합해야 위험 어휘/숫자가 보이는 항목**이다. 기존 V66.1의 137개 신호를 새 게이트에서 **137/137 유지**했으며 나머지 **565개가 추가 에스컬레이션**됐다. 이는 검사 규칙 차이에 따른 업무 큐 증가이며 참 금융 주장 565개를 독립 발견·승인했다는 뜻은 아니다. 기존 V67의 233개 규칙과의 완전 교집합/차집합은 해당 V67 비공개 31/233 source ID 본문이 이번 환경에 없어 별도로 인증하지 않는다. 137+565=702의 계산은 오직 V66.1 이전 137과 V68의 포함관계에서만 성립한다.

**중요한 안전 경계:** 위험어휘를 찾지 못한 P2 **513개**, P1 **7개**까지 포함해 **미검토 1,303개 전체를 자동 지식·개인자문 후보 승인에서 계속 차단한다.** 단어 없음 = 비금융/사실/안전 판정으로 전환하지 않는다. P2 이름을 P0로 몰래 변경하지 않고 새로운 `DIRECT_ESCALATION / CONTEXT_ONLY_ESCALATION / PENDING_SOURCE_REVIEW` 상태를 별도로 보존한다.

## 시행한 코드 수준 수정과 자동 회귀시험

신규 독립 검문기 `validation/ire-v6-frozen/v68_context_risk_gate.py`:
- 실제 비공개 원본 cue 텍스트와 V33 후보 인용·SHA·cue 인덱스의 일치성 재검증.
- 기존 완료/미검토 source key 분모의 일관성 확인. 1,603개 전체 vs 1,303개 미검토 후보가 누락·중복되면 예외.
- 금융어휘·금액/기간 숫자를 직접 탐지하고, 같은 원본 영상에서 앞뒤 2개 cue까지 포함한 문맥 신호 탐지.
- 모든 미검토 후보는 위험 신호 유무와 관계없이 `approved_as_nonfinancial=false`, `review_complete=false`를 강제.
- 상위 자문 승격 함수 `require_research_quality_for_advice`는 외부 독립 확인이 없는 현재 연구영수증을 **항상 fail-closed**로 거절한다. 이는 기존 운영용 자문 경로에 이미 필수 연결됐음을 의미하지 않는다.
- 원본·인용·리뷰 태그/승인 조작, 무단 후보 제외·추가, 빈 자료·중복 입력은 차단. 공개 영수증에는 수량·SHA·상태만 포함하며 사적 자막/해석 전문 미포함.

실제 원본 1,603후보 재생성/1,303 미검토 검문 **PASS**, 원본을 악의적으로 바꾸는 **17개 실제 소스 오류 주입 전부 거부**, 독립 합성 **16/16 회귀시험 PASS**. 기존 강한 P2 신호 **18개**도 실제 원문·양옆 cue와 함께 ChatGPT에서 문맥/질문/권고/가정/미검증 수익률로 **개별 재분류**하여 비공개 원장에 남겼다. 다만 이 18개는 V67 31건과 겹칠 가능성이 있어 기존 300부모의 신규 최종 원자 분할 수에 추가하지 않고 **내부 위험 검문 18건**으로만 보고한다.

**CI 구조개선:** 기존 `.github/workflows/ire-v6-frozen-ci.yml`에 `source-context-risk-regression` 별도 job을 추가했다. 이제 GitHub Actions에서 개인 SRT 없이 실행 가능한 **V68 합성 16개 회귀·부정시험이 자동 실행**된다. 기존 frozen `ire/v6/`의 106파일/647테스트·원본 V5/승인 지식은 **변경하지 않았다**. 새 CI job 합격은 소프트웨어 안전검문 통과이지 실제 독립 금융 의미 정확도 인증은 아니다. **실제 소유자 원본을 이용한 702개 검문은 비공개 로컬 실증**이며 GitHub CI 서버에 개인 원본을 올리지 않는다.
