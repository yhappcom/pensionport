# V39 — 비공개 원본 발화 의미 검문기 및 V38.2·V38.3 계수 정정

**기준일:** 2026-11-11 KST. **검증 브랜치 직전 HEAD:** `be4fb897701e909e64512690f056fd164dd0cded`. `main`·V5·기존 승인 116·P4는 수정하지 않는다.

## 1. 새로 발견한 실제 데이터 무결성 결함

실제 Google Drive `1-100.zip`(SHA256 `088869c583b2d3ed93d68e4dd5348b1f506877ea2bdc1d66466c199ec80e7716`)의 #1·#2 개인 원본 SRT, V37 원본 창·V33 발화 후보 해시, 그리고 V38.2·V38.3에서 **비공개로 작성한 총 78개 ChatGPT 발화별 의미 제안**을 다시 대조했다.

| 원본 창 | 정확한 V33 발화 후보 | 이전에 보고한 의미 메모 | 실제 비공개 메모 개수 | 판정 |
|---|---:|---:|---:|---|
| #1 W00015 | 14 | 25 | **25** | 일치 |
| #1 W00016 | 9 | 19 | **19** | 일치 |
| #1 W00017 | 14 | 18 | **18** | 일치 |

| #2 W00014 | 17 | **18** | **22** | 기존 집계 4개 누락 |

V38.2의 의미 메모 수는 **79→81**, V38.3은 **36→40**, 누적은 **115→121**로 이력 정정한다. **원본 6창·240cue와 78개 발화 후보 수에는 차이가 없었다.** 121개는 예시·질문·과거 상품 불확실성·의미단편 6개를 포함한 *동일 ChatGPT가 작성한 검토 메모 수*이지, 독립적으로 참값을 검증한 금융 원자 주장 수가 아니다.

## 2. 엔진 V39 실제 보완

`ire/v6/host_semantic_custody_v39.py`에 `audit_host_semantic_custody_v39`을 추가했다. 모델 API 없이 비공개 SRT 바이트를 받아 원본 SHA·자막 인덱스, V33의 원본 구간별 재분할, V37의 원문 창 SHA·후보목록 digest를 **호스트 의미 메모와 독립적으로 다시 계산**한다.

- 선택 창 내부 **후보 1개당 메모 행 정확히 1개**를 요구한다. 삭제, 중복, 다른 창/잘못된 후보 ID, 자막 참조 조작 시 검증을 차단한다.
- 원문 발화 전체 문자열과 원문 SHA를 실제 SRT와 일치시킨다. 리뷰자가 발화를 바꿔 넣어도 PASS하지 못한다.
- 의미 메모 종류와 건수를 **원본 메모 행에서 계산**한다. 하드코딩된 합계를 성과로 사용하지 않는다.
- 원음, 당시 증권사 계약, 금융 사실의 독립 인증, 외부 독립 평가자, 개인 자문 승인 등이 **거짓으로 true가 되면 예외 처리**한다.
- 비공개 발화 전문과 판단 근거 문장은 반환하지 않고 출처·분류 메모의 해시/개수만 반환한다.

**테스트:** 합성 회귀시험 신규 **15건 로컬 PASS**, 비공개 #1·#2 실제 SRT·6창·78개 후보에 대한 로컬 재현 **78/78 PASS**, 악의적 변조/누락/중복/허위 인증 부정 검문 **10/10 차단 PASS**. 실제 비공개 전체 검문 결과 영수증 canonical SHA256: `524ab71a59fd773c348d44760b552677953d4fa3ad2d492b1085da0d327fd8b3`. 영수증은 **원본 또는 독립 정답이 아니다**. 공개 저장소에는 이 해시와 합계만 남기며 사용자 비공개 자막/의미 원문은 올리지 않는다.

## 3. 실행·보호 범위

- V39은 **선택 창에 대한 의미 검토 근거·계수 보관 검문기**이다. `all_1603_atomized`, `human_blind_gold`, `financial_truth_certified`, `p0_go`는 모두 **false**.
- 현재 **6/130창**만 이 심층검문을 수행했고 **나머지 124창·1,525개의 잠정 발화**는 다음 분석 대상. **당시 음성·발행사 원표 8건은 전부 OPEN**.
- 기존 V6의 580개 테스트 및 역사적 V37 검증 지문은 변경하지 않고, 신규 15개를 합한 **595개 테스트**의 CI 발견 게이트만 별도 확장한다. 추가되는 `ire/v6` 파일은 정확히 2개, 예상 전체 수는 100개이며 코드·테스트 파일 Git blob SHA를 V39 매니페스트로 고정한다.
- 전체 CI 통과와 임의 금융사실의 독립 정확성 인증은 별개의 판정이다. CI 확정 전에는 배포·병합하지 않는다.

**결론:** V38 보고서의 실제 의미 메모 계수 6개 오류를 발견·정정하고, 같은 유형의 누락·오보가 반복되지 않도록 V39 소스-기반 검문 모듈과 회귀시험을 구현했다. 투자자문 활용 승인 **P0 NO-GO** 유지.
