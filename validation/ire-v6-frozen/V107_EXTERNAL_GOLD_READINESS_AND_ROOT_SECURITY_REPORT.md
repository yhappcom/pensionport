# V107 — 160개 미노출 원본 블라인드 검토 자료 생성·신원 인증 보강

기준: **2026-11-14 KST**. 비공개 `1-70.zip` 원본 SHA-256 `00024d54bbca57c8c9f528d3c6c2f4766052ad2dc37bf4f132280dbd223dd8fd`. 이전 V104~V106 연구 자료 및 V105 사전 고정 평가 범위를 재검증했다. **독립 정확도 평가는 아직 수행되지 않았다.**

## 1. 실제 수행 결과

- V105에서 사전에 선정한 영상 **#1·#3·#5·#7의 4개 창, 160개 cue**를 원본 자막·cue 텍스트 SHA·순서·시간·창 범위·사전 고정 window SHA·cohort digest로 재검증: 160/160 구조 일치.
- 비공개 원본 자막과 직전의 A/B 미작성 상태를 확인했다. 실제 **외부 검토자 서명·판정·조정 0건**.
- **A 검토자**, **B 검토자** 각자의 독립 배포용 ZIP을 생성했다. 각 ZIP에는 동일한 원본 160개 cue(자막·시각·원본 hash), 독립 판정 양식의 초기 160개 `UNREVIEWED`, 한글 지침만 들어 있다. 다른 검토자의 답안, V93~V106 엔진 예측·검토 결과, 위험 신호별 층화 지표는 들어 있지 않다. 별도 사용자/검토자 전달 여부는 미확인이다.
- 검토자 A/B가 제출할 경우 **160개 cue 전부 판정, 주장별 원본 span SHA, 다중 cue 출처, 화자 입장, 위험도, 금액·기간·조건·예외**가 누락되지 않았는지 검증하는 `v107_blind_review_intake.py`를 추가했다. 동일 판정의 구조 검문은 독립적 *의미 일치* 또는 재현율이 아니다.
- 빈 양식·원본 변조·중복 cue·원본 범위 변경·출처 SHA 위조·완료 누락·가짜 독립 승인·주장 출처 이탈·원자 ID 불일치·역할 순서 바꿈 등 **신규 합성 시험 42/42**를 일반 Python 및 최적화 Python에서 통과했다.
- 비공개 패키지 생성 2회 재현: 바이너리 ZIP SHA-256 일치 및 CRC 검증 PASS. 소유자 전용 복구 ZIP과 A/B 독립 배포 ZIP은 개인 라이브러리에만 저장한다. 공개 GitHub에는 소유자 자막·의미 주석·원자 주장 텍스트가 없다.

## 2. V105 독립 신원 인증 결함 개선

기존 `v105_blind_gold_protocol.py`의 `trusted_registry['verified_by_external_identity_authority']=True`는 **신뢰 기관 자체의 외부 증명**이 없으면 사용자가 자의적으로 제출 가능한 표시였다. 임의의 키로 서명한 판정을 신원 인증 자료처럼 취급할 위험이 있었다. 또 합성 산술 시험에서 가짜 `independent_gold=True` 입력으로 계산한 수치가 외부 인증 점수와 혼동될 수 있었다.

V107에서는 V105의 실제 금표시(`external_gold_gate`)와 실점수 함수(`score_predictions`)에 다음 fail-closed 검증을 적용했다.

1. 신원기관 공개키의 SHA-256이 **별도의 외부 검토 절차로 고정된 신뢰 루트**에 포함돼야 한다. 현재 실물 인증 루트가 없어 allowlist는 **비어 있다**. 사용자 입력 키나 Boolean으로 우회할 수 없다.
2. 루트 승인 이후에도 신원기관이 서명한 등록부와 정답·의미 동치 승인 영수증을 각각 검증해야 한다. 개별 검토자·조정자 서명·중복 확인도 유지한다.
3. **현재 외부 신뢰 루트가 없으므로 실제 독립 정답 승인과 금융 정확도 점수는 모두 차단된다.** 합성 계산 시험은 명시적인 `synthetic_arithmetic_only=True`에서만 가능하며, 공개 정확도 키 `precision/recall/high_risk_recall`은 항상 `null`이다.
4. 기존 V105 합성시험 14건과 신규 V107 42건, 합계 56건을 로컬 일반·최적화 실행에서 검증했다.

코드가 신원기관을 만들거나 사람의 독립성을 보증하는 것은 아니다. 별도 외부 신원 확인·평가자 섭외·불일치 조정·서명·신뢰 루트 반영이 필요하다.

## 4. 이어서 개선할 우선 과제

- **P0:** 실제 외부 검토자 2명과 불일치 조정자 1명의 독립성·금융전문성 확인 및 서명 가능한 외부 신원 루트 확보. ChatGPT 내부 역할극이나 임의 키 생성은 이 조건을 만족하지 않는다.
- **P1:** 두 검토자가 독립적으로 전체 160 cue를 분할·판정하고 원음 확인 OPEN을 해결한 후, 조정자가 주장 단위의 내용·출처·화자 입장·조건/예외 동치를 봉인.
- **P2:** 독립 정답을 고정한 뒤 엔진의 미공개 예측을 개봉해 원자 주장 TP/FP/FN·고위험 누락·수정 빈도를 평가. 평가 범위와 승인 기준은 비교 전에 확정.
- **P3:** 이 파일럿과 분리된 미노출 영상의 무작위/주제별 표본을 추가하고, 외부 검토자·모델·근거 검색·원음·OPEN 해결시간을 각각 계측하여 791편 확장 판단.

## 5. 배포·불변 조건

`main`, 승인된 Master116/P4/V5 및 V98 원본 대기열은 건드리지 않는다. GitHub 검증 브랜치와 Draft PR #53에서만 신규 코드·공개 SHA 영수증을 관리한다. 비공개 ZIP에는 원본이 있으므로 **GitHub 또는 공개 자료로 업로드하지 않는다.** A/B 검토자에게는 소유자용 전체 복구 ZIP이 아닌 역할별 ZIP만 따로 전달해야 한다.

**최종 분리 판정:** 원본·블라인드 포맷·서명 루트 차단·합성 회귀시험 **PASS**, 실제 외부 독립 의미 정확도 **NO-SCORE**, 개인 투자자문 자동 승인 **0 / P0 NO-GO**.
