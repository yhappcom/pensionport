## 1. V120 개발용 참조셋 중복 조정 — 엔진 정확도 개선과 다른 작업

- 원본 영상 `Yb_5prWaqhk` 173 cue, 원본 SHA-256 `19ce2a37a37079dc0a6ea4dde3d031bdc2b7bb990f0506fd1e0610442dbf0145`를 보관본과 다시 검증했다.
- 이전 ChatGPT 참조 후보 **59개 중 의미 중복성이 높은 2쌍**을 원문 재대조해 **57개 정식 *잠정 채팅 참조 후보***로 조정했다. 기업 수익성 부진/적자 설명과 운용사 고유재산·고객재산 분리 원칙의 반복 설명이다. 다른 개념인 별도 수탁기관 보관은 별도로 유지한다. 이 두 병합은 해석적으로 재검토 가능하며 외부 독립 골드로 인증되지 않는다.
- “시스템 오류 가능성이 거의 없다”와 “없다”의 **화자 강조·자기수정**, 파생형 예외, 손실 대기 기회 소멸과 손실 실현은 구분해 유지했다. 과일바구니 유추는 독립 금융 사실이 아닌 문맥/비유로 명시하고 담화 평가 원장에서는 보존했다.
- 동일한 **V120 고정 기존 46개 예측**과 보수적 1:1 의미 대응을 재계산하면 TP **35**, FP **11**, FN **22**, 개발용 참조 precision **76.1%**, recall **61.4%**, 고위험 재현율 **60.9%**이다. 기존 값 **35/11/24, 76.1%/59.3%/60.9%** 대비 FN 2건이 감소한 것은 **참조셋 분모 변경만의 효과**다. 실제 원자 추출 알고리즘의 성능 향상 또는 미노출 독립 시험 합격이 아니다.
- 이 수치는 이전 채팅의 주제·예측 노출과 동일 모델의 참조 작성에 영향을 받는다. **CHAT_INTERNAL_DEVELOPMENT_POSTHOC**, `independent_gold=false`, 외부 인증값 NULL.

## 2. P0-1 원자 주장 분할/동치 결함 개선

- 이전 V117 **46개 잠정 주장 가운데 11개**에 대해 SHA 고정 출처 기반 **8건 다중 분할, 2건 단일 범위 축소·강도 복구, 1건 반복주장→추가 출처 변환**의 *수정 제안*을 작성했다. 부모 ID와 원본 cue·해시를 보존한 **18개 수정 하위 주장**을 제안하고, 나머지 35개는 변경하지 않은 후보로 유지하여 **53개 잠정 후보**를 산출했다.
- 핵심 수정: (a) 주식 ATS 매매와 ETF KRX 매매를 분리, (b) 수익성/부채/자본잠식/위법을 분리, (c) 지수 추적·괴리율을 분리, (d) ETF 규모가 상장폐지 사유 중 ‘압도적 1위’라는 화자 단정을 약화하지 않기, (e) 장내매도·해지상환·손실 실현 구분, (f) “거의 없다→없다→파생형 예외”의 화자 강조·예외 경로 연결.
- 소프트웨어 게이트 `apply_host_reviewed_atomic_patch`는 어느 원본 SRT라도 **소유자·호스트가 제공한 단위별 분할·재작성·반복근거 표**를 출처 SHA·순서·하위 claim ID로 검사하고 비승인 후보로 돌려준다. 실제 한국어 금융 의미의 분할 여부와 정오 판정은 **ChatGPT가 채팅 내부에서 제공**한다. 자동 모델 호출·금융 정답 인증 기능이라고 주장하지 않는다. 이 53개는 **V117 동일 개발 영상에 대한 사후 수정 제안**이지 새로운 미노출 영상의 엔진 예측이 아니다.
