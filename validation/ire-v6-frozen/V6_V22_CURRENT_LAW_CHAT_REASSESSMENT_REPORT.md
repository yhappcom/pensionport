# IRE V6 V22 — 과거 영상의 현행 법령 재판정 및 ChatGPT 보완 게이트

**작성일:** 2026-11-10 KST · **기준 코드:** V21 `c94defcf648baa3ec1266a42a460abfac76f59ce` · **상태:** 검증 브랜치 전용 / 투자자문 지식 자동 승인 없음 / P0 NO-GO.

## 1. 사용자 요구의 명시적 실행 계약

**현재 투자자문용 현재성 판단:** 옛 영상의 원자 주장을 원본·ID·조건·화자와 함께 불변 보관하고 **자문을 작성하는 날(`current_as_of`)에 시행 중인 법령** 및 공식기관의 최신 제도 안내와 대조한다. 과거 영상의 게시일은 현재 규정의 적격성 판단을 제한하지 않는다. 현재 법규가 과거 발언 이후 개정된 경우에도 오늘 조언의 법률 비교에 적용해야 한다.

**역사 검증과 구별:** 원래 발언이 촬영 당시 적법·정확했는지 평가하는 연구에는 그 당시의 법령판본이 필요하다. 오늘의 법령을 과거로 소급하여 '그 시점에도 적용됐다'거나 과거 이미 완료한 증여·과세 사건에 새 법률을 소급 적용했다는 주장은 금지한다. 과거 거래의 세금 신고·추징 여부는 **실제 거래일과 과도기 부칙**을 별도로 확인해야 한다.

**엔진과 ChatGPT 역할:** V22 엔진은 원본 원자, 오늘 날짜, 법규 유효기간, 공신력 있는 URL 도메인, 법규 발췌문 SHA 및 연결 근거를 **기계적으로 검증**한다. 법령의 복합 의미, 조건·예외와 실제 계좌·연령·세액·상품 적용 범위를 코드만으로 판단하지 못하면 `prepare_private_current_law_chat_packet`이 **사실 검토를 현 채팅으로 전달**하고 근거를 요구한다. 채팅이 판단한 뒤 `audit_current_law_reassessment`가 원자-근거 관계·현재성·원본 인용 SHA·미해결 항목을 검사한다. 채팅 해석은 독립 인간 골드가 아니며 **자동 법률 자문/지식 승인으로 승격되지 않는다**.

| ChatGPT 현재 규정 비교 상태 | 의미 | 개인 자문 활용 |
|---|---|---|
| `CURRENT_RULE_CONTRADICTS_SOURCE` | 현재 규정의 명시적 예외·요건에 비추어 영상의 단정과 충돌 | 영상 그대로 인용 금지, 현재 규정 재설명 필요 |
| `CURRENT_RULE_SCOPE_MISSING` | 예외·적용 대상·계좌·기간 미구분 | 조건과 예외 확인 전 일반화 금지 |
| `CURRENT_GENERAL_RULE_CONSISTENT_CONDITIONAL` | 오늘의 일반 규정과 조건부 일치하는 내부 검토 | 조건 기재 및 별도 적용성 점검 |
| `CURRENT_FACT_OR_APPLICABILITY_UNKNOWN` | 실증/법령 근거 또는 개인 조건 미확보 | OPEN |
| `NOT_A_REGULATORY_CLAIM` | 질문·의견 등 법률 사실 단정 아님 | 일반 투자 위험은 별도 판단 |

### 기계적으로 보장하는 것과 보장하지 못하는 것

- 보장되는 구조: 원본 SRT·원자 후보 감사, 현재 법령 시행일/만료일, 30일 초과 재조회 보류, 공식 도메인 목록, 법규 발췌문 SHA, 비공개 원자 ID/명제 해시, 1:1 심사 항목, `CHATGPT_REVIEW_REQUIRED` 큐, 사용자 원본·과거 V21 기록 보존, 개인 승인·독립 정답·P0 GO 상시 false.
- **보장되지 않음:** 발췌문 내용 자체의 정부 발행 인증, 공식 법령 본문 **전체 바이트/법제처 서명** 검증, 채팅 해석의 완전성, 계좌·개인별 적용성, 영상 전수 정확도 또는 독립 정밀도/재현율. 이번 근거 발췌문은 공개 공식 페이지의 *채팅 재서술 요약*에 대한 SHA이며 공식 원문 전체 SHA가 아니다. `document_body_sha256=None`으로 기록.
- 오프라인 코드 자체는 인터넷이나 모델 API를 호출하지 않으며 법적 주장을 자동 추정하지 않는다. 관련 공식 근거가 없거나 30일 이상 오래됐거나 시행 전/만료된 규정으로 현재 일치 판정을 내리려 하면 **차단**; 채팅의 근거 조사가 필요한 항목은 OPEN으로 전환.
