## 실제 신규 수행과 원본 영수증

비공개 원본 1-70.zip의 실제 #1~#5 SRT를 읽어 기존 V37 원본 SHA를 일치 확인했다. 원본 5,129개 cue, 130개 40-cue 창, 1,603개 V33 잠정 발화 후보를 원본 V39 주 모듈의 발화 레지스트리로 다시 생성하여 1,603개 후보 각각의 창 ID, 후보 ID, 인용 본문 SHA, 원본 cue 범위와 비교했다. 원본 V39 주 모듈은 GitHub와 동일한 바이트이지만 source.py/V33 보조 모듈은 V57 호환 구현이다. 전체 clean checkout이 동일 환경에서 직접 실행됐다는 인증은 아니다.

기존 V61.1에 비공개로 보존된 고위험 발화 12개/33개 의미 단위에 더해 **신규 38개 고위험 발화/67개 의미 단위를 직접 작성**했다. 총 **50/1,603 발화 부모가 100개 의미 단위**로 검토되었다. 이 의미 단위에는 영상의 질문·투자 가정·개인 권고·자막 불확실성과 설명 주장이 모두 포함되어 있으며, 100개 독립적으로 인증된 금융 사실 또는 정답 원자가 아니다.

## 미완료 P0 과제와 허위 완료 차단

- **P0-1:** 원본 cue와 1,603 후보 소유권의 계산은 완료. 금융 의미상 최종 원자 분할은 **50/1,603**, 미완료 1,553. 채팅 의미 주석은 외부 블라인드 정답이 아니다.
- **P0-2:** 기존 V60 금융 위험 10건 중 6건은 일반 법령/계산 범위의 정정 방향을 확보했으나, 상세 계좌·발행사 약관, 외환 거래별 과세 원전, 올웨더 1972~2022 수익률 원표 등 **4건 핵심 증빙 OPEN**. 기존 역사 원음·발행사 특정 증거 **8건도 미해결**. 새 9개 현행 규정 대조가 이를 자동 닫지 않는다.
- **P0-3:** 첫 5편 130창 SHA 출처 인벤토리는 V58에 있고, V57의 실물 22창 이벤트를 보존한다. V55 누적 100창과 초기 8창의 실제 SQLite 파일이 없어 **108창 원본 ACID 체인 무손실 복구는 실패/미확보**. 공개 SHA만으로 V40 이벤트를 위조하지 않는다.
- **독립 정확도:** 9편 독립 인간 2명+조정자 1명 사전등록에 해당하는 실제 서명/봉인 정답셋이 여전히 없으므로 정확도·정밀도·재현율 **NO_SCORE**. 채팅이 참조정답을 직접 만들면 내부 개발 참고자료일 뿐이다.

검증 전용 코드 v62_p0_release_readiness.py는 이런 blockers가 남아 있으면 NO-GO를 반환하며, 모든 숫자 조건을 충족해도 별도 외부 독립 승인 없이 자동 GO를 발급하지 않는다. 관련 합성시험 test_v62_p0_release_readiness.py를 validation 경로에 추가했으며 **기존 V6 106파일·647테스트 원장에는 추가/수정을 하지 않았다**. 검증 모듈은 현재 운영용 자문 진입점에 필수 결합되지 않았고, 기존 CI가 신규 합성시험을 자동 실행한다고 주장하지 않는다.
