# V113 — V98/V101/V102 ↔ V109–V112 출처 창 중복 검문과 OPEN 12건 증거 결손

기준일: 2026-11-14 KST. **이번 턴에는 공개 GitHub 영수증과 개인 라이브러리의 V92/V96/V97/V98/V102/V108/V110/V111/V112 비공개 복구 ZIP을 실제로 불러와 읽기 전용 교차검증했다.** 자막별 출처 위치·SHA는 직접 대조했지만, 별도의 원본 `1-70.zip` 전체 바이트를 재다운로드해 SHA를 새로 측정하거나 실제 음성·영상·계좌 원표를 확보하지는 않았다. **새 원음 판정·개인 과세 승인 0건**이다. GitHub에는 비공개 SRT·계좌자료·의미 주석 원문을 업로드하지 않는다.

## 1. 실제 검문: 이미 읽은 창의 반복 계상 차단

공개 기록에서 다음의 서로 다른 video-id/window-id 쌍을 확인했다.

| 기원 | 고정 창 | 기존 채팅 직접 검토 cue | 이번 V113 신규 의미 검토 |
|---|---|---:|---:|
| V109 → V110/V111/V112의 **동일 출처를 반복 분석한 계보** | #1 W00020, #3 W00008, #5 W00006, #7 W00065 | 160 | 0 |
| V101의 여섯 창 | #1 W00012, #2 W00029, #3 W00017, #4 W00005, #5 W00016, #7 W00024 | 240 | 0 |
| V102의 두 창 | #1 W00009, #7 W00033 | 80 | 0 |
| **이 세 코호트에서만 확인된 출처 창 합집합** | **12개의 서로 다른 40-cue 창** | **480** | **0** |

이 12개 창은 서로 **video-id와 window-id의 복합키가 겹치지 않으며**, V98 원본의 여섯 영상·399개 창과 범위가 일치한다. 추가로 **비공개 V98의 15,857개 cue SHA 목록**과 V109/V112 160개 및 V102 누적 320개의 실제 원장 키를 대조해 **480/480개 cue SHA 일치, 두 연구 코호트 간 겹치는 cue 키 0개**임을 확인했다. 따라서 **위 세 코호트 내부에서만** 160 + 240 + 80 = 480개의 서로 다른 cue-창 위치가 확인된다. 분모 V98 15,857개 cue 기준 약 **3.03%**이다. 이들 12개 창에 속하지 않는 원본 cue는 **15,377개(96.97%)**이다.

**추가 이전 원장 대조:** 비공개 V92의 소스에 연결된 390개 부모(고유 cue 위치 1,958개), V96 직접 검토 61개 cue, V97 비교 200개 cue, V108 검토 160개 cue를 동일한 V98 15,857개 원장과 대조했다. V113의 480개와 cue 위치가 겹치는 것은 **V96에 존재하는 1개뿐**이며, V92·V97·V108과는 겹치지 않았다. 따라서 이 명시된 이력 범위의 source-cue 위치 합집합은 **2,858개**이며, 480개 중 해당 이전 네 집합에 없었던 위치는 **479개**다. 이는 **원자 주장이나 승인 금융 지식 2,858개**를 뜻하지 않으며, 확인하지 못한 V75 및 기타 이력을 포함한 완전한 중복 인증이 아니다.

**중요한 비합산 규칙:** V109·V110·V111·V112가 같은 160개 cue를 반복 다루었다고 640개로 합산하면 안 된다. V102의 **15,537개**는 *V101/V102 오버레이에 아직 연결되지 않은 cue*이며, V109의 별도 160개를 무시한 집계다. V113의 15,377개는 *선정한 12개 창 바깥의 범위*이다. 어느 수치도 과거 V92/V96/V97/V108 또는 V75 전체와 완전히 대조된 고유 의미 검토 총량을 뜻하지 않는다.

특히 V75의 원장 404건과 원본 식별키 대응이 아직 복구되지 않았고, V92의 검토 단위와 현재 12개 창 간 cue 수준의 실물 교집합도 본 실행에서 전부 재생성하지 않았다. 따라서 **'역사 전체에서 새롭게 확인된 고유 cue 480개' 또는 'V98 전체 의미 완성 480개'는 주장하지 않는다.** 각 창의 부모 후보·의미 단위·금융 사실 후보 수도 서로 다른 측정 단위이므로 합산하거나 동일시하지 않는다.

## 2. OPEN 12건: 확보한 증거와 확보되지 않은 증거를 구분

V111과 V112의 해시-only 출처/상태 영수증은 동일하게 **22건 중 문맥 해결 10건, 미해결 12건**을 기록한다. 개인 비공개 V110·V111·V112 복구 ZIP의 **개별 OPEN 12건 ID·소속 영상·원문 cue 번호·시각·출처 SHA·요구 증거 종류**를 실제로 복구하고 상호 일치시켰다. V111의 22개 판정과 V112의 85개 오버레이는 ID 기준 충돌이 없었다. 다만 **원음 파일·화면 원표·실제 개인 과세 증빙은 이 복구 ZIP에 포함되지 않았기 때문에** 어떤 OPEN도 임의 폐쇄하지 않았다. 개별 12건의 비공개 판정 문구와 타임코드는 공개 GitHub에 게시하지 않았다.
