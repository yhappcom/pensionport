# V113 — V98/V101/V102 ↔ V109–V112 출처 창 중복 검문과 OPEN 12건 증거 결손

기준일: 2026-11-14 KST. **이번 턴은 공개 GitHub 원장에 접근해 읽기 전용 근거 대조를 수행했다.** V110/V111/V112 원본 포함 개인 비공개 ZIP의 내부 행별 자료, 실제 음성 7건 및 화면·계좌 원표 4건은 이 실행에서 원문 바이트로 재생·검증하지 못했다. 따라서 **새 원음 판정이나 개인 계좌 과세 승인 0건**이다. GitHub에는 비공개 SRT·계좌자료·의미 주석 원문을 업로드하지 않는다.

## 1. 실제 검문: 이미 읽은 창의 반복 계상 차단

공개 기록에서 다음의 서로 다른 video-id/window-id 쌍을 확인했다.

| 기원 | 고정 창 | 기존 채팅 직접 검토 cue | 이번 V113 신규 의미 검토 |
|---|---|---:|---:|
| V109 → V110/V111/V112의 **동일 출처를 반복 분석한 계보** | #1 W00020, #3 W00008, #5 W00006, #7 W00065 | 160 | 0 |
| V101의 여섯 창 | #1 W00012, #2 W00029, #3 W00017, #4 W00005, #5 W00016, #7 W00024 | 240 | 0 |
| V102의 두 창 | #1 W00009, #7 W00033 | 80 | 0 |
| **이 세 코호트에서만 확인된 출처 창 합집합** | **12개의 서로 다른 40-cue 창** | **480** | **0** |

이 12개 창은 서로 **video-id와 window-id의 복합키가 겹치지 않으며**, V98 원본의 여섯 영상·399개 창과 범위가 일치한다. 따라서 **위 세 코호트 내부에서만** 160 + 240 + 80 = 480개의 서로 다른 cue-창 위치가 확인된다. 분모 V98 15,857개 cue 기준 약 **3.03%**이다. 이들 12개 창에 속하지 않는 원본 cue는 **15,377개(96.97%)**이다.

**중요한 비합산 규칙:** V109·V110·V111·V112가 같은 160개 cue를 반복 다루었다고 640개로 합산하면 안 된다. V102의 **15,537개**는 *V101/V102 오버레이에 아직 연결되지 않은 cue*이며, V109의 별도 160개를 무시한 집계다. V113의 15,377개는 *선정한 12개 창 바깥의 범위*이다. 어느 수치도 과거 V92/V96/V97/V108 또는 V75 전체와 완전히 대조된 고유 의미 검토 총량을 뜻하지 않는다.

특히 V75의 원장 404건과 원본 식별키 대응이 아직 복구되지 않았고, V92의 검토 단위와 현재 12개 창 간 cue 수준의 실물 교집합도 본 실행에서 전부 재생성하지 않았다. 따라서 **'역사 전체에서 새롭게 확인된 고유 cue 480개' 또는 'V98 전체 의미 완성 480개'는 주장하지 않는다.** 각 창의 부모 후보·의미 단위·금융 사실 후보 수도 서로 다른 측정 단위이므로 합산하거나 동일시하지 않는다.

## 2. OPEN 12건: 확보한 증거와 확보되지 않은 증거를 구분

V111과 V112의 해시-only 출처/상태 영수증은 동일하게 **22건 중 문맥 해결 10건, 미해결 12건**을 기록한다. 개인 비공개 원장의 개별 OPEN 12건 전체 원문·발화시각·단위별 해시를 이번 재개 실행에서 복구하지 못했으므로, 각 단위를 확인 없이 재분류하거나 폐쇄하지 않았다.

| 현행 OPEN | 수 | 요구되는 실물 증거와 재판정 원칙 | V113 결론 |
|---|---:|---|---|
| `OPEN_AUDIO` | 7 | 해당 영상의 원음, cue 타임코드, 화자 연속 발화, 부정형·고유명사·숫자 구간을 원본 SRT와 직접 비교. 공개 기업연혁·서지 정보로 발음 자체를 확정하지 않음 | **미확보/재생 미검증 → OPEN 7** |
| `OPEN_VISUAL` / `OPEN_ACCOUNT_VISUAL` | 4 | 영상 화면의 계산표·기간·수치·단위·가정, 해당 계좌·원표의 증빙. 화면이 없을 때 ASR 문구만으로 계산 결과를 인증하지 않음 | **화면·원표 확인 없음 → OPEN 4** |
| `OPEN_ACCOUNT_SCOPE` | 1 | `V110_P10_U01`: 재원별 과세대상·세액공제 이력·계좌 유형·인출 방식·수령 연도 및 다른 소득. V112의 7개 재원 분기와 9개 개인 사실 필드를 유지 | **일반 세법 정정 연결 유지 / 개인 적용 OPEN 1** |
| **합계** | **12** | 새 영상·은행·개인 자료의 실제 증빙이 연결되기 전에는 폐쇄 금지 | **12 OPEN 유지** |

계좌별 연금 과세 일반론의 과잉 단정은 V112에서 이미 국세청·소득세법 시행령과 대조해 정정 대상으로 분류했다. V113은 **같은 사례를 새로 승인하거나 개인 세액으로 계산하지 않는다.** 연금계좌에서 인출되는 돈은 과세제외 납입금·이연퇴직소득·세액공제 받은 납입금/운용수익 등 재원과 연금수령/연금외수령을 먼저 구분해야 한다. 특정 과세연도 공식자료의 시행 범위 및 적용 요건을 재확인해야 한다.

**V111 문맥 해결 10건은 금융 사실 승인과 별개**이고, V112에서 V111의 22개 OPEN 대상으로 포함되지 않은 **63개 단위 역시 자동 완료 승격 대상이 아니다**. 원본 160 cue 중 부모 소속 158개와 미귀속 2개는 V110/V112의 별도 출처 관계로 보존된다.
