## 검증에 입각한 수정

초기 분석은 V164 typed REVIEW의 최종 승인 필드가 항상 False이고, V126/V127/V128이 동결 V123만 신뢰하기 때문에 '새 승인기를 만들어 네 관문 모두 바꿔야 한다'는 가정이었다. **대신 V143에서 이미 안전하게 검증되는 `NON_RESEARCH_CONTENT` 원자별 격리 계약을 재사용**할 수 있는지 실증했다.

- 신규 코드 `v166_source_only_to_v123_quarantine.py`: V164에서 실제 인용·문맥·원자 해시까지 증명한 **B0001 다섯 원자**(`C00001`, `C00003`, `C00277`, `C00285`, `C00293`)를 **금융 사실이 아닌 source-only 원문 확인 기록**으로 source-pinned quarantine에 추가하는 *초안* 생성기.
- 기존 `C00012` 격리 원장은 보존하고 5개 원자의 `NON_RESEARCH_CONTENT` 사유·typed 의미 메모 SHA를 추가. 원문 cue는 삭제/재배치하지 않음.
- 객관 역사·도서 사실 `C00002`, `C00009`, `C00010`은 **OPEN 그대로**. 위험 `12` 및 `disagreements_adjudicated=false`는 원본에서 임의로 수정하지 않음.
- **작성기가 자체적으로 PASS를 만들지 않음**: `release_authorized_by_compiler=False`; 이후 실제 동결 `require_chat_final_release`를 반드시 다시 실행해야 함. 실제 출처·위험·갈등 미해결이 남으면 V126/V128은 여전히 HOLD.
- 해당 방식은 frozen V123/V126/V127/V128을 개조하지 않고 기존 원자별 격리를 사용하므로 기존 보안 모델과 원자적 발행 조건을 유지함. 단, 그만큼 ChatGPT의 분류 실질 검토와 원전 확보가 필수다.
