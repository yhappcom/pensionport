## 1. 이번 설계의 결정 사항

**V3.0은 유사 문장 후보 탐색을 최종 목표로 하지 않는다.** 연구의 최종 산출물은 (a) 원본 구간과 연결된 전체 원자 주장 원장, (b) 공식자료·정량·실증의 주장별 필수 연구 의무, (c) 범위·조건·발효일을 포함한 명제 관계 후보, (d) 개정·반박·영향전파가 가능한 지식 그래프의 검토 대기 이벤트, (e) 독립 연구 완결 판정 또는 구체적인 차단 사유다.

초기 구현은 **실제 진실 판정까지 완료한 엔진이 아니라, 위 계약을 실행 시점에 강제할 수 있는 초기 연구 작업 계획기와 명시적 프레임 비교 프로토타입**이다. 이 구분을 지키지 않으면 V2.3의 개발표본 100% 착시가 반복된다.

검증된 저장소 자료:
- `data/synthesis/investment_knowledge_001_260/claims_crosswalk_001_130.json` 2,127건 + `claims_crosswalk_131_260.json` 1,993건 = **4,120개** 역사 주장, 253편·39개 주제군. #71 대체 공개자막의 비표준 ID 13건은 정식 예외로 보존.
- `v5/policy/research_completion_gate_v1.json`의 원본·공식증거·정량/실증·일반 의사결정 4영역 및 `v5/integration/integration_policy_v1.json`의 승인이 필요한 append-only 지식 통합 규칙은 **그대로 상속**.
- #19·#20은 이미 V2.3 신규 영상 검증에 사용됐으므로 **개발·출처 계보 스모크 테스트용**으로만 활용한다. 두 파일의 역사 SRT SHA와 V3 원자주장 수 12+6을 확인할 뿐 원본 SRT 전문·음성/화면·공식 원문을 본 초기 작업에서 재검증하지 않는다.

## 2. 데이터 흐름과 계약

| 순서 | 모듈 | 입력·검증 | 실패 시 차단 |
|---|---|---|---|
| 1 | `SOURCE_PROVENANCE` | 원본 ID·원천 Git blob·SRT SHA·영상 번호·기간 | 출처 불일치/원문 불명 |
| 2 | `ATOMIC_COVERAGE` | 모든 실질 자막 구간과 원자 주장 연결·누락 0개 증명 | 원본 없이 완료 선언 불가 |
| 3 | `CLAIM_FRAME_AND_OBLIGATIONS` | 법/상품/수치/전략/정성 분류, 주체·행위·금융 역할·대상·국가·발효일·조건·단위 | `UNCLASSIFIED`는 근거 의무 면제 불가 |
| 4 | `PRIMARY_EVIDENCE` | 실제 읽은 공식 원문·원문 SHA·조항·효력일·적용 예외·제3자 감사 | URL만 있으면 미검증 |
| 5 | `QUANT_AND_EMPIRICAL` | 수식·납입시점·기간·세전/세후·재현 데이터·전략 비교·비용/위험 | 산식만 합격해도 사실 승인 금지 |
| 6 | `RELATION_CANDIDATES` | 금융 개념·동일성·조건부·반증·수치 의존·시간차·신규 개념 | 단순 의미 유사도만으로 자동 병합 금지 |
| 7 | `INDEPENDENT_REVIEW` | 원자 주장·공식증빙·실증방법론·관계판정의 별도 심사 | 독립 감사 전 완료 인증 금지 |
| 8 | `COMPLETION_AND_APPEND_ONLY_INTEGRATION` | V5 RESEARCH_COMPLETE + 인간 검토 관계 이벤트 + 계보·영향범위 | 기록 삭제·무증빙 병합 금지 |

### 재사용 vs 신규 구현

**이미 있는 기능, 보존:** V5 완결성 관문 `scripts/verify_v5_research_completion.py`, 지식통합 `scripts/verify_v5_knowledge_integration.py`, 역사 주장 원장, 원본 출처·정정 추적.

**이번 착수로 구현한 실행 기능:**
- `scripts/v30_integrated_research.py`: 기존 4,120건과 39개 주제의 전수 ID/역사 판정 보존 검증. #19·#20만 허용하는 *source-locked* 역사 개발자료 리더.
- 주장별 `UNCLASSIFIED` 상태·실행할 근거 의무·4가지 구체적 차단사유를 반환하는 **fail-closed 연구 작업 원장 생성**. 등록 원본 SHA가 일치해도 원본 자막 전문·독립 음성을 이번 차수에서 다시 확인하지 않았으므로 모두 `RESEARCH_BLOCKED`로 유지.
- 출처 검토가 선행된 주장과 **명시적 사람이 정한 금융 명제 프레임**을 전제로 하는 관계 후보 분류: 역할 다른 세법과 같은 숫자 구별, 발효일·조건 차이, 수치충돌, 정정 전용 출처 표시. `UNKNOWN` 날짜·대상은 자동 동일성 판단하지 않음.
- 정확한 `Decimal`로 월말 적립 미래가치·월말 지급 원금소진식의 산술 계산(월이율 = 명목 연이율 / 12)을 재현하되, 실제 상품계약·개인 금융·세후지급 보장을 주장하지 않음.
- `scripts/verify_v30_integrated_research.py`: 역사 영상 해시·차단 원장, 세금·금융 역할 분리, 반박 격리, 비정상 입력·미사용 영상 접근 거부, 4% 복리 및 원금소진 현금흐름 가정 반례를 검사.

**반드시 다음 단계에서 구현/연결해야 하는 기능 (아직 구현되지 않음):**
1. 비공개 원본 SRT의 안전한 로더, 영상 전체 구간 원자화, 검토 누락탐지와 검토자 비교 및 검증 가능한 atomic coverage 증명.
2. 명시적 프레임 등록을 보조할 금융 분류·의미 추론 모듈과 불확실성 관리. 현재 핵심 타입의 자동 추출은 **없음**. 누락된 프레임에 사람 검토 없이 값을 채우는 기능도 없음.
3. 검색·연결 계층: 4,120건 전체에 대해 topic-family → 임베딩/키워드 → 그래프와 관계 후보 → noncandidate 음성표본 감사. 이번 스모크는 역사 원장의 개수/계보를 확인하는 것이지 전체 4,120건에 대한 새로운 의미검색을 돌린 것은 아님.
4. 국가법령정보·국세청·공적기관 상품공시 등 실제 공식 원문 읽기·본문 인용 위치 검증·법령 발효일·관할·예외 검사.
5. 전략별 공공 실증자료 수집·원본 데이터 해시·비용/세금 반영·표본외 재현·편향 감사. 재현 불가능한 성과 주장 `BLOCKED` 유지.
6. 원자 주장과 실제 근거가 인증된 후 관계를 인간 승인하여 기존 V5 append-only 지식 통합 이벤트로 전달하는 어댑터 및 재검토 영향 전파.
7. 외부 독립 검사자와 시간상 고정한 진단 표본을 이용하는 **실전 평가 및 신뢰구간 보고**.

## 3. 안전 불변조건

원본 변경 없음; 법률 관련성·숫자 유사성만으로 사실 승인 없음; `CONTRADICTED` 주장은 `CORRECTION_ONLY`만; `HYPOTHETICAL` 출처는 미재현 검토 전용; 법령 발효일 `UNKNOWN`이면 동일 규칙으로 단정하지 않음; 공식자료 링크 자체가 승인 증빙은 아님; 모든 실질 주장에는 독립 증거 또는 차단 사유; 자동 지식 병합·연구완결증명·개인투자추천·매매 0건.

`V3.0` 예측 관계 유형은 후보판정이며 지식의 실제 동일성/반박 사실을 확정하지 못한다. 원래 V3에서 `APPROVED`로 관리한 교육 주장도 V5의 별도 `RESEARCH_COMPLETE` 조건을 충족하기 전까지 지식 통합 허용 근거가 아니다.

## 4. 구현 전 고정해 둔 성능 평가 원칙

[평가 계약](contracts/evaluation_protocol_v1.json)에 #1~#20 개발자료와 **#21 이후 보호된 미사용 평가자료**의 경계를 명시한다. 평가용 새 영상은 평가쌍·독립 블라인드 판정·층화된 검색후보/비후보 표본·코드 SHA를 **예측 전에** 커밋해 고정한다. 평가 결과를 본 뒤 수정하면 같은 영상을 독립 신규 평가로 재사용하지 않는다.

목표치는 신규 영상 후보 재현율 95% 이상, 정밀도 85% 이상, 핵심 분야별 재현율 90% 이상 **목표**다. 실제 신뢰구간, 충분한 표본, FN/FP 원인, 미라벨 후보 검토비용, 독립 원본·자료검증을 함께 확인하기 전에는 운영 승인할 수 없다. 중요한 주장·근거는 확인하거나 정확하게 차단하는 100% 처리율을 목표로 하되 **모든 중요한 주장이 참이라고 판정해야 한다는 뜻은 아니다.**

## 5. 검증 및 수용 기준

현재 첫 스모크의 합격 범위는 기존 지식 4,120건·253편·39주제 보존, #19·#20 역사 개발자료 18개 주장에 대해 누락 없는 차단 작업표 생성, 금융 역할 프레임의 오류/반례 실험, 명목연 4% 적립·인출 산식 검산, 비공개/미사용 영상 접근 및 미승인 지식승격 차단이다.

V3.0 통합 연구 엔진을 **실제 영상 분석에 투입할 수 있는 완성 단계**로 판단하려면 위 미구현 7개 기능을 구현하고, 원본 동기화→원자화→공식·수치·실증 근거 완결→관계후보→인간검토→V5 append-only 이벤트까지 **하나의 실제 사례에서 재현 가능**해야 한다.
