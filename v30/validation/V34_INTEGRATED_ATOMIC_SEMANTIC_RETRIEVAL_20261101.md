## 1. 설계 및 실행 범위

V3.4는 동결된 V3.0~V3.3을 수정하지 않는 새 모듈로 구축했다.

1. \`scripts/v30_v34_atomic_semantics.py\`: 실제 SHA-256으로 결속한 원본 SRT 전체 cue를 빠짐없이 원자 주장 **초안**에 매핑한다. 하나의 cue에 여러 문장을 분할할 수 있고, 타임코드·인용문 해시·claim ID를 양방향 검증한다. 비금융 발언이라도 자동 제외하지 않고 \`REVIEW_REQUIRED\`로 남긴다. 부정·가정·조건·금액(Decimal)·금융상품·금융 사건은 **의미구조 제안**으로만 추출한다. 띄어쓰기·영상 문장 경계·다중 금융 사건의 완전 분해는 보장되지 않는다.
2. \`scripts/v30_v34_model_bridge.py\`: 별도 실행 모델의 atom 목록 및 typed frame 제안을 원본 SRT SHA, claim quote SHA, 전체 cue/claim 전수, 모델 SHA, 프롬프트 SHA로 고정한다. 원문에 없는 발언, cue 생략, 부적절한 이벤트·역할, 매칭 안 되는 인용문, 모델 변경을 차단한다. SHA만으로 실제 모델 실행 주체나 인간 독립성을 증명하지는 못한다. 외부 모델의 실제 실행은 제공하지 않는다.
3. \`scripts/v30_v34_retrieval.py\`: 한국어 단어 BM25·문자 2/3/4-gram BM25·금융 사건/엔티티/행위 등 여러 검색 경로의 상위순위를 RRF로 통합한다. 선택적으로 모델 SHA가 고정된 외부 벡터와 별도 검토된 그래프 관계를 활용한다. 특정 이벤트·범위가 미분류돼도 해당 원장 주장을 삭제하거나 후보군에서 영구 배제하지 않는다. 동일 상품의 다른 세법 사건, 조건 차이, 부정 가능성, 반박 이력은 **관계 검토 후보**이지 자동 동일성·실제 반박 인증이 아니다.
4. \`scripts/v30_v34_pipeline.py\`: SRT → 전수 원자 초안 → 전수 의미구조 초안 → 역사 4,120개 원장 색인 → 개별 top-10 관계 검토 및 비후보 진단을 하나의 호출로 연결한다. 외부 모델의 초안은 선택적으로 주입할 수 있다. 개발 입력은 #1~#260으로 제한한다. 출력 전문은 Git 저장소 밖에 파일 모드 0600으로 생성하며 사용자 자막 전문이나 모델 프롬프트를 공개 Git/CI 로그로 내보내지 않는다.
5. \`scripts/verify_v30_v34_integrated.py\`: 인용문 위조·누락 cue·부정 문맥·전혀 다른 이벤트·잘못된 벡터/모델·외부 모델 문구 위조·해시 불일치·121개 cue 규모·민감 출력 경계를 합성 자료로 검사한다.
6. \`scripts/verify_v30_v34_retro.py\`: 역사상 이미 노출된 #66~#70의 기존 관계 판정쌍을 사용한 **후향적 개발 진단**. 신규 미노출 성능과 엄격히 분리한다.

## 2. 기존 4,120건 계보와 인덱스 적재

기존 \`claims_crosswalk_001_130.json\` 2,127건 및 \`claims_crosswalk_131_260.json\` 1,993건을 원본대로 유지한다. 실제 인덱스 4,120건, 역사 영상 253편의 수량을 검증했다.

추가로 다음 예외를 발견하여 **삭제하거나 정상 SHA로 날조하지 않고** 원장 출처 위험으로 격리했다.

| 상태 | 주장 수 | V3.4 처리 |
|---|---:|---|
| 원본 SHA 형식 정상(64자리) | 4,065 | 원래 기록값을 유지하되 원음 진위/독립 감사까지 인증한 것은 아님 |
| 원본 SHA 기록 없음 | 38 | \`HISTORIC_ORIGINAL_SHA_MISSING\`, 원본 해시 NULL |
| 원본 SHA 잘못된 길이(54자리) | 17 | \`HISTORIC_ORIGINAL_SHA_MALFORMED\`, 원본 해시 NULL |
| #71 공개대체 자막의 비표준 claim ID | 13 | 기존 식별자를 유지하고 해당 계보를 별도 표시, 신규 정식 ID로 변환하지 않음 |

상기 38+17=55건이 해당 형태의 출처 미확정 주장이다. **기존 4,120건과 253편 숫자를 그대로 유지하는 것이 목표이며, 잘못된 SHA는 원본 재확인이 필요하다.**

개발 진단 데이터는 이전 V3.2의 #66~#70 영상 관계표 48쌍(관련 24, 무관 24)이다. V3.4에서는 같은 108개 역사 주장으로 검색 인덱스를 구축하고 양방향 top-10 검색에 관계가 포함됐는지 검사한다.
