**판정:** V3.3 프레임·검토·블라인드 평가 프로토콜 코드 및 합성 적대적 시험 구현·실행 완료. **실제 원본 #261+의 독립 성능 입증은 미완료, RESEARCH/PRODUCTION BLOCKED**.

## 1. 기존 V3.2 실패에서 변경한 설계

V3.2는 별도 실제 영상 #66~#70에서 상위10 관계 재현율 5/24(20.8%)에 불과하고, 금융 사건 분류를 하지 못한 기존 핵심 주장이 108건 중 65건이었다. #1~#5·#61~#65의 개발 라벨 92쌍에 적합하더라도 새로운 주제에서 무너지는 것을 확인했으므로, **키워드 사전 확장으로 이 결함을 해결했다고 주장하지 않는다**.

새로운 설계는 다음 세 부분을 분리한다.

1. **원본·원자 주장 검증:** 실제 SRT 바이트 SHA256, 자막 구간 전체, 인용 문장, 원자 주장 장부 전체 SHA256 및 각 주장에 대한 양방향 매핑을 확인한다. 새 원자 발언은 `ORIGINAL_UNEVALUATED`로 표시한다. 기존 V3의 `SPEAKER_OPINION`으로 바꿔 확정하지 않는다. 기존 동결된 V3.0 검사 코드를 고치지 않고 임시 복사본에서만 구조 검사를 재사용한다.
2. **독립적인 금융 의미구조 추출 및 검토:** 외부 모델 또는 사람이 제안한 `subject`, `object`, `action`, `event_kind`, `modality`, `jurisdiction`, `effective_date`, `conditions`, `measurement`에 대해 타입·범위·원문·금액·금리 기준을 확인한다. 모르거나 모호한 값은 `UNRESOLVED`로 남고 지식검색 승인에 사용할 수 없다. 원문 검토자와 **서로 다른** 의미구조 검토자의 역할별 HMAC 서명 두 개가 정확히 같은 프레임·원자 장부에 연결되어야 구조 검토 완료로 취급한다. **자격증명 소유가 독립된 실제 인간의 신원증명을 자동으로 제공하지는 않는다.**
3. **별도의 블라인드 관계평가:** 사전 고정된 주장을 전수 쌍으로 구성한다. 검토자용 비공개 자료에는 모델 예측을 포함하지 않는다. 외부 검토자 A·B가 각각 전수 양성/음성 라벨을 서명하고, 의견 차이는 제3의 심사자가 조정한다. 실제 예측 결과는 독립 골드가 Git에 먼저 등록된 다음 별도 커밋으로 보존한다. 후보에 포함되지 않은 쌍까지 TP/FN/FP/TN 분모에 포함하여 Wilson 95% 신뢰구간을 계산한다. 출처·골드·모델 SHA 불일치, 전수 쌍 누락, 미분류, 서명 재사용은 차단한다. **독립 인사 검증과 실제 블라인드 준수는 외부 기관이 확인해야 한다.**

## 5. 실제 원본이 확보된 이후의 재현 절차

원본 SRT 전문, 전수 원자 장부, 검토자 키 등은 **GitHub 저장소 밖**에 보관해야 한다. 원본/키는 `0600` 파일 권한을 적용하며 출처 검토자·의미 검토자·블라인드 골드 검토자 A/B는 서로 독립된 실제 신원이어야 한다.

원본과 사람이 검토한 전체 원자 장부가 있으면 다음 CLI에서 비공개 구조화 초안을 만든다.

```bash
python -B scripts/v30_semantic_extraction_v33.py \
  --root . \
  --original-srt /secure/261_original.srt \
  --source-manifest /secure/261_original_manifest.json \
  --reviewed-atomic-ledger /secure/261_full_atomic_ledger.json \
  --private-output /secure/261_semantic_proposals.json
```

선택적인 외부 추출 모델이 있을 경우 `--external-model-proposals` 및 `--model-sha256`으로 검증 가능한 초안을 추가할 수 있다. 모델의 결과는 **항상 PROPOSED**로 유지되며 사람이 승인·서명하기 전에는 검색 권위에 사용하지 않는다.

다음으로 `v30_semantic_frame_v33.verify_independent_frame`에 실제 원본·전체 원자 장부·원본 검토 서명·의미구조 검토 서명을 각각 입력한다. 성공한 `BoundSemanticFrame`만 `v30_blind_recall_v33.make_blind_census`의 입력이 된다. 이 모듈의 전수 패킷에는 예측 결과가 없고 원문 발언을 포함하므로 **별도 비공개 심사 채널**로 전달한다. 외부 골드를 코드/인덱스 동결 후 Git에 사전 등록한 다음에만 예측을 생성하고 전체 후보·비후보의 재현율을 계산한다.

기준은 이미 프로젝트에서 정한 **재현율 Wilson 95% 하한 95% 이상 / 정밀도 Wilson 95% 하한 85% 이상**, 각 금융 주제군의 최소 재현율, 증거 미확정 0건 승인 원칙이다. 실제 양성 쌍 수가 부족하면 신뢰하한 기준을 만족할 수 없으므로 표본 크기도 검토해야 한다.
