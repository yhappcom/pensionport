## 3. 전수·검증 단계별 안전성

- 원본 SRT는 저장소에서 읽어 쓰지 않고, 프로그램에 제공되는 원본 파일을 SHA256으로 대조한다. 비공개 원문 초안은 저장소 밖의 0600 권한 파일로만 기록 가능하다.
- 원본 구간이 1개라도 누락되거나 중요한 원자 주장이 근거 없이 제외되면 완료라고 표시할 수 없다.
- 재현 계산값이 수학적으로 정확해도 실제 상품계약·세금·주요 시장데이터가 검증됐다는 결론을 내리지 않는다.
- 법령·공시의 인용 구절과 효력일·예외를 확인하는 기능은 실제 원문 바이트를 요구한다. 외부 감사자가 해당 공식문서의 진위와 적용조건을 확인할 때만 근거 상태를 올릴 수 있다.
- 실제 독립 검토자의 신원을 확인하는 조직적 절차는 HMAC 코드 외부에 있다. 합성 서명키로 테스트를 통과해도 실제 사람의 인증을 보장하지 않는다.
- 서명된 원자 주장이라도 역사 V3에서 CONTRADICTED인 경우 독립 정정 전용이며, 자동 긍정 지식으로 병합되지 않는다.
- 자동 개인 투자 권고·매매·원본 덮어쓰기·완결 인증서 임의 발행은 모두 불허한다.

## 4. 기존 #19 소스 개발 입력

[공개된 등록 정보만 포함한 #19 입력 manifest](examples/019_readonly_source_manifest.json)는 실제 기존 영상 번호·ID·원본 SRT SHA·1,134구간·V3 Git blob을 제공하지만 **원본 비공개 SRT·독립 서명·실제 자료는 포함하지 않는다**.

안전한 원본 구간 전처리 예:

    python -B scripts/v30_claim_extraction.py --original-srt /secure/019.srt --sha256 e7284caf3d5cee58a202ad29e88a39c57973d5f181dda018f47852a9f23200f3 --video-id zi9x_q2fYoc --private-out /secure/019_atomic_candidates.json

실제 주장 장부 및 근거를 심사한 후 실행할 수 있는 통합 명령 예:

    python -B scripts/v30_research_pipeline.py --root . --manifest v30/examples/019_readonly_source_manifest.json --original-srt /secure/019.srt --atomic-ledger /secure/019_reviewed_ledger.json --evidence-package /secure/019_evidence.json --search-bank /secure/dev_search_bank.json --export-blocked-preview /secure/blocked_v5

독립 검토자 증명은 V30_REVIEWER_REGISTRY_PATH 환경변수에서 **저장소 밖의 0600 권한 파일**로 받는다. --independent-review와 --relation-review는 실제 외부 서명만 수용하며, --v5-certificate와 --v5-review는 기존 V5 인증서를 확인하기 위한 별도 입력이다.

## 5. 독립 신규 검증과 남은 필수 조건

[독립 평가기](../scripts/v30_independent_evaluator.py)는 분야별 TP/FN/FP/TN, Wilson 신뢰구간, 검색·데이터/모델 해시, 표본 구성, 과거 원장에 노출된 메타데이터 여부를 분리해 계산한다. 현재 **외부 독립 블라인드 골드라벨 또는 미노출 영상 성능시험은 진행하지 않았다.** 임의 표본으로 수치 목표를 통과해도 실제 운영 승인은 자동으로 승인하지 않는다.

실제 완료를 위해 별도로 확보해야 하는 것은 (a) 실제 원본 SRT와 독립 원자화 검토 (b) 공식자료·상품계약 및 시점별 법률 증명 (c) 진짜 공개 시계열·독립 정량/실증 검증 (d) 유효한 검토자 승인·V5 완료인증 (e) 신규 미노출 데이터의 검색정확도·처리량 평가 및 외부 브랜치 보호다.

**정확한 최종 상태:** 기술적으로 동작하는 연구 파이프라인과 안전장치가 구현됐으나, 실제 영상에 대한 독립 연구완결 증명은 0건이므로 운영 게이트는 BLOCKED로 유지한다. 합성 테스트 통과를 금융 사실 검증 완료로 설명하지 않는다.
