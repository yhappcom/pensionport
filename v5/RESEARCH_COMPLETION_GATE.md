# 박곰희TV V5 연구 완결성 검증 엔진 (2026-10-30)

## 목적: 최종 연구 완료 선언을 Fail Closed로 통제

연구의 **실행 종료**, GitHub **형식·산술 CI 성공**, 연구의 **실질적 완결**은 세 개의 다른 사건이다. 기존 완료 선언의 반복적 번복을 방지하기 위해 *최초 연구에서 무엇을 해야 할지 먼저 확정하고* 결과를 승인한다.

### 최초 연구 시 반드시 수행하는 네 가지 영역

1. `SOURCE_AND_CLAIMS`: 원본 SRT 전체 검토·원본 해시, 영상의 핵심 주장 전수 시간코드 매핑과 레거시 주장 ID 대조.
2. `PRIMARY_EVIDENCE`: 법령·세제·금융상품 등 주장의 독립적인 1차 근거, 적용 시점·예외·반대 근거의 실제 원문 검토.
3. `QUANT_AND_EMPIRICAL`: 숫자·기간·분배금·수수료 등의 재현 가능한 계산. 성과 및 전략의 우위 주장에는 **실제 시장 시계열 및 벤치마크·비용·편향·표본외 검증**이 필수. 합성 가정만으로 성과의 실증을 대체할 수 없다.
4. `GENERAL_DECISION`: 유지(`NO_CHANGE`)와 대안 비교, 투자기간·세후 비용·유동성·시장 상태별 반례·적용 제외 조건·영상 간 충돌 및 차단.

각 주장에 `LEGAL_OR_PRODUCT`, `NUMERIC`, `STRATEGY_OR_PERFORMANCE`, `QUALITATIVE` 유형을 연결한다. 복합 주장은 작은 원자 주장으로 나누거나 필요한 **모든** 검증 의무를 부과한다. 주장 한 건에 아무 근거 없이 `완료`가 붙을 수 없다.

## GitHub 구조

- 정책: `v5/policy/research_completion_gate_v1.json`
- 기존 상세 연구: `v5/videos/v5_NNN_<video_id>_advisory_review.json`
- 완결성 인증서: `v5/completion/v5_NNN_<video_id>_certificate.json`
- 기존 10편 상태: `v5/research_completion_001_010.json`
- Python: `scripts/verify_v5_research_completion.py`
- 명령: `python -B scripts/verify_v5_research_completion.py --root . --self-test`

신규 영상의 연구 JSON과 인증서가 동일한 커밋에 함께 있어야 한다. 인증서는 원본 연구 JSON의 SHA256, **모든 주장 ID**, 주장 유형·중요도·증거·모형·실증·반례·결론 제약·독립 감사를 기록한다. 파일이 바뀌면 인증서가 무효화된다.

### 결과 판정

- `RESEARCH_COMPLETE`: 네 영역이 전부 통과하고 중요 증거 미해결이 없으며, 기존 V5의 `DECISION_MODULE_READY_L2` 및 별도 출처·방법 검토를 충족한 경우에만 가능하다.
- `RESEARCH_BLOCKED`: 실증에 필요한 실제 데이터가 없거나 중요 근거가 빠지면 누락 증거·차단할 투자결정·재개 조건을 기록하고 완료를 금지한다. **BLOCKED 상태의 CI 성공은 연구 완료가 아니다.**
- 실제로 반박된 주장은 근거와 정정이 충분하면 `REFUTED`로 연구를 종결할 수 있으나, **원래 잘못된 투자원칙으로 재사용할 수 없다.**

이 검증기는 내부 기록/모형 연결과 공개 데이터 해시 등 재현 가능한 요소를 자동 점검한다. 공개 저장소에 **비공개 SRT나 개인 금융자료를 업로드하지 않는다.** Actions는 비공개 원본 음성·화면, 웹 페이지의 실질적인 문맥, 시장 데이터의 경제적 유효성을 독립적으로 보장할 수 없다. 인증서에 독립적 비판 검토가 필요하나 그 사실까지 소프트웨어가 보증하지는 않는다.

## 변동 통제와 반복 방지

검증기가 대상 주장의 입력·원본 해시·근거 버전·모형 버전을 확인해 이미 완료된 분석을 재사용한다. 실제로 새로운 상충 근거가 나타나면 영향받는 주장만 재검증하며, 단순히 새로운 체크리스트를 제안했다는 이유로 기존 연구 전체를 무조건 재실행하지 않는다. 실행 중단은 추후 같은 주장 ID를 기준으로 재개한다.

## 현재 1~10편

기존 122건의 주장 원장, 10개 정량 모형, 20개 합성 시나리오와 원본 해시 기록은 보존한다. 그러나 26건의 외부 증거가 미해결이고 모든 핵심 주장에 필요한 실증을 수행한 것은 아니므로 **완결성 최종 승인 0편**이다. 이 판단은 과거 연구를 삭제하거나 이미 검증한 자료를 다시 분석하라는 의미가 아니다.

## 시험 범위와 실제 검증의 구분

`--self-test`는 **합성 차단 사례와 의도적으로 변형한 잘못된 연구기록이 실패하는지**를 시험한다. 이 결과를 실제 #1~#10 연구의 독립 진위 검증으로 보고해서는 안 된다. 실제 연구 승인은 원본 전체 검토와 공식·실증 자료의 독립 대조를 거쳐야 한다.

연구 품질 승인과 개인별 투자자문 적합성은 별도다. `L3/L4`는 자동 승인하지 않는다.
