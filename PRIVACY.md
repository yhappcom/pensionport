# Publication and privacy boundary

This public repository's current tree contains only generic research-quality information. No source transcripts, copied media content, channel names, video titles, creator-identifying metadata, source-specific indices or individualized investment/account information should be committed here.

Do not upload detailed research archives or copyrighted third-party media text. Keep source evidence in an access-controlled private archive.

**A cleaned file tree is not a history purge.** Previously pushed commits, pull-request diffs, cached search results, forks and clones may still expose old data.

Repository administration is required to make the repository private and to plan any coordinated history rewrite. A force push or deletion cannot retract copies held by others.
