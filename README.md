# Pensionport — ChatGPT 중심 투자 연구 엔진 (Clean Start)

2026-11-27, 사용자 결정으로 기존 IRE 개발을 종료하고 SRT 원본에서 시작하는 신규 경량 엔진 개발로 전환한다. 이 저장소의 main은 신규 개발의 유일한 기준이다. 이전 엔진과 연구 결과는 별도 보존 브랜치에 동결되어 있으며 신규 연구에는 사용하지 않는다.

**목표:** ChatGPT가 791편 투자 영상의 원본을 연구하고, 최신 공식 금융 근거와 대조하여 최종 검증하며, 새로 얻은 지식을 누적해 투자 질문에 활용할 수 있는 시스템. 외부 LLM API 없이 현재 채팅과 연결된 도구만 사용한다. 포트폴리오 연결은 연구 엔진 완성 후 실시한다.

현재 D0·D1 PASS (저장소 전환 및 최소 기능 구현·기술 시험 완료), D2 PASS (첫 영상 2턴 실제 연구 완료), D3 운영 PASS (#273 퇴직연금 2턴 완료, 27자막/14 의미 의무/8 최종 판정; 내부 평가 14/14, 독립 인증 미확인). D4-1 PASS, 추가 5편 중 #266 및 #282 2턴 운영 검증·통합 완료(2/5편). 정식 운영 원장 4편/활성37개. #261 2턴 사후 진단 및 복제 저장·조회 성공, 참조 의무 사전 고정 실패로 HOLD(운영 승격 금지). #282 2턴 내부 운영 PASS(원문28개, 최종13개, 참조 의무 사전 고정, 운영4편/활성37개/판정61개). 추가 합격2/5편, #261 HOLD 유지, #280 2턴 시간 초과, 3턴 기술 복구 PASS/운영 HOLD(2턴 목표 미충족). 운영 원장 불변, 다음 #263 1턴. 기존 #269 HOLD 및 실험 복제본38개는 별도 보존하고 사용하지 않는다. 신규 엔진은 `engine.py`로 구현했다. D2 당시 신규 투자 지식 활성 17개, 연구 완료 영상 1편이었다. 실제 원문 173개와 최종 30개 의미 판정을 비공개 연구 원장에 저장했다(5 승인/12 교정/10 문맥/3 보류). D2 내부 운영 검증이며 독립 정확도 인증 및 신규 영상 간 통합 성능은 미검증이다. 과거 진행률은 계승하지 않는다. D1 시험 입력의 금융 의미는 검증하지 않았다.

**원본 업로드 범위:** 사용자 확인 기준 현재 약 1~300번 SRT가 업로드되어 있다. 791편은 최종 연구 대상이며 전체 업로드가 완료된 상태가 아니다. 2026-11-27 재접근으로 ZIP 3개(1-100/101-200/201-300) 다운로드 및 CRC 검증 완료. SRT 항목 300개 중 동일 바이트 복사본 1개, 고유 원본 299개. 번호별 대응 및 미노출 여부는 별도 확인한다.
