# Pensionport — ChatGPT 중심 투자 연구 엔진 (Clean Start)

2026-11-27, 사용자 결정으로 기존 IRE 개발을 종료하고 SRT 원본에서 시작하는 신규 경량 엔진 개발로 전환한다. 이 저장소의 main은 신규 개발의 유일한 기준이다. 이전 엔진과 연구 결과는 별도 보존 브랜치에 동결되어 있으며 신규 연구에는 사용하지 않는다.

**목표:** ChatGPT가 791편 투자 영상의 원본을 연구하고, 최신 공식 금융 근거와 대조하여 최종 검증하며, 새로 얻은 지식을 누적해 투자 질문에 활용할 수 있는 시스템. 외부 LLM API 없이 현재 채팅과 연결된 도구만 사용한다. 포트폴리오 연결은 연구 엔진 완성 후 실시한다.

현재 D0·D1 PASS (저장소 전환 및 최소 기능 구현·기술 시험 완료), D2 진행 중 (첫 영상 1턴 연구 초안 저장 완료, 2턴 최종 검증 대기). 신규 엔진은 `engine.py`로 구현했다. 신규 투자 지식 및 신규 연구 완료 영상은 여전히 0이다. 실제 원문 173개 검토와 의미 항목 30개 초안을 비공개 연구 원장에 저장했다. 과거 진행률은 계승하지 않는다. D1 시험 입력의 금융 의미는 검증하지 않았다.

**원본 업로드 범위:** 사용자 확인 기준 현재 약 1~300번 SRT가 업로드되어 있다. 791편은 최종 연구 대상이며 전체 업로드가 완료된 상태가 아니다. 개별 파일 접근·누락 여부는 별도 확인한다. D0에서 직접 확보한 SRT는 시범용 3편이다.
