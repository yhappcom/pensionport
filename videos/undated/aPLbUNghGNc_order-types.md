## Analysis
An investment idea can still be executed badly if the investor does not understand order mechanics. The video therefore treats price/time priority and order type as execution-risk controls. A market order prioritizes execution over price control; a limit order prioritizes price control but can remain unfilled.

This deepens the execution layer introduced in video 30. It does not conflict with long-term investing: order literacy reduces avoidable implementation errors.
