## 확인된 구조
공식 목차는 모든 것을 의심하라 → 내러티브 투자 → 투자의 시작과 성공 → 가장 큰 리스크 → 초보자의 분산투자 → 투자비중 판단 도구 → 올바른 반응의 99%는 무반응 → 안전하게 투자근육 키우기 → 세상 공부 → 한국 증시 구조변화 → 콘텐츠 필터링 순이다. 출판사의 경제적 지원을 받은 콘텐츠다.

## 핵심 분석
투자공부의 목적을 '더 많은 정보를 소비해 더 자주 거래하는 것'이 아니라 가설을 의심하고, 위험을 분산하고, 포지션 크기를 통제하며, 불필요한 반응을 줄이는 의사결정 역량으로 본다. 특히 '올바른 반응의 99%는 무반응'이라는 장은 뉴스·가격변화에 대한 과잉행동을 경계하는 행동원칙을 명시한다.

## 실행 프레임
정보/내러티브 수집 → 반대근거 확인 → 포트폴리오 내 비중결정 → 분산 → 실제 소액투자 → 관찰/복기 → 필요할 때만 행동으로 이어진다. 초보자는 종목 확신보다 포지션 크기와 분산을 통해 실패비용을 관리해야 한다.

## 위험
내러티브는 미래를 이해하는 도구가 될 수 있지만 이야기의 설득력과 투자수익은 동일하지 않다. 책/인터뷰 콘텐츠이므로 출연자의 주장과 박곰희TV의 누적 원칙을 분리한다. 구체적인 '비중 판단 도구' 공식은 전체 원문이 없어 추정하지 않는다.

## 프레임워크
학습 → 의심/반증 → 위험예산 → 분산/비중 → 실행 → 무반응 규율 → 복기의 decision-quality loop를 강화한다.
