# 관계 정책 후보 — 의무 기반 질문별 검증 (SHADOW)

운영 원장과 승인 관문은 그대로 둔다. 300개 기존 판정은 감사용으로 모두 보존한다. 기존의 보완 관계와 의존성을 직접 연결로 유지하고, 신규 미검토 쌍은 UNREVIEWED로 표현한다. DISTINCT를 자동 추론하지 않는다.

## 단계
1. 원본/공식 근거를 검증한 직접 명제의 승인과 복합 질문의 적용 검증을 분리한다. 이 프로토타입은 직접 명제 신규 승인 구현이 아니라 기존 승인 스냅샷의 질문 검증 경로이다.
2. ChatGPT가 질문 유형 및 적용 범위를 판단한다. 고정 프로필의 의무(기한, 세액, 현금, 계좌, 상품, 위험, 비용 등)와 의존 카드 전체를 조회한다. 미등록 유형, 만료, 미승인 카드, 알려진 충돌/미해결 동치는 HOLD.
3. 중요한 교차 관계의 상태를 조회하고, 미검토 관계는 질문 한정 추가 의미 검토를 요구한다. 기존 관계도 해당 질문 적용을 다시 검토한다. 미검토를 무관으로 치환하지 않는다.
4. 질문 원문, 날짜, 유형, 실제 Git 스냅샷, 출처와 카드 버전, 전체 의무 및 관계 검토, 답변 전문을 한 검토 영수증에 묶는다. 누락·불일치·확정 거래는 차단한다. 의미 판정은 ChatGPT의 책임이며 구조 검사만으로 진위 인증 불가.

## 한계
- 현재는 실제 25개 원장의 읽기 전용 투영. 기존 전수 관계 요구를 제거한 새 발행 엔진은 미구현. 프로필 누락·잘못된 유형 선택·새 충돌 탐지의 의미 정확도는 별도 실증 필요.
- 신뢰된 검토자 및 Git 스냅샷 가정. 전자서명/외부 독립 인증이 아니다. 질문별 영수증이 전역 승인이나 개인 거래 승인이 되지 않는다.
- 신규 주제에서 기존 전수 비교와 대조하고 비용을 계측하기 전 운영 변경 금지.
