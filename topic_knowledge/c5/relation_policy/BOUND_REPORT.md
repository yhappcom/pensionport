# T005 입력 결속 및 혼합 질문 범위 보완

2026-11-28 / 고정 실험 범위 구조 PASS / C5 확장성 및 C6 HOLD. 기존 운영 25카드·300관계, 실험 29카드·308관계 보존.

## 실행 결과
- 승인 계획과 실제 Git 파일 7개를 SHA-1 Git blob framing(UTF-8 byte length, blob header)으로 재계산. 별도 실행 코드 두 파일 해시 확인. 승인 commit/path 메타데이터와 기대 blob을 확인하고 원문 문자열에서 파싱·실행. 같은 pin의 변조, 변조 후 새 해시, 잘못된 위치, 프로필/관계/원장 변조 차단. 승인 anchor 자체의 신뢰는 별도 전제.
- 고정 4문항/10기준 내부 평가: 조건부2/HOLD2. 구조 검사 29/29(기존 회귀 27/27 포함 검사 1개). 혼합 질문은 두 프로필 합집합을 강제하며 오분류·의무/관계 누락 차단. 미등록 질문은 HOLD. 자연어 분류 일반화 검증 아님.
- 질문당 선택12카드, 신규 관련 미검토30쌍과 기존 지정2쌍을 검토. 두 질문 총64개 관계 검토기록, 미검토 관계 확인60회(고유30쌍); 전역 승인 없음. 기존 106쌍 사전 검토와 비교할 때 비용이 질문 시점으로 이동. 실제 의미 시간/비용 절감 미입증.
- 첫 파일 결속 178ms, 네 질문 재실행 188/215/187/188ms. 기술 실행 구간만 측정. 의미 평가 동일 ChatGPT, 독립 인증 아님.

## 잔여 한계
- 원본 hash는 신뢰된 Git 승인 anchor의 일치 검증이며 독립 서명이나 금융 진위 인증 아님.
- 기존 저수준 admit API는 변경하지 않음; 새 검증 runner 경로에서만 변조 차단. 승인 anchor/runner 자체는 신뢰된 host가 고정해야 함.
- 고정 4문항 범위만 분류 누락 차단. 신규 자연어 분류 및 의미적 허위 검토 자동 판정은 미해결.
- 전체 선택된 신규 미검토 관계는 열거하나 선택 바깥 관련성·누락의 완전성은 미입증.
- 전체 의미 연구시간·금전비용·Node CI 미측정. 기존 운영 원장 및 엔진 불변.
- 허위 의미 검토 기록과 답변을 함께 작성하면 여전히 통과하는 실제 반례. 이 결함을 구조 시험의 PASS로 해석하지 않는다. 승인 검토의 진실성은 ChatGPT의 의미 책임이며, 코드만으로 보장 불가.

## 의사결정 권고
추가 엔진 보완을 반복하기보다 현재 연구 성과(운영25, 실험4)를 보존하고, C5의 전체쌍 의무를 유지할지 또는 직접 명제의 독립 승인과 질문별 의미 검토를 분리한 제한 운영 정책으로 전환할지 명시적 정책 결정을 요청한다. 후자의 경우 모든 신규 주제의 전역 관계 완전성 인증을 주장하지 않으며, 실제 자문마다 최신 공식 근거·필수 적용조건·충돌 및 미확정 범위를 ChatGPT가 직접 검토한다. C6 대량 확대 및 개인 포트폴리오 연결은 아직 시작하지 않는다. 전체 의미 비용을 새 연구에서 기록하되 과거 미계측치를 추정하지 않는다.
