## C6 제한 운영 순서
1. 기존 299편 고유 SRT만 검색 대상으로 사용(791편 전체 확보 주장 금지). 새 주제 T006(분배금·배당 투자와 총수익/현금흐름)부터 시작. 기존 T003-06 등과 중복 규칙을 새로 발행하지 않고 신규 직접 명제만 승인한다. 신규 공식 근거를 검색한다.
2. 주제별 사전 범위/필수 조건 등록, 원문 및 금융 근거 확인, 직접 의존·동치·충돌 후보 검토, 별도 의미 승인, Git 원문 해시 결속, 승인 목록 갱신, 실제 조회/조건부 자문 및 비용 기록. 미확정 핵심 항목 HOLD. 새 질문은 ChatGPT가 관련 주제 및 적용조건을 직접 판단하고 의미 검증한다.
3. 전체 연구시간은 앞으로 신규 주제에 대해 가능한 실제 시작/종료 또는 도구 시간과 의미 검토 분리 여부를 기록한다. 수치가 확보되지 않으면 미측정으로 남긴다. 총량·독립 정확도·자동 분류·포트폴리오 미실증을 소급 인증하지 않는다.
