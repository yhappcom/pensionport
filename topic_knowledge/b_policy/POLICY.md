# B안 — 직접 명제 승인 및 질문별 적용 검증 운영정책

2026-11-28 / 사용자 직전 B안 권고에 대한 진행 지시를 제한 운영 전환 승인으로 해석. C안의 주제 중심 목표를 유지하며 관계 완전성 요건만 변경한다. 기존 A안 전수 검토 결과 및 HOLD 이력은 역사 기록으로 보존한다. F/D 구 엔진 및 기존 25카드 원장·코드는 변경하지 않는다.

## 승인 정책
- 사전 연구 질문, SRT 원본 해시/위치/문맥, 최신 공식 근거, 조건·예외·시점, 수치·단위 및 반례를 확인한 직접 명제만 승인한다. 중요 미확정 항목은 HOLD, 범위 밖/개별 거래 미확정은 명시하여 승인 범위를 제한한다.
- 기존 명제와 직접 동치·충돌 후보 및 의존 지식을 실제로 비교한다. 동치는 기존 지식으로 연결, 미해결 충돌은 해당 명제 HOLD. 모든 지식 쌍의 관계를 강제하지 않는다. 미기록 관계는 UNREVIEWED이며 DISTINCT 또는 무관으로 간주하지 않는다. 이미 알려진 충돌/동치가 누락되거나 덮어쓰이지 않도록 원장과 자료를 검토한다.
- 별도 검토 및 ChatGPT 승인 근거가 있는 원본을 Git commit/path/blob으로 고정한다. 신뢰된 호스트가 승인 목록을 고정하고 UTF-8 Git blob 해시 재계산 후 직접 파싱·조회한다. 승인 목록에 없는 연구/실험 자료는 운영 조회 불가. 파일 해시는 의미의 진실성을 인증하지 않는다.
- 신규 운영 목록은 기존 전수 원장을 읽기 전용으로 계승하고 B안 승인 기록을 추가한다. 기존 승인 25개와 300관계 보존. T005는 별도 명시 승인 기록과 실제 조회 검증 후에만 운영 활성. 2026-12-31까지 기존 유효기간 유지, 이후 재검증.

## 실제 자문
1. ChatGPT가 질문에서 목적, 기간, 손실·유동성, 상품, 계좌, 세금, 비용·거래, 기타 관련 판단 조건을 직접 식별하고 필요한 지식 주제를 조회한다. 미등록 자연어를 자동 분류하지 않는다. 질문과 무관한 조건은 이유를 기록하고 중요 조건이 미확정이면 HOLD 또는 제한 조건부 답변.
2. 관련 직접 명제 및 모든 필수 의존성, 최신 공식 근거와 관련 예외·실제 계좌/상품 제한 확인. 질문에 중요한 미검토 관계와 알려진 충돌 검토. 지식의 조회 가능성은 실제 자문 승인과 별개. 미검토 관계를 승인 사실로 표현하지 않는다.
3. 질문·적용 범위·사용 카드/출처·계산·미확정 사항·답변을 별도 기록하고 ChatGPT가 최종 의미 검토. 허위 의미 기록을 구조 검사만으로 탐지할 수 없음을 명시. 개인 정보 부족 시 조건부 일반 교육용. 실제 거래 확정 금지.

## C5/C6 기준
C5의 전역 관계 완전성 및 전체쌍 확장성 인증은 역사적 HOLD 유지, 운영의 선행조건에서 분리한다. B안은 제한 내부 운영 검증만 별도 판정. 운영 원장 실제 29개 조회·차단 검증이 완료되면 C6 제한적 순차 연구를 개시할 수 있다. 대량 자동 처리 및 독립 정확도 인증, 전체 의미 연구 비용은 별도 미입증. C6는 주제마다 실제 원문/공식 근거/승인/조회/조건부 자문/처리량을 기록하며 결함 발생 시 해당 주제 HOLD. C7 포트폴리오 연결은 C6 운영 평가 이후 별도 승인. 외부 LLM API 없이 채팅에서 수행.
