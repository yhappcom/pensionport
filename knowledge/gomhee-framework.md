## 현재 핵심 구조

### 1. 행동
`루머 배제 → 장기 관점 → 분산 → 과잉매매 억제 → 규칙 준수`

### 2. 학습
`소액 실전 → 상품 구조 이해 → 장점/리스크 비교 → 큰 금액은 이후`

### 3. 자산군
`주식 외 REITs·금·채권 학습 → 서로 다른 위험원천을 분리`

### 4. 구현수단
`자산군 목적 → ETF/펀드/직접투자 → 상장시장 → 통화 → 현물/선물 → 분배정책 → 비용·세금`

ETF 관련 영상이 누적되면서 구현수단 레이어가 크게 구체화됐다.

### 5. 계좌
`연금저축 → IRP 보완 → ISA 추가 → 계좌별 목적·유동성·세제구조 분리`

### 6. 포트폴리오
`자산군 선택 → 목표 비율 → 구현상품 선택 → 리밸런싱 → 장기 유지`

### 7. 복잡한 상품
`기초자산 → 손익조건 → 만기/유동성 → 발행사/구조 → 이해 가능한 경우에만 편입`

ELS와 선물형 ETF가 이 원칙을 강화한다.

## ETF에 대해 새로 강화된 원칙

### 국내상장 vs 해외상장
같은 지수를 추종해도 통화·세금·거래시간·계좌호환성이 다르다. 어느 시장이 절대적으로 우월하다는 식으로 보지 않는다.

### 선물형
ETF 안에 선물계약이 있으면 만기와 롤오버를 이해해야 한다. ETF 형식 자체가 위험을 단순화하지 않는다.

### TR/분배정책
배당 재투자는 총수익률과 복리에 중요하지만 과세이연은 면세가 아니다.
더 중요하게, 2025년 세법 변경처럼 **제도변경이 ETF의 분배정책 자체를 바꿀 수 있다.**

## 현재 연금·계좌 프레임
`연금저축 → IRP → ISA → 각 계좌 안 자산배분/ETF 구현 → 장기 유지`

아직 국민연금, 은퇴 인출률, 건강보험료까지 통합된 완성형 연금 프레임은 아니다.

## 해석상 주의
- ETF = 자동으로 안전한 상품이 아니다.
- 선물 ETF = 현물 ETF와 동일하지 않다.
- TR = 2020 영상의 구조가 2026에도 그대로 유지된다고 가정하지 않는다.
- ISA/연금 계좌에서는 매수 가능한 ETF 범위가 일반계좌와 다르다.
- 오래된 세금·보수·상품명은 현재 규정과 투자설명서로 재검증한다.
