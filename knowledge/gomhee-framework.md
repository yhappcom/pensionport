## 전체 의사결정 구조
`현금흐름/계좌 인프라 → 행동규율 → 목표/기간/소유주체 → 계좌·세제/고용제도 선택 → 자산군/통화 선택 → 목표비율 → 구현상품 → 상품구조·지수/벤치마크·신용·비용·세금·환전 검증 → 주문/체결/기준가격/환매 → 리밸런싱 → 장기 유지 → 인출/이전`

## 1. 행동
`루머 배제 → 장기 관점 → 분산 → 과잉매매 억제 → 규칙 준수`

## 2. 학습
`소액 실전 → 상품 구조 이해 → 장점/리스크 비교 → 큰 금액은 이후`

## 3. 계좌
`연금저축 → IRP 보완 → ISA를 별도 목적의 절세 버킷으로 구분`
계좌와 그 안의 투자상품을 동일시하지 않는다.

## 4. 자산배분
`자산군 선택 → 목표 비율 → 구현상품 → 리밸런싱`
종목 수보다 서로 다른 위험원천의 조합을 중시한다.

## 5. 구현수단
`ETF/펀드/직접투자 → 상장시장 → 통화 → 현물/선물 → 분배정책 → 비용·세금`

ETF라는 형식 자체를 자산군이나 안전성으로 해석하지 않는다.

## 6. 복잡한 상품
`기초자산 → 손익조건 → 만기/유동성 → 발행사/파생구조 → 이해 가능한 경우에만 판단`
ELS와 선물 ETF가 이 원칙을 강화한다.

## 7. 시간의존 정보
증권사 이벤트·금리·수수료, 세율·한도, 상품명·분배정책은 영구 원칙이 아니다. 과거 설명은 역사정보로 보존하고 현재 판단에는 최신 공식자료를 적용한다.

## 연금·노후 프레임
현재 canonical 139편 기준:
`연금저축 → IRP → ISA(별도 목적) → 계좌 안 자산배분/ETF 구현 → 장기 유지`

국민연금은 knowledge에서 노후현금흐름의 기초층으로 분석 중이나 초기 영상의 시간축 검증이 남아 있다. 은퇴 후 체계적 인출전략은 아직 충분한 근거가 축적되지 않았다.

## 중요한 예외
- 안전자산 = 무위험이 아니다.
- ETF = 자동으로 분산·안전해지는 상품이 아니다.
- 선물 ETF = 현물 ETF와 동일하지 않다.
- TR의 과거 과세이연·분배구조가 현재 그대로 유지된다고 가정하지 않는다.
- ISA/연금계좌는 일반계좌와 투자 가능 범위·세제가 다를 수 있다.
- 오래된 세금·보수·금리·이벤트는 현행 공식자료로 재검증한다.
- 원문이 없는 영상의 세부 발언·수치는 추측하지 않는다.

## chronology 운영
현재 확인 가능한 큐에서 계속 전진한다. 나중에 더 오래된 영상이 발견되면 chronology repair로 보정하며, 미발견 영상의 부재를 입증하기 위해 작업을 중단하지 않는다.

## 21~23편에서 추가된 지식
- TDF: 연금계좌 안에서 생애주기형 자산배분·리밸런싱 일부를 위임하는 구현수단. 편의성과 원금안전은 구분한다.
- 발행어음: 현금관리도 금리뿐 아니라 발행기관 신용·상품구조·유동성·보호장치를 함께 본다.
- CMA 투자일기: 투자상품 선택보다 앞서 현금흐름과 중심계좌/연결계좌 구조를 설계한다.
- 세 영상의 게시일은 아직 미확정이며 처리 순서는 provisional이다. 날짜 확보 시 chronology repair만 수행하고 분석은 유지한다.

## 24~25편에서 추가된 지식
- 세금: 과거의 세제개편 예정안과 실제 시행법을 분리한다. 세금은 상품·계좌 선택을 바꿀 수 있는 독립 검증 레이어다.
- 은: 금과 같은 귀금속이라는 이유로 동일한 위험구조로 보지 않는다. 원자재도 포트폴리오 역할을 먼저 정하고 실물·ETF·선물 등 구현수단을 비교한다.
- 두 영상의 정확 게시일은 미확정이며 provisional 처리다.

## 26~28편에서 추가된 지식
- 멀티에셋 ETF: 목표 자산배분을 여러 상품으로 직접 구현하는 방법과 하나의 자산배분 ETF에 위임하는 방법을 구분한다. TDF와도 자동화 목적·배분규칙의 차이를 확인한다.
- 고배당 ETF: 배당률만 비교하지 않고 직접주식/ETF 선택, 분산, 비용, 세금, 총수익을 함께 평가한다.
- 채권 실습: 신용등급·표면금리·만기를 실제 상품 선택 체크리스트로 사용하며, '안전자산'이라는 이름만으로 판단하지 않는다.
- 세 영상은 정확 게시일 미확정 상태로 provisional 처리했으며 날짜 확보 시 chronology repair한다.

## 29~30편에서 추가된 지식
- 주식투자 준비: 계좌·투자자금·시장 기초·정보원·행동규율을 실제 투자 이전 준비단계로 묶는다.
- 시장 실행: 주문 → 체결 → 결제 → 잔고 확인을 투자 실행 리스크 관리에 포함한다.
- 과거 거래시간·비용·시장제도 수치는 현재 공식 규칙으로 재검증한다.

## 30편 체크포인트
전체 구조는 `현금흐름/계좌 인프라 → 행동규율 → 목표/기간 → 계좌 선택 → 자산군 → 목표비율 → 구현상품 → 구조·비용·세금 검증 → 주문·체결·결제 → 리밸런싱 → 장기 유지`로 확장됐다. 국민연금 원본 ID와 체계적 은퇴 인출전략은 아직 검증 과제로 남는다.

## 31~40편 체크포인트
- 시장 실행: 주문유형·체결·결제뿐 아니라 해외시장에서는 통화·환전·해외세금까지 실행 레이어가 확장된다.
- 퇴직연금: DB/DC/IRP를 개인연금과 구분되는 노후소득 층위로 편입한다.
- 연금저축: 가입·세액공제에서 계좌이전·장기운용·수령·잔여자산 관리까지 생애주기 전체로 확장한다.
- 소득 없는 가입자 사례를 통해 가입자격과 세액공제 실익을 분리한다.
- 2026 국세청 기준 연금저축 세액공제 대상 납입한도 600만원, 퇴직연금 포함 900만원을 현재 기준값으로 사용하고 과거 400/700만원은 역사정보로만 유지한다.
- 인출이 독립 단계로 등장했으나 정량적 은퇴 인출률 전략은 아직 미완성이다.

## 41~42편 누적 반영
- 테마 ETF: ETF 안에서도 특정 산업·테마에 집중될 수 있으므로 ETF 형식과 실질적 분산을 분리한다.
- ETF Q&A: ETF는 자산배분을 구현하는 도구이며, 시장의 절대 지수 수준보다 목표·기간·배분규칙을 먼저 본다는 기존 행동원칙을 강화한다.
- 구현 검증 레이어를 `기초자산 → 추종지수 → 구성종목/집중도 → 구조 → 비용·세금 → 계좌 적합성`으로 세분화한다.
- 2021년 당시 테마 상품·구성·보수 등은 역사정보이며 현재 선택에는 최신 공시가 필요하다.

## 43~45편 누적 반영

- 2021 ISA 리뉴얼은 ISA를 세제 래퍼로 보는 기존 원칙을 강화하면서 손익통산·자산배분 자유도·이전·중도인출을 실제 운용 레이어로 추가한다.
- 연금저축·IRP·ISA는 절세라는 공통점보다 목적·유동성·투자가능범위의 차이를 먼저 본다.
- 과거 제도 설명과 이후 정부의 개편 추진안, 실제 시행 규정을 서로 구분한다.

## 46편 누적 반영
- 중개형 ISA 출시기의 증권사 비교를 통해 `계좌 제도 선택`과 `판매사 실행조건 선택`을 분리한다.
- 세제·손익통산·유동성·투자가능범위는 계좌 레이어, 수수료·앱·이벤트는 실행 인프라 레이어로 관리한다.


## 47~50편 및 50편 체크포인트
- 증권사 이벤트·수수료·환전우대는 투자전략과 분리된 실행조건이며 역사값은 현재값으로 재사용하지 않는다.
- 달러는 자산배분의 통화 노출로 명시한다. `통화 역할 → 구현수단(현금/예금/ETF/RP/발행어음) → 환전비용·금리·신용위험` 순으로 본다.
- 개별주식은 코어 자산배분을 대체하지 않으며 선택 시 사업모델·반복매출·경쟁우위·성장동력·경쟁사·재무·실패경험을 점검한다.
- 자녀계좌/증여는 `소유주체 → 증여시점·누계 → 세금/신고 → 계좌 → 투자기간·유동성 → 상품` 순으로 설계한다.
- 전체 구조를 `현금흐름/계좌 인프라 → 행동규율 → 목표/기간/소유주체 → 계좌·세제 선택 → 자산군/통화 → 목표비율 → 구현상품 → 구조·비용·세금·환전 → 주문·체결 → 리밸런싱 → 장기 유지 → 인출/이전`으로 확장한다.


## 51~60편 체크포인트
- 펀드는 이름·최근수익률보다 투자대상·운용방식·벤치마크·위험·비용·기준가격·환매조건을 먼저 본다.
- ETF는 형식이 아니라 기초자산·지수방법론·집중도·파생구조·환노출·추적·비용을 확인한다.
- 채권은 '안전자산'이라는 명칭 대신 발행자·신용·만기·가격·수익률·금리민감도·유동성 위험을 분해한다.
- 정기 신규자금은 시장예측보다 목표비중의 부족 자산을 보충하는 cash-flow rebalancing에 활용할 수 있다.
- 퇴직연금은 고용/제도유형 → DB/DC/IRP → 운용책임/투자통제권 → 투자규제 → 자산배분 → 수령전략 순으로 본다.
- 개별기업 분석은 `주식 권리구조 → 현재 cash engine → 성장 플랫폼 → 미래 option → 자본배분 → 규제/윤리 → 밸류에이션`의 하위 프레임을 사용한다.
- 미래기술·과거 프로젝트는 현재 기업가치의 확정근거로 사용하지 않으며, 현재 현금창출력과 옵션가치를 분리한다.
- canonical 저장 실패와 콘텐츠 분석을 분리한다. source가 막힌 영상은 verification_needed로 건너뛰고, 분석 완료 문서는 pending_sync로 관리한다.


## 61편 누적 반영
- 연금저축의 실행 완료 기준을 '계좌 개설·납입'에서 '계좌 내부 실제 운용'까지 확장한다.
- 세액공제와 투자수익은 분리한다. 세액공제 대상 납입을 했더라도 자금이 현금으로 남아 있으면 투자 단계는 완료되지 않은 것이다.
- 투자 숙련도에 맞춘 구현수단 사다리를 추가한다: `유휴현금 확인 → MMF 임시 대기 → TDF 위임형 자산배분 → ETF 자기주도 자산배분`.
- MMF/TDF/ETF는 우열이 고정된 상품군이 아니라 운용 목적·숙련도·관리책임이 다른 구현수단이다.
- 연금저축 하위 프레임을 `계좌 개설 → 납입/세액공제 → 유휴현금 확인 → 구현수단 선택 → 구조·비용 검증 → 장기 유지·리밸런싱 → 인출`로 확장한다.
- 현재 세액공제 한도와 법정 공제율은 현행 소득세법으로 재검증하되 상품별 비용은 TIME_SENSITIVE로 별도 확인한다.

## 62편 누적 반영
- 통화 투자의 첫 단계에 **사용목적과 투자목적의 구분**을 추가한다.
- '엔화가 싸다' 같은 가격수준 판단을 매수근거로 단순화하지 않고 `목적 → 규모·기간 → 구현수단 → 환전비용·상품구조 → 포트폴리오 역할` 순으로 판단한다.
- 달러에서 축적된 통화 노출 프레임을 엔화로 확장하되, 직접 엔화 보유·통화 ETF·일본 주가지수·개별주식은 서로 다른 노출로 취급한다.
- 환율과 금융기관 환전수수료는 TIME_SENSITIVE이므로 영상 당시 수치를 현재값으로 재사용하지 않는다.

## 63편 누적 반영
- CMA를 단순 수익률 상품이 아니라 급여·생활비·투자대기자금과 여러 투자계좌를 연결하는 cash-management hub로 명시한다.
- 현금관리 하위 프레임을 `현금 목적/기간 → CMA 운용구조·보호 → 자동화 → 투자계좌 분배 → 자산배분`으로 강화한다.
- 영상 당시 금리·취급조건은 TIME_SENSITIVE 역사정보로 분리한다.

## 64편 누적 반영
- 목돈 투자에서도 `목표·기간·비상자금 분리 → 자산배분 → 진입규칙 → 포트폴리오 점검` 순서를 적용한다.
- 개별 종목의 성공경험을 전체 포트폴리오 원칙으로 일반화하지 않고 집중위험을 별도로 본다.
- 상세 transcript 미회수 영상이므로 확인 가능한 공개 메타데이터 범위를 넘어 세부 비중·발언을 추정하지 않는다.

## 65편 누적 반영
- 퇴직금은 일시금 투자자금이 아니라 은퇴 현금흐름 자산으로 분류한다.
- 은퇴 직전·직후 의사결정 순서를 `퇴직자산 총액 → 단기 생활비/비상자금 → 퇴직급여 세제·이전 → 연금계좌 역할 → 인출기간 → 자산배분`으로 확장한다.
- 적립기에는 장기 기대수익률과 자산배분이 중심이지만, 은퇴 전환기에는 유동성·세제·인출순서가 선행한다.
- 퇴직연금·IRP 관련 한도·세율·수령 규정은 TIME_SENSITIVE로 취급하고 현행 공식규정으로 재검증한다.

## 66편 누적 반영
- ISA를 단순 보유·운용 계좌가 아니라 **개설 → 운용 → 만기 → 세금정산 → 연금전환/재가입**으로 이어지는 lifecycle wrapper로 확장한다.
- ISA의 세제효과는 계좌 보유 여부만이 아니라 어떤 소득원을 ISA에 배치했는지까지 포함해 판단한다.
- ISA 만기자금의 연금계좌 전환은 ISA의 출구와 연금계좌의 입구를 연결한다.
- 현행 공식규정상 ISA 만기 전환금액의 10%, 최대 300만원 추가 세액공제 한도는 TIME_SENSITIVE 규정으로 관리한다.

## 67편 누적 반영
- ISA의 절세효과를 계좌명만으로 판단하지 않고 `기초자산 소득원천 → 외국 원천세 → 국내 과세 → ISA 비과세/분리과세 → 과세이연 → 실효세후수익`으로 세분화한다.
- 펀드 외국납부세액 조정 방식은 2025년 귀속부터 제도 변경이 있었으므로 TIME_SENSITIVE로 관리한다.

## 68편 누적 반영
- 월배당 포트폴리오는 높은 분배율 자체가 아니라 목표 현금흐름·분배원천·집중위험·총수익·세금·실제 수령액을 기록하는 feedback loop로 관리한다.
- 커버드콜·고배당·리츠/인프라 등은 분배원천과 가격상승 참여구조가 다르므로 분배율 하나로 비교하지 않는다.

## 69편 누적 반영
- 서킷브레이커 같은 시장안정장치와 장기 투자자의 의사결정을 분리한다.
- 급락 발생 자체를 방향예측 신호로 쓰지 않고 `시장충격 → 안정장치 → 심리반응 → 위험예산 → 사전 리밸런싱 규칙`으로 대응한다.

## 70편 누적 반영 및 체크포인트
- 달러는 단순 환율 베팅이 아니라 위기대응·통화분산·달러지출·해외투자 대기자금 등 목적을 먼저 정의한다.
- 달러 예금·통화 ETF·RP·발행어음은 수익원·유동성·비용·신용위험·계좌/세금이 다른 구현수단이다.
- 61~70편 구간에서 전체 프레임은 **계좌 lifecycle, tax-location, 은퇴 현금흐름, 분배금 feedback, 시장충격 행동규율, 통화 구현수단**까지 확장됐다.
- 다음 정식 종합은 80편이다.


## 71~76편 누적 반영
- 71편은 월급 규모별 현실적 현금흐름 설계를 통해 `상품선택 이전에 생활비/저축·투자 구조를 먼저 만든다`는 cash-flow-first 원칙을 강화한다.
- 72편은 투자 복잡성을 낮추는 것을 마켓타이밍·과잉판단을 줄이는 행동 리스크 관리 수단으로 보고, 자립자금의 목적을 소비보다 선택권 확대로 연결한다.
- 73편은 소득별 예산 사례에서 생활비/저축·투자 → 연금저축/ISA → 자산배분 순서를 강화하고, 근로소득 성장과 자본소득 성장을 병행 축으로 추가한다.
- 74편은 초보 학습 순서를 `자산배분 → 준비 → 투자방법 → 소득별 계획 → 기록/점검`으로 정리한다. 과거 재구성 영상의 숫자는 현재값으로 재사용하지 않는다.
- 75~76편은 ISA·연금저축·IRP 배분을 고정 납입순서가 아니라 `월 투자 가능액 + 유동성 + 생애 이벤트 + 세액공제 실익`의 함수로 확장한다.
- ISA 만기→연금 전환 등 시간의존 숫자는 영상 설명보다 현행 공식 법령·국세청 안내를 우선한다. 역사적 숫자와 현재 규칙이 충돌하면 CONFLICT_NUMERIC으로 보존하고 현재값으로 승격하지 않는다.
- chronology가 불명확해도 콘텐츠 분석을 멈추지 않는다. effective canonical과 전체 exact-ID inventory를 대조해 미처리 source-backed 영상을 선택한다.

## 77편 누적 반영
- 연금저축을 단순 세액공제 계좌가 아니라 **장기 현금흐름을 축적하는 시스템**으로 확장한다.
- 장기계좌의 유동성 제약은 비용인 동시에 단기 가격변동에 대한 과잉개입을 줄일 수 있는 행동 통제 장치다.
- 장기 수익률·복리 시뮬레이션은 가정과 교육도구로 보존하며 기대수익 또는 보장수익으로 승격하지 않는다.
- 현행 연금 세액공제 및 사적연금 과세 기준은 영상의 역사적 수치보다 최신 법령·국세청 자료를 우선한다.

다음 정식 종합 체크포인트는 80편이다.

## 78~139 backlog compaction 통합 결과
- 연금: 납입한도와 세액공제 한도를 분리하고, 공제/비공제 원금의 tax basis, 연금저축·IRP 기능차이, 연금수령·잔여자산 운용까지 축적기와 인출기를 하나의 lifecycle로 연결했다.
- 은퇴: 국민연금·직역연금·퇴직연금·개인연금을 노후현금흐름의 여러 층으로 보고, 목표지출·공적연금·부족분·인출률·sequence risk를 함께 본다.
- 현금흐름: 월급 규모와 관계없이 상품선택보다 생활비·비상금·저축가능액·CMA·절세계좌 배치가 선행한다.
- 자산배분: 마켓타이밍보다 risk budget, 목표비중, 리밸런싱, 생애주기와 인출시점에 따른 위험자산 조절을 강화했다.
- ETF/테마: ETF 형식보다 지수·구성종목·집중도·비용·밸류에이션·생애주기 적합성을 확인한다.
- 기업/시장구조: DART 공시, 기업 자본조달, 주문·체결원칙, 서킷브레이커, 액면분할, 주식 권리구조 등 시장기초를 실행 프레임에 편입했다.
- 행동: 매수가 앵커, 성과추종, 과잉정보 소비, 늦었다는 불안에 따른 과도한 위험추구를 경계하고 기록·분산·무반응 규율을 강화했다.
- canonical sequence 78~139의 상세 claim/framework delta는 `knowledge/backlog-compaction-078-139.md`에 보존한다.
