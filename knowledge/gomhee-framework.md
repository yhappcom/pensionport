## 현재 핵심 구조

### 1. 행동
`루머 배제 → 장기 관점 → 분산 → 과잉매매 억제 → 규칙 준수`

### 2. 학습
`소액 실전 → 상품 구조 이해 → 장점/리스크 비교 → 큰 금액은 이후`

### 3. 자산군
`주식 외 REITs·금·채권 학습 → 서로 다른 위험원천을 분리`

### 4. 구현수단
`자산군 목적 설정 → ETF/펀드/직접투자 비교 → 비용·유동성·제약 확인`

### 5. 계좌
`연금저축 → IRP 보완 → 장기 납입 → 과세이연/세액공제 → 중도해지 억제`

### 6. 포트폴리오
13번째 영상까지 반영하면 `자산군 선택 → 목표 비율 → 리밸런싱 → 장기 유지`로 확장된다.

## 새롭게 강화된 핵심

### 리츠
부동산 자산군을 소액 금융상품으로 접근할 수 있지만 시장가격과 부동산 경기 위험은 남는다.

### 채권
'안전자산'을 무위험으로 보지 않는다. 수익률·신용도·만기를 함께 보고, 금리 변화와 중도매도 위험을 이해한다.

### ETF
ETF는 자산군 그 자체가 아니라 주식·채권·원자재 등의 노출을 구현하는 형식이라는 점이 더욱 명확해졌다.

## 현재 연금 프레임

`연금저축 개설 → 규칙적 납입 → 장기 운용 → IRP로 세제계좌 확장 → 중도해지 억제 → 은퇴 후 연금화`

아직 ISA, 국민연금, 은퇴 인출률, 건강보험료까지 통합된 완성형 연금 프레임은 아니다.

## 해석상 주의

- 안전자산 = 무위험이 아니다.
- 리츠 = 직접 부동산 보유와 동일하지 않다.
- ETF = 자동으로 분산·안전해지는 상품이 아니다.
- 트레이딩 체험 권유 = 단타 전략 권장이 아니다.
- 특정 자산배분 비율은 교육 사례이며 영구 권장 비율이 아니다.
