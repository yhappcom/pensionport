## 현재 핵심 구조

### 1. 행동
`루머 배제 → 장기 관점 → 분산 → 과잉매매 억제 → 규칙 준수`

### 2. 학습
`소액 실전 → 상품 구조 이해 → 장점/리스크 비교 → 큰 금액은 이후`

### 3. 자산군
`주식 외 REITs·금·채권 학습 → 서로 다른 위험원천을 분리`

### 4. 구현수단
`자산군 목적 설정 → ETF/펀드/직접투자 비교 → 비용·유동성·제약 확인`

### 5. 계좌
`연금저축 → IRP 보완 → ISA 추가 → 계좌별 목적·유동성·세제구조 분리`

ISA 반영으로 계좌 프레임이 노후계좌만의 구조에서 중기 절세 투자계좌까지 확장됐다. ISA는 상품이 아니라 세제 래퍼이며 손익통산까지 포함해 평가한다.

### 6. 포트폴리오
`자산군 선택 → 목표 비율 → 구현상품 선택 → 리밸런싱 → 장기 유지`

### 7. 복잡한 상품
ELS 1·2편 반영으로 `상품명보다 구조` 원칙이 구조화상품까지 확장된다.

`제시수익률 확인 → 기초자산 확인 → 상환조건 확인 → 손실조건 확인 → 발행사/유동성 확인 → 이해 가능한 경우에만 판단`

## 현재 연금·계좌 프레임
`연금저축 개설 → 규칙적 납입 → IRP로 장기 세제계좌 확장 → ISA를 별도 목적의 절세 버킷으로 구분 → 각 계좌 안의 자산배분/상품 선택 → 장기 유지`

아직 국민연금, 은퇴 인출률, 건강보험료까지 통합된 완성형 연금 프레임은 아니다.

## 해석상 주의
- 안전자산 = 무위험이 아니다.
- 리츠 = 직접 부동산 보유와 동일하지 않다.
- ETF = 자동으로 분산·안전해지는 상품이 아니다.
- ISA = 특정 고수익 상품이 아니라 계좌 구조다.
- ELS = 예금 대체재로 단순화할 수 없다.
- 오래된 영상의 세율·한도·가입조건은 현행 제도로 재검증한다.
- 원문 전사가 없는 영상의 세부 수치·사례는 추측하지 않는다.

## chronology 운영
현재 확인 가능한 큐를 기준으로 전진한다. 더 오래된 누락 영상이 나중에 발견되면 chronology repair로 보정하되, 미발견 영상의 부재를 입증하기 위해 처리를 멈추지 않는다.
