## 핵심 구조

### 1. 행동 레이어
`루머 배제 → 장기 관점 → 분산 → 과잉매매 억제 → 규칙 준수`

투자 성과를 시장예측보다 투자자가 통제할 수 있는 행동에서 시작한다.

### 2. 학습 레이어
`소액 실전 → 상품 구조 이해 → 장점/리스크 비교 → 큰 금액은 이후`

처음부터 완벽한 지식을 요구하지 않지만, 큰돈을 넣기 전에 작은 실전으로 학습한다.

### 3. 상품 레이어
`자산군 선택 → 구현상품 비교 → 비용/세금/제약 확인`

금, ETF, 펀드 등은 목적 자체가 아니라 투자 노출을 구현하는 수단이다.

### 4. 계좌 레이어
`연금저축 → IRP 보완 → 장기 납입 → 과세이연/세액공제 → 중도해지 억제`

세제혜택 계좌를 장기자산의 별도 버킷으로 구축한다. 오래된 세법 숫자는 현재 규정과 분리한다.

### 5. 포트폴리오 레이어
`서로 다른 자산군 → 목표 비율 → 리밸런싱 → 장기 유지`

초기 '분산'이 자산배분과 리밸런싱으로 구체화된다.

## 현재 핵심 원칙

1. 예측보다 통제 가능한 변수에 집중한다.
2. 큰돈보다 작은 실전으로 먼저 배운다.
3. 상품명보다 구조·비용·위험을 이해한다.
4. 금융상품은 장점/단점을 대칭적으로 본다.
5. 자산군과 구현수단을 분리한다.
6. 연금저축·IRP 같은 세제계좌를 장기노후자산에 활용한다.
7. 개별 종목 분산을 넘어 자산군 분산을 추구한다.
8. 목표비율이 깨지면 리밸런싱해 규칙을 복원한다.

## 현재 연금 프레임

`연금저축 개설 → 규칙적 납입 → 장기 운용 → IRP로 세제계좌 확장 → 중도해지 억제 → 은퇴 후 연금화`

아직 ISA, 국민연금, 은퇴 인출률, 건강보험료까지 통합된 완성형 연금 프레임은 아니다.

## 해석상 주의

- 트레이딩을 소액 학습경로로 소개한 것을 단타 전략 권장으로 해석하지 않는다.
- ETF를 핵심 도구로 설명해도 ETF 자체를 무위험/만능상품으로 보지 않는다.
- 펀드의 전문가 운용을 자동적 우월성으로 보지 않는다.
- 특정 자산배분 비율은 교육용 사례이며 영구적 모델 포트폴리오가 아니다.
