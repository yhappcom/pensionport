# ELS — 누적 지식

## 상태
초기 박곰희TV ELS 1·2편을 canonical sequence 15·16으로 반영했다.

- 1편: `SGTzm6JgQgU` / 2020-05-23 / 10:33
- 2편: `siC58JGNWh0` / 2020-05-28 / 10:01
- 전체 전사: 미확보 → 세부 역사 수치·사례는 검증필요

## 현재 프레임
ELS는 **조건부 손익구조를 가진 복잡한 파생결합증권**으로 보고 높은 제시수익률만으로 판단하지 않는다.

확인 체크:
- 기초자산
- 조기/만기 상환조건
- 원금손실 발생 조건
- 만기
- 발행사 신용
- 중도환매 조건
- 예금자보호 여부

## 공식 위험검증
금융감독원 전자공시 투자설명서 기준 ELS는 원금손실 가능성이 있고 예금자보호 대상이 아니며, 정해진 조건을 충족하지 못할 경우 약정수익을 얻지 못하거나 상품에 따라 원금손실이 발생할 수 있다.

## 박곰희 프레임과의 연결
ETF·펀드·채권에서 반복된 `상품명보다 구조`, `장점과 위험을 함께`라는 원칙이 복잡한 구조화상품까지 확장된다.

## 프레임워크 반영
- `GOMHEE-C14`: 조건부 수익상품은 표면수익률보다 손익구조와 손실조건을 먼저 이해한다.
- ELS를 예금 대체재로 단순화하지 않는다.
- 이해하기 어려운 구조는 기대수익만으로 편입하지 않는다.
