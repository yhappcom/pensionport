# ELS — 누적 지식

## 상태
초기 박곰희TV ELS 1·2편의 Video ID와 길이는 확보했으나 게시일과 전체 전사는 미확정이다. 아직 canonical 영상 수에는 포함하지 않는다.

- 1편: `SGTzm6JgQgU` / 10:33
- 2편: `siC58JGNWh0` / 10:01

## 현재 프레임
ELS는 **조건부 손익구조를 가진 복잡한 파생결합증권**으로 보고 높은 제시수익률만으로 판단하지 않는다.

확인 체크:
- 기초자산
- 조기/만기 상환조건
- 원금손실 발생 조건
- 만기
- 발행사 신용
- 중도환매 조건
- 예금자보호 여부

## 공식 위험검증
금감원 공시 투자설명서 기준 ELS는 원금손실 가능성이 있고 예금자보호 대상이 아니며, 정해진 조건을 충족하지 못할 경우 약정수익을 얻지 못하거나 손실이 발생할 수 있다.

## 박곰희 프레임과의 연결
ETF·펀드·채권에서 반복된 `상품명보다 구조`, `장점과 위험을 함께`라는 원칙이 ELS에서도 유지되는지 전사 확보 후 확정한다.
