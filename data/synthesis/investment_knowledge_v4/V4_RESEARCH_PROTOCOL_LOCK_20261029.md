# 박곰희TV V4 연구 운영 기준 1.2 — SRT 중심 연구 종결 게이트

기준일: 2026-10-29
적용: #1 연구를 바탕으로 정한 #1~791편 공통 원칙
상태: **SRT_FIRST_PROTOCOL_ACTIVE / VIDEO_001_CLOSED_WITH_SOURCE_LIMITATIONS**

## 연구 목표
영상요약이나 기존 V3 주장의 기계적 재분류가 아니다. 원본을 통독하여 사실·예시·시장가정·의견과 투자 판단 규칙을 분리하고, 공신력 있는 자료로 확인 가능한 규칙에만 재사용 가능성과 적용 조건을 부여한다. 기존 V3, 원본 원장, 원본 ZIP/SRT와 main을 보존한다.

## 모든 영상에서 반드시 수행할 고정 절차
1. **원본 신원과 추적성**: 영상 ID/제목/날짜/원본 SRT SHA256/인덱스·타임코드·기존 V3 주장 ID 일치 확인. 자동자막은 영상 화면/오디오와 구분한다.
2. **원문 전수 범위 감사**: 영상의 모든 1분 단위 시간 구간을 누락 없이 분류, 투자논점 및 명시적으로 제외한 비투자 논점까지 색인. '기존 23개 주장 100% 연결'은 전수 내용 추출을 대체하지 못한다.
3. **원자 주장 분해**: 세법, 연금 제도, 공시, 적립액·수익률·기간, 상품위험, 개인사례, 의견, 가정을 분리. 결합된 주장에는 각각 독립 판단을 기록.
4. **독립자료 검증**: 주무기관·법령·시장 공시·약관 우선. 시행일, 적용 계좌, 소득 원천, 예외, 지역세 포함 여부 명시. 출처 URL만 있는 것은 검증 아님. 서로 다른 공식/상품자료 내용은 OPEN_SOURCE_CONFLICT로 처리.
5. **수치 회귀검사**: 납입원금/평가액/분배금/세액공제 받은 원금/과세제외금액/현금흐름을 별도 장부로 계산. 명목/실질, 월/연 복리, 지급 시점, 인출연차, 세금, 수수료와 위험을 분리. 가정과 보장된 사실 구분.
6. **반례와 적용금지**: '무조건/항상/원금보전/절대/평생' 등의 단정, 연금수급자의 생존·건보료·연금소득세, 상품별 예금자보호·손실·해약조건 확인.
7. **SRT 우선·영상 비필수**: 사용자에게 원본 영상 업로드를 요구하지 않는다. 제공된 SRT를 1차 발화기록으로 삼되 자동자막일 경우 실제 음성 확인과 동일시하지 않는다. 화면·음성은 이미 확보 가능한 경우에만 선택적으로 사용한다. SRT와 독립자료만으로 입증할 수 없는 세부 주장·화면 수치·화자 의도는 `OPEN_MEDIA_DEPENDENT` 또는 `SOURCE_AMBIGUOUS`로 격리하고 재사용/투자신호 승인을 금지한다. 다른 독립 검증된 지식의 영상 단위 종료까지 가로막지 않는다.
8. **지식 원칙 완결성**: 각 원칙의 유효시점/적용대상/계좌·자산 종류/필수 개별자료/검증 출처/예외와 반례/투자에 직접 사용하면 안 되는 상황을 기록.
8-1. **원자 주장 전수 추적성 게이트**: 영상에서 추출한 모든 금융·투자 원자 주장에는 `V4 원칙 ID` 또는 `EXCLUDED/OPEN + 사유`를 필수로 연결한다. 연결률 100% 및 누락 ID 0건을 코드로 검사한다. 단, 원칙에 연결됐다는 사실만으로 공식자료 독립 검증이나 개인 투자 활용 승인을 의미하지 않는다.\n9. **기존 지식 연동**: 이전 V4 원칙의 사실상 동일·추가 근거·조건 다름·반증 여부 판단 후 통합. 문자열 유사도만으로 병합 금지.
10. **영상별 QA**: 분단위 커버리지 100%, V3 ID 연계 100%, 주요 숫자·세제 주장 독립 검증 또는 명시적 OPEN, 독립 QA와 GitHub 자동검사 실행/결과 확인.
11. **OPEN 종결 정의**: 개인의 NPS 예상액·보험계약, 화면 의존 수치, SRT 문맥 불명확 사례는 OPEN_EXTERNAL/OPEN_MEDIA_DEPENDENT로 분리해 영구 제한할 수 있다. 그 주장을 사용 가능한 투자 원칙으로 승격하지 않는다. 영상 연구 단위는 SRT 전체 추출과 독립 검증 가능 원칙의 QA를 충족하면 `CLOSED_WITH_SOURCE_LIMITATIONS`로 종료할 수 있다. SRT 자체가 누락·손상되거나 중요 영역을 전혀 확인할 수 없으면 `HOLD_SOURCE_MISSING`.
12. **연구 상태**: NOT_STARTED → SOURCE_READY → EXTRACTED → PRIMARY_REVIEWED → MODEL_AUDITED → VIDEO_QA → `CLOSED_WITH_SOURCE_LIMITATIONS`(SRT만 이용한 경우) 또는 `CLOSED_FULL_MEDIA_VERIFIED`(실제 화면·음성을 검증한 경우). 핵심 소스인 SRT 자체가 없으면 HOLD. 영상 단위 종료와 각 주장별 검증 승인, 개인 투자 실행 승인은 서로 별개의 축이다.
13. **변경 통제**: 한 번 승인한 영상에 신규 중요 오류 발견 시 사전 정의된 품질 결함 코드·증거·영향·회귀검사와 함께 개정한다. 근거 없이 원칙 수만 늘리거나 불필요한 반복 재심사를 금지한다.

## SRT 중심 영상 완료 안전장치
- 필수: SRT 원본·해시, 영상 시간 구간 전수감사, 기존 V3 주장 연결, 세부 주장 분해, 공식자료·법령 시행일 검증, 핵심 산술 독립 검산, 적용조건/예외, 누락·충돌 감사, GitHub 자동검사.
- 원본 영상 파일은 **필수 입력이 아니고** 추가 업로드를 요구하지 않는다. 영상 화면·음성 미확보는 **출처 충실도 한계**로 표시한다.
- 검증이 불가능한 개별 발언·수치·인출 모형은 `OPEN_MEDIA_DEPENDENT`, `MODEL_CONTRADICTED_UNDER_STATED_ASSUMPTIONS`, `OPEN_EXTERNAL` 등으로 격리한다. 이를 사실 확정·화자 발언 오류 확정·투자 활용 승인으로 포장하지 않는다.
- 영상별 `CLOSED_WITH_SOURCE_LIMITATIONS`은 그 영상에 대해 확보 자료 범위 내의 연구 절차를 마쳤다는 의미이며 **영상의 모든 주장이 참이라는 뜻이 아니다**.
- 화면만 있으면 해결되는 OPEN과, 법령/약관으로 해결할 수 있는 OPEN을 혼합하지 않는다. 새 영상 연구를 불필요하게 중단하지 않는다.
- 이미 발행된 `v4_001_media_gate_20261029.json`은 당시의 HISTORICAL_HOLD 기록으로 보존하며, 후속 SRT 중심 완료 정책에서 명시적으로 대체한다.
