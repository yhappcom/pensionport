# Batch 006 — 누적 51~60편 종합

- 체크포인트: 60편
- 작성일: 2026-10-04
- 범위: canonical sequence 51~60

## 이번 10편의 핵심 변화

51~54편은 펀드·ETF 선택을 상품명이나 최근 수익률이 아니라 구조와 실행으로 분해했다. 펀드는 투자대상·운용방식·위험·비용·환매조건을 먼저 보고, 동일 유형 안에서 벤치마크·운용일관성·변동성·비용을 함께 비교한다. ETF도 형식 자체보다 기초자산·지수방법론·파생구조·집중도·환노출·추적·비용을 확인한다.

55~57편은 채권과 정기투자를 실제 실행 레이어로 확장했다. 채권은 금리 숫자나 '안전자산'이라는 이름보다 발행자·신용등급·만기·가격·표면금리·수익률·유동성·금리민감도를 분해한다. 신규 현금흐름은 시장방향 예측보다 목표비중에서 부족한 자산을 채우는 cash-flow rebalancing에 사용할 수 있다.

58편은 퇴직연금을 DB·DC·IRP별 운용책임과 투자통제권으로 구분했다. 먼저 제도유형과 투자결정권을 확인하고 그 다음 투자규제·자산배분·수령전략을 설계한다. 중도인출·위험자산 한도·세액공제·연금수령 과세 등은 TIME_SENSITIVE로 최신 공식자료 확인이 필요하다.

59~60편 알파벳 사례는 개별기업 분석을 현재 제품 친숙도에서 더 확장했다. 주식 권리구조 → 현재 cash engine → 성장 플랫폼 → 미래 option portfolio → 자본배분 → 규제/윤리 → 밸류에이션 순으로 본다. 미래기술의 흥미나 과거 프로젝트 명칭을 현재 기업가치의 확정근거로 사용하지 않는다.

## 반복 강화된 원칙
- 상품명보다 경제적 노출과 구조를 먼저 본다.
- 최근 수익률 1위보다 목표 적합성·위험·비용·지속 가능성을 함께 본다.
- 안전자산도 신용·금리·유동성 위험을 분해한다.
- 계좌·상품·판매사·실행조건은 서로 다른 의사결정 레이어다.
- 신규 현금흐름은 예측보다 목표비중 복원에 활용할 수 있다.
- 과거 세율·제도·수수료·기업수치는 현재값으로 재사용하지 않는다.
- 개별주식은 코어 자산배분을 대체하지 않는다.

## 새 예외/위험
- 펀드는 주식처럼 항상 실시간 가격으로 즉시 체결되는 상품이 아니다. 기준가격 적용시점과 환매기간이 존재한다.
- 레버리지·인버스 ETF의 일일수익률 구조를 일반 장기 ETF와 동일하게 취급하지 않는다.
- 채권은 원금보장 상품이 아니며 만기 전 매도 시 금리변화에 따른 손실이 가능하다.
- 적립식 투자도 손실을 제거하거나 수익을 보장하지 않는다.
- DB·DC·IRP는 운용책임과 통제권이 다르므로 동일한 투자계좌처럼 취급하지 않는다.
- 미래사업은 실패·중단·규제 가능성이 있으며 option 가치와 현재 cash engine을 분리한다.

## 연금저축·IRP·ISA·국민연금
이번 구간의 직접 확장은 퇴직연금이다. DB/DC/IRP를 먼저 구분하고 운용책임과 투자통제권을 확인한 뒤 자산배분과 수령전략으로 넘어간다. 연금저축·ISA·국민연금의 기존 canonical 핵심 구조를 바꾸는 새 근거는 이번 10편에서 추가되지 않았다.

## 세금·공식검증
이번 구간은 새로운 현재 세율·한도 숫자를 canonical 값으로 추가하지 않는다. 퇴직연금의 중도인출, 위험자산 한도, 세액공제, 연금수령 과세는 제도 변경 가능성이 있으므로 실제 적용 시 최신 공식자료를 확인한다.

## 자산배분
채권은 단순한 '안전자산'이 아니라 신용·금리·듀레이션·유동성 위험을 가진 독립 자산군으로 본다. 정기 납입은 목표비중에서 부족한 자산을 우선 매수하는 cash-flow rebalancing으로 연결한다.

## 60편 시점 누적 프레임워크
`현금흐름/계좌 인프라 → 행동규율 → 목표/기간/소유주체 → 계좌·세제/고용제도 선택 → 자산군/통화 선택 → 목표비율 → 구현상품 → 상품구조·지수/벤치마크·신용·비용·세금·환전 검증 → 주문/체결/기준가격/환매 → 리밸런싱 → 장기 유지 → 인출/이전`

개별기업을 선택하는 경우 별도 하위 프레임을 사용한다.
`주식 권리구조 → 현재 cash engine → 성장 플랫폼 → 미래 option → 자본배분 → 규제/윤리 → 밸류에이션`
