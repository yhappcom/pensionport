# Batch 005 — 누적 41~50편 종합

- 체크포인트: 50편
- 작성일: 2026-10-02
- 범위: canonical sequence 41~50

## 이번 10편의 핵심 변화
41~46편은 ETF·ISA·증권사 선택을 더 세밀한 실행 레이어로 분해했다. ETF는 형식 자체가 분산을 보장하지 않으며 테마 집중도·추종지수·비용·세금을 확인해야 한다. ISA는 '좋은 상품'이 아니라 세제 래퍼이며, 제도 선택과 증권사 이벤트/수수료 선택을 분리한다.

47편의 해외주식 계좌 혜택 비교는 수수료·환전비용·이벤트 기간을 투자전략과 분리해야 한다는 원칙을 강화한다. 48편 달러투자는 원화 중심 포트폴리오의 통화 분산을 추가하고, 달러 자체와 달러예금·ETF·RP·발행어음이라는 구현수단을 구분한다.

49편 마이크로소프트 사례는 개별주식을 선택할 경우 사업모델·반복매출·경쟁우위·성장동력·경쟁사·실패경험·재무를 확인하는 기업분석 체크리스트를 추가한다. 이는 ETF/자산배분 코어 원칙을 대체하지 않는다.

50편 자녀 증여 영상은 프레임워크에 '세대 간 자산이전'을 새 축으로 추가한다. 자녀계좌에서는 상품보다 소유권·증여시점·10년 누계공제·신고·유동성을 먼저 설계한다.

## 반복 강화된 원칙
- 계좌, 증권사, 상품, 자산군은 서로 다른 의사결정 층위다.
- 분산은 상품 개수보다 위험원천의 분리다.
- 비용·세금·환전·상품구조는 실행 단계에서 반드시 검증한다.
- 과거 이벤트·금리·세율·기업지표를 현재값으로 사용하지 않는다.
- 장기 원칙은 반복 검증하지 않되 제도와 수치는 최신 공식자료로 검증한다.

## 새 예외/위험
- 달러는 위기 방어 역할을 할 수 있지만 환율상승이 보장되는 자산이 아니다.
- 외화 RP·발행어음은 은행예금과 동일하게 취급하지 않는다.
- 좋은 기업과 좋은 매수가격은 동일하지 않다.
- 자녀에게 정기적으로 소액을 이전한다고 해서 자동으로 증여세 이슈가 사라지지 않는다.
- 세대생략 증여는 별도 할증 규정을 확인한다.

## 연금저축·IRP·ISA·국민연금
이번 10편에서 연금저축/IRP의 핵심 구조 자체를 바꾸는 새 근거는 없었다. ISA는 세제 래퍼와 판매사 실행조건을 분리하는 원칙이 강화됐다. 국민연금의 새 canonical 근거는 추가되지 않았다.

## 세금
자녀 증여가 독립 세금축으로 추가됐다. 2026 국세청 기준 거주자인 수증자의 직계존속 증여재산공제는 10년 누계 성년 5천만원, 미성년 2천만원이다. 증여세는 10~50% 누진세율이며 세대생략은 원칙적으로 할증과세가 존재한다.

## 자산배분
기존 주식·채권·금·원자재에 더해 통화 노출을 명시적으로 본다. 달러 보유는 환차익 베팅과 위기 방어 목적을 구분하고 전체 목표비율 안에서 관리한다.

## 50편 시점 누적 프레임워크
`현금흐름/계좌 인프라 → 행동규율 → 목표/기간/소유주체 → 계좌·세제 선택 → 자산군/통화 선택 → 목표비율 → 구현상품 → 상품구조·비용·세금·환전 검증 → 주문/체결 → 리밸런싱 → 장기 유지 → 인출/이전`
